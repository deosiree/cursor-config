时序图 — Sequence Diagram

用户登录流程

100% 
sequenceDiagram
    participant User as 用户
    participant UI as 前端
    participant Auth as 认证服务
    participant DB as 数据库

    User->>UI: 输入账号密码
    UI->>Auth: POST /api/login
    Auth->>DB: 查询用户信息
    DB-->>Auth: 返回用户记录
    Auth->>Auth: 验证密码哈希
    alt 验证成功
        Auth->>DB: 生成会话 Token
        DB-->>Auth: Token 存储完成
        Auth-->>UI: 200 + Token
        UI-->>User: 跳转首页
    else 验证失败
        Auth-->>UI: 401 错误
        UI-->>User: 显示错误提示
    end

    Note over Auth,DB: 密码使用 bcrypt 加密
