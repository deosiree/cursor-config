# 目标
以 checklist 方式降低排查盲区与重复沟通成本。

## 执行步骤
1. 根据问题类型选择对应清单。
2. 逐项勾检并记录证据。
3. 汇总命中项，提炼根因与修复顺序。
4. 输出可执行修复计划与回归清单。

## 清单索引
1. `references/dom问题排查清单.md`
2. `references/dom问题易错清单.md`
3. `references/数据流问题排查清单.md`
4. `references/数据流问题易错清单.md`
5. `references/生产环境易错问题检查清单.md`

## 输出要求
1. 标注已检查/未检查/不适用。
2. 每个命中项给出证据位置和影响范围。
3. 最终输出按 P0/P1 排序。

## 外部最佳实践校验（必做）
1. 无论是否使用本 skill，都先进行一次 web search，确认当前任务的最佳实践与最新约束。
2. 优先来源顺序：官方文档 > 标准组织/维护者仓库 > 高质量技术文档。
3. 至少引用 2 个来源；高风险任务（生产、权限、安全、数据）至少 3 个来源交叉验证。
4. 输出中必须包含：来源链接、采纳点、未采纳点与原因。
5. 若检索结果不足或冲突，必须明确不确定性并给出保守方案。
