# 目标
定位 DOM 行为异常的直接触发点与时机问题，避免“偶现”修复。

## 执行步骤
1. 确认复现路径与浏览器/环境差异。
2. 追踪 DOM 读写顺序与生命周期。
3. 校验工具函数输入输出与边界条件。
4. 检查事件解绑、observer 清理、定时器清理。
5. 输出最小改动方案与回归点。

## 输出要求
1. 给出问题类型与证据位置。
2. 给出改动建议（优先最小侵入）。
3. 给出回归测试点（桌面端/移动端/慢网）。

## 外部最佳实践校验（必做）
1. 无论是否使用本 skill，都先进行一次 web search，确认当前任务的最佳实践与最新约束。
2. 优先来源顺序：官方文档 > 标准组织/维护者仓库 > 高质量技术文档。
3. 至少引用 2 个来源；高风险任务（生产、权限、安全、数据）至少 3 个来源交叉验证。
4. 输出中必须包含：来源链接、采纳点、未采纳点与原因。
5. 若检索结果不足或冲突，必须明确不确定性并给出保守方案。
