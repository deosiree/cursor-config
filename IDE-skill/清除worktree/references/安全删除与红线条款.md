# 安全删除与红线条款

## 必须

1. **默认 dry-run**：未加 `-Execute` 不得删除
2. **用户确认**：dry-run 展示后，用户明确同意才 `-Execute`
3. **`git worktree remove`**：在 **主仓库根** `gitRoot` 执行，禁止在 worktree 内部 remove 自身
4. **收尾 `git worktree prune`**：每个 gitRoot 执行一次
5. **跳过当前使用**：等于 `git rev-parse --show-toplevel` 或当前 `$PWD` 在其下的路径

## 禁止

- `Remove-Item -Recurse` 替代 `git worktree remove`（会残留 phantom 注册）
- 删除白名单外路径
- 未 dry-run 直接 `-Execute`
- 删除主 checkout

## 失败处理

- `git worktree remove` 失败：记录到表格 `Action=failed`，**不**强删目录
- 未在 `git worktree list` 注册的目录：跳过并注明原因

## 过期依据

使用目录 **LastWriteTime**（非 Git 创建时间）。输出中注明 cutoff 日期。
