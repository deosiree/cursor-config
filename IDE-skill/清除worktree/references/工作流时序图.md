# clean-worktrees.ps1 工作流时序图

## 整体流程（5 阶段）

```text
 ┌──────────────────────────────────────────────────────────────────┐
 │ ① 初始化                                                       │
 │  ├─ Resolve-WorkspaceRoot → 校验路径是否存在                    │
 │  ├─ 计算 Cutoff = (Get-Date).AddDays(-OlderThanDays)            │
 │  └─ git rev-parse --show-toplevel → 记录当前所在工作树 $currentTop │
 └─────────────┬────────────────────────────────────────────────────┘
               │
               ▼
 ┌──────────────────────────────────────────────────────────────────┐
 │ ② BFS 发现 Git 根 (Find-GitRoots)                              │
 │                                                                │
 │  Queue ← { Path=WorkspaceRoot, Depth=0 }                       │
 │  while Queue.Count > 0:                                        │
 │    item = Queue.Dequeue()                                      │
 │    if Test-IsGitRoot(item.Path) → 加入结果集                   │
 │      并扫描直接子目录是否有独立 .git → 嵌套仓库也加入           │
 │      continue (不再向更深 BFS)                                  │
 │    if Depth ≥ MaxDepth(3) → continue                           │
 │    列出子目录，跳过 $SkipDirNames                               │
 │      Queue.Enqueue({ subDir, Depth+1 })                        │
 │                                                                │
 │  返回: 排序后的 GitRoot 数组                                    │
 └─────────────┬────────────────────────────────────────────────────┘
               │
               ▼
     ┌─── 对每个 gitRoot 迭代 ───→┐
     │                            │
     ▼                            │
 ┌──────────────────┐             │
 │ ③ 读取 Git 注册   │             │
 │ Get-Registered-   │             │
 │ WorktreePaths     │             │
 │                   │             │
 │ git worktree list │             │
 │ --porcelain       │             │
 │ 解析 worktree 行  │             │
 │ → 返回注册路径集  │             │
 └────────┬─────────┘             │
          │                       │
          ▼                       │
 ┌──────────────────┐             │
 │ ④ 白名单扫描     │             │
 │ Get-TempWorktree │             │
 │ Candidates        │             │
 │                   │             │
 │ 3 个模式：        │             │
 │ .claude/worktrees │             │
 │   /agent-*        │             │
 │ .worktrees/*      │             │
 │ worktrees/*       │             │
 │ → 合并去重返回    │             │
 └────────┬─────────┘             │
          │                       │
          ▼                       │
 ┌─────────────────────────────────┴──────────┐
 │ ⑤ 逐候选判定 (5 层 if/elseif 保护链)       │
 │                                            │
 │  ┌─ 是主 checkout? ──────────────────→ skip (main checkout) ──┐
 │  │                                                            │
 │  ├─ 是当前所在 $currentTop 或在其子路径? → skip (in use)     │
 │  │                                                            │
 │  ├─ 未在 git worktree list --porcelain 注册? → skip (not     │
 │  │   registered in git worktree)                              │
 │  │                                                            │
 │  ├─ LastWriteTime ≥ Cutoff? → skip (not expired)              │
 │  │                                                            │
 │  ├─ -Execute 未传? → dry-run                                  │
 │  │                                                            │
 │  └─ 全部通过 → git worktree remove --force --force ✂️         │
 │                 → 成功: removed / 失败: failed                 │
 │                                            │
 │  每候选 → 输出一行表格                                       │
 └──────────────────────┬──────────────────────┘
          │             │
          │   (迭代下一个候选)
          │
          ▼  (当前 gitRoot 候选遍历完毕)
 ┌──────────────────┐
 │ ⑥ 收尾 prune     │
 │ 仅 -Execute 模式  │
 │ git worktree      │
 │ prune             │
 └────────┬─────────┘
          │
          ├──→ 下一个 gitRoot (回到③)
          │
          ▼  (所有 gitRoot 处理完毕)
 ┌──────────────────────────────────────────────────────────────────┐
 │ ⑦ 输出汇总                                                      │
 │  ├─ Format-Table 展示全部行                                      │
 │  ├─ Summary: preview=N removed=N skipped=N failed=N             │
 │  ├─ dry-run 且有候选→ 提示「加 -Execute 重跑」                   │
 │  └─ exit 0(全部成功) / exit 1(有 failed)                        │
 └──────────────────────────────────────────────────────────────────┘
```

## 函数关系

```text
Main body
 │
 ├─ Resolve-FullPath          — 路径存在校验 + 返回绝对路径
 ├─ Find-GitRoots             — BFS 遍历，返回所有 Git 根
 │    ├─ Test-IsGitRoot       — 检测路径下是否有 .git
 │    └─ (跳过 $SkipDirNames)
 │
 ├─ 对每个 gitRoot:
 │    ├─ Get-RegisteredWorktreePaths — git worktree list 注册比对
 │    ├─ Get-TempWorktreeCandidates  — 扫描 3 个白名单目录
 │    └─ 对每个候选:
 │         ├─ Test-IsExpired         — LastWriteTime < Cutoff
 │         └─ git worktree remove --force --force
 │         └─ git worktree prune (仅 -Execute 模式)
 │
 └─ Format-Table + Summary
```

## 5 层保护判定优先级

```text
候选路径
  │
  ├─ 第 1 层: 等于 gitRoot 本身?
  │      → skip (禁止删主 checkout)
  │
  ├─ 第 2 层: 等于 $currentTop 或当前 $PWD 在其下?
  │      → skip (禁止删正在使用的 worktree)
  │
  ├─ 第 3 层: 在 git worktree list 注册表中?
  │      No → skip (phantom 目录，git 不知情)
  │
  ├─ 第 4 层: LastWriteTime < Cutoff?
  │      No → skip (未过期)
  │
  └─ 第 5 层: -Execute 已传?
         No → dry-run (仅预览)
         Yes → git worktree remove --force --force
             → 成功: removed / 异常: failed
```

## 边界情况

| 场景 | 触发阶段 | 处理方式 |
|:---|---:|:---|
| WorkspaceRoot 不存在 | ① 初始化 | 抛出异常，脚本终止 |
| 某个子目录不可读（权限） | ② BFS | `Write-Warning` 跳过，继续下一个 |
| 嵌套 Git 根不可读 | ② BFS | `Write-Warning` 跳过嵌套扫描 |
| `git worktree list` 失败 | ③ 注册读取 | `Write-Warning` 返回空数组 |
| 白名单目录不存在 | ④ 候选扫描 | `Test-Path` 跳过，无候选 |
| 候选取消注册（phantom） | ⑤ 判定第 3 层 | skip + 注明 not registered |
| 候选 locked | ⑤ 执行删除 | `--force --force` 覆盖锁 |
| `git worktree prune` 失败 | ⑥ 收尾 | `Write-Warning` 不影响整体结果 |
| 无任何候选 | ⑦ 输出 | exit 0 + "No temp worktrees under whitelist" |
