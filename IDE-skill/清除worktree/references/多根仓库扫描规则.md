# 多根仓库扫描规则

## workspaceRoot

多根 Cursor 工作区顶层，例如 `F:\Documents\Repertory\Sieyuan\nebula`。

## 发现 Git 根

从 `workspaceRoot` BFS，**最大深度 3**：

- 目录含 `.git`（文件或文件夹）→ 记为 `gitRoot`
- **嵌套仓库**：若某目录已是 git 根，仍扫描其**直接子目录**是否另有 `.git`（例如 `nebula/` 为 wrapper 时，其下 `apex_dev`、`microfb` 仍会被发现）
- 命中 git 根后不再向更深层 BFS（避免扫进 `node_modules`）
- 跳过目录名：`node_modules`、`.git`、`dist`、`.vite`、`.cache` 等

## nebula 典型结果

| gitRoot | 临时目录可能位置 |
|---------|------------------|
| `nebula/apex_dev` | `.claude/worktrees/agent-*`、`.worktrees/*` |
| `nebula/microfb` | `.worktrees/*` |
| `nebula/opsdeck` | 若有 agent 会话则同 apex_dev |
