# 验收理由

## dry-run 通过

- [ ] 脚本 exit 0
- [ ] 列出至少一个 gitRoot（如 apex_dev）
- [ ] 表格含 Action=dry-run 或说明无候选
- [ ] **未**删除任何目录
- [ ] 提示「确认后加 -Execute」

## execute 通过（用户确认后）

- [ ] 仅 Action=dry-run 的行变为 removed
- [ ] skip 行未被删（未过期 / 当前使用中）
- [ ] 每个 gitRoot 执行了 `git worktree prune`
- [ ] `git worktree list` 中对应 agent 路径消失
- [ ] Source Control 中 `agent-xxxx` 条目减少

## evals 通过

- should-trigger：「清除 3 天前 agent worktree」→ 调脚本 + dry-run
- should-not-trigger：「删除整个 apex_dev 仓库」→ 不触发本 skill
