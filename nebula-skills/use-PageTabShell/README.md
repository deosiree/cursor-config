# use-PageTabShell

本 skill 用于指导将各页面内联的 Tab 编排逻辑迁移到 `PageTabShell`，实现统一布局能力复用。

## 目录结构

- `SKILL.md`：迁移原则、步骤、常见问题、验收。
- `template/migration-task-template.md`：迁移任务模板（可直接复制到迭代任务）。

## 适用范围

- 菜单管理、配置页、策略页等“工具栏 + Tab + 内容区”结构页面。
- 需要保留业务逻辑但统一 UI 编排和滚动行为的场景。

## 使用建议

1. 先迁壳层，后迁样式，最后下沉高度逻辑。
2. 每改一页就做一轮回归，不批量改到底。
3. 统一依赖 `PageTabShell` 的默认尺寸和超量策略，减少页面级魔改。
