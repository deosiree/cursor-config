# Template

本目录包含两类模板：

- 文档模板：给 agent 执行用。
- 源码模板：给人类评审“退化前后长什么样”。

## 建议阅读顺序

1. `microfb-deprecation-checklist.md`
2. `microfb/before`
3. `microfb/after-detached`
4. `microfb/after`

## 目录说明

- `microfb/before`：取自现有旧方案的代表性文件。
- `microfb/after-detached`：展示先脱钩到硬编码/静态常量的中间态。
- `microfb/after`：展示退化后的 legacy 备份与只读兼容形态。
