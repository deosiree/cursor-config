# feature-skills

这里是 `i18n-server` 的源码级功能技能池。

本索引采用 `写skill` 要求的本地中文模式。

## 定位

- 所有节点都只负责某一类具体源码改造能力
- 不负责总方案、多轮会话路由或高层策略判断
- 可被多个 `../intention-skills/` 节点复用

## 使用原则

- 当功能缺口明确时，可直接进入这里的某个节点
- 当功能缺口不明确时，应先经过 `路由-选择功能子skill` 或其他意图层节点

## 使用示例

```text
我已经确认当前只差模板层静态文案收口，直接帮我进入对应的功能 skill。
```

```text
如果当前缺口还不明确，不要直接猜功能节点，先回到意图层判断。
```
