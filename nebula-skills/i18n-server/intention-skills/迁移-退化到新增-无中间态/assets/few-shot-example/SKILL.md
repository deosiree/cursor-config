# 会话示例：先退化旧链路再新增

## 背景

这个示例用于说明：当前仓库仍有旧 runtime 深度参与运行，不能直接进入新增阶段，也不适合保留长期中间态。

## 重点

- 先确认旧 runtime 是否仍在主链路中
- 先说明为什么不适合走“有中间态收敛”
- 给出退化阶段步骤
- 最终显式 handoff 到 `策略-新增新i18n`

## 最小成功信号

- 能证明为什么必须先退化
- 能说明为什么不是“有中间态收敛”
- 能说明退化完成后下一步进入哪个意图节点
