# intention-skills

这里是 `i18n-server` 的意图层 skill 入口。

## 节点列表

- `分析-i18n链路`
- `迁移-退化到新增-无中间态`
- `迁移-收敛旧到新-有中间态`
- `策略-新增新i18n`
- `路由-选择功能子skill`
- `编排-i18n迁移`

## 层级约束

- 根 `SKILL.md` 只直接消费这一层
- 这一层再按需消费 `../feature-skills/`
- `分析-i18n链路` 是横向公共前置能力，不只是独立节点

## 典型协作方式

- 链路不明确：先 `分析-i18n链路`
- 需要总方案：`编排-i18n迁移`
- 需要单次功能路由：`路由-选择功能子skill`
- 需要迁移策略：进入对应迁移 skill
- 已无旧 i18n：进入 `策略-新增新i18n`

## 使用示例

```text
先分析当前 i18n 链路，再决定该走退化、收敛还是新增。
```

```text
我要多个方案比较，不是单次功能路由。
```

```text
我已经知道当前只差某项能力，直接帮我选功能 skill。
```
