# 会话示例：单次功能路由判断

## 背景

这个示例用于说明：用户并不需要总方案，只想知道当前这一步最该进入哪个功能节点。

## 重点

- 先判断问题是否仍属于单次功能路由
- 如果 gap 不明确，但仍不是总方案问题，可先消费 `分析-i18n链路`
- 最终只输出 1 个 `selectedFeatureSkill`
- 同时说明为什么不是其他候选节点

## 最小成功信号

- 不会把问题误升级成总编排
- 不会把问题误降成直接实现某个功能节点
- 能解释当前一步为什么优先进入某个功能 skill
