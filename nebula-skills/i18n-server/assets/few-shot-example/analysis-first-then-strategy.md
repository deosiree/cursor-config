# analysis-first-then-strategy

## 用户请求

```text
如果分析结果显示旧 i18n 已经完全退化，就帮我进入新增新 i18n 阶段；如果还没退化干净，再告诉我该走哪条迁移策略。
```

## 预期父 agent 判断

- 当前不能直接进入 `策略-新增新i18n`
- 也不能直接进入某个迁移策略节点
- 必须先分析事实

## 预期分流路径

1. `分析-i18n链路`
2. 根据分析结果二选一：
   - `策略-新增新i18n`
   - `迁移-退化到新增-无中间态` 或 `迁移-收敛旧到新-有中间态`

## 关键理由

- 用户提出的是条件式策略请求
- 关键分叉点是：
  - 是否仍存在旧 runtime
  - 是否已完全退化
  - 是否适合保留中间态

## 合格输出信号

- 明确先分析，再条件分流
- 不在事实不足时提前承诺新增阶段
- 若进入策略节点，能解释为什么不是其他相邻策略
