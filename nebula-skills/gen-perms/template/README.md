# template

本目录提供 `gen-perms` 的两类文档模板与模板索引，面向“复制后填充”场景。

## 模板文件

- `路由-组件-权限点-API 源码梳理.md`
  - 用途：已命中权限指令的路由梳理。
  - 重点：权限点下 API 三列表。

- `未命中-v-hasPerm-静态路由-权限点补齐设计.md`
  - 用途：未命中权限指令路由的补齐设计。
  - 重点：`## [路由]` + `### [权限点]` 的层级化三表结构。

- `template-index.yaml`
  - 用途：为 agent 提供模板元信息、必填章节、占位符清单。

## 使用流程

1. 从 `template-index.yaml` 读取目标模板与必填项。
2. 复制模板到 `outputDocs` 对应路径。
3. 用真实路由、组件、权限点、API 数据替换占位符。
