# docs

本目录存放 `gen-perms` 的规则依据与计划样例，供 agent 生成文档时对齐口径。

## 文件说明

- `spec.yaml`: agent 优先读取的结构化规范（输入/输出契约与回退策略）。
- `权限点api表格化优化.plan.md`: API 三列表口径来源样例。
- `未命中路由权限补齐文档.plan.md`: 路由补齐设计结构来源样例。
- `路由-组件-权限点-API 源码梳理计划.md`: 梳理文档计划样例。

## 使用建议

1. 先读取 `spec.yaml`，确定参数与输出结构。
2. 再参考 plan 样例，补全中文术语与表达风格。
3. 生成文档后执行自检：层级键、表头、回退描述、行号证据。

## 常见坑

- 把 `direct/forward` 前缀写进 `apiUrl`。
- `description` 字段取值混乱（未按 `description > summary > 默认文案`）。
- 同一路由下权限点标题重复，导致层级歧义。
