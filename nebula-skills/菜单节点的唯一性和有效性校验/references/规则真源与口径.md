# 规则真源与口径

## 唯一真源

- 文档：`nebula/docs/plans/前端的表单校验规则.md`
- **禁止**用本地未上传的 `seccenter` 实现覆盖文档（例如旧版「perm 全表唯一」）。

## 唯一性与耦合（文档摘要）

| 对象 | 规则 |
|------|------|
| directory / page `route_path` | 同 `project_id` 下，`type!=function` 的非空 path 唯一；不支持 `*` |
| function `route_path` | 同项目下不得与**父链**上任一节点 path 全等；任意段可 `*` |
| page `route_path` + `params` | **全库**（type=page）唯一 |
| 非 page | `params` 必须为空 |
| function `perm` | 必填；**同 `parent_id`** 下唯一（允许跨父复用） |
| 非 function | `perm` 必须为空 |
