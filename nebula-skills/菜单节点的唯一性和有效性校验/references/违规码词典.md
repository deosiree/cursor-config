# 违规码词典

扫描输出形如 `[source/code]`。`source` 仅为 `frontend` | `doc`。

| code | source | 含义 | 倾向 |
|------|--------|------|------|
| `route.syntax` | frontend/doc | path 语法不合法；或 dir/page 含 `*` | 多半改节点；大量再谈放宽语法 |
| `route.dup` | doc | 同项目 directory\|page 的 `route_path` 重复 | 改其中一个 path |
| `route.anc` | doc | function path 与父链全等 | 改 function path（如加 `/*`） |
| `perm.empty` | doc | function 缺 perm | 补配置 |
| `perm.sibling` | doc | 同 `parent_id` 下 perm 重复 | 改标识 |
| `perm.mustEmpty` | doc | 非 function 带了 perm | 清空 perm |
| `params.invalid` | frontend | page params 条目非法 | 改 params |
| `params.mustEmpty` | doc | 非 page 带了 params | 清空 params |
| `page.combo` | doc | type=page 的 path+params **全库**冲突 | 见下方「单项目 vs 合并」 |

## 单项目 vs 合并扫描

| 范围 | 常见结果解读 |
|------|----------------|
| 单文件 / 单 `projectId` | 看该项目是否合规；`route.dup` / `perm.sibling` / 语法等 |
| `_all.json`（多导出合并） | `page.combo` 会把「跨项目同 path+params」算进来；克隆模板常见 |

**不要**把跨项目 `page.combo` 当成「单项目菜单脏数据」。
