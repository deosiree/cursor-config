# 写说明书

## RED

没有本 skill 时，agent 常见失败：

- 不区分改版/新建，照抄企业版或某一模块原文
- 正文使用粗体、列表、表格，转 Word 需手工清理
- 段与段之间无空行，带格式粘贴 Word 后被合并为同一段
- 截图占位 `【待补截图：…】` 上下无空行，Word 格式刷无法分段刷首行缩进
- 把整节所有内容挤成一行超长段落
- 用日式引号「」标注界面文案（应使用 “ ”）
- 把权限标识、API、实现细节写进用户手册
- UI 文案与源码 i18n 不一致
- 新建模块因无企业版原稿而无法组织章节
- 未读源码就落盘，确认框文案与界面不一致
- 漏写截图占位（`##`/`###`/节内卡片或步骤子块均须有 `【待补截图：…】`）

## 何时使用

- 将某模块从企业版说明书改版为云边版（用户/菜单/角色/租户等）
- 为企业版未收录的模块新建云边版说明书（个人中心、安全配置等）
- 用户明确要求：参考模板结构、读源码、输出无格式 md

## 何时不要使用

- 只改 apex_dev 业务代码，不写说明书
- 只润色 Word 排版或补截图，不涉及正文编写
- 只翻译或校对已有云边版全文，无需对照源码

## 执行反例（禁止）

- 修改 `云边版/原稿/**/*-企业版.md` 或 `references/enterprise-manual/` 内任何文件
- 在说明书正文写 perm 标识、API 路径、前端实现细节
- 用粗体、无序/有序列表、表格组织用户手册正文
- 无企业版收录的模块仍写“相较企业版的变化”
- 跳过源码阅读直接拼凑企业版原文
- 段与段之间无空行（粘贴 Word 合并为一段）
- 漏写 `【待补截图：…】`（含 `##` 总述、各 `###` 节、节内卡片/步骤/并列场景）
- 用 HTML 注释 `<!-- -->` 写截图占位（粘贴 Word 不可见，须用方括号）
- 截图占位上下不插空行（Word 格式刷无法逐段刷首行缩进）
- 界面按钮文案与源码 i18n 不一致（如写 “新建” 而源码为 “新增”）
- 用日式引号「」标注界面文案（应使用 “ ”）

## 输入契约

缺一则暂停询问，不得猜测落盘：

| 字段 | 必填 | 说明 |
|------|------|------|
| moduleName | 是 | 模块中文名 |
| targetOutputPath | 是 | 云边版 md 输出路径 |
| sourceRepo | 否 | 默认 apex_dev |
| route | 否 | 定位 views 与路由 meta |
| referenceTemplatePath | 改版必填 | 同模块 `*-企业版.md` 切片路径 |
| structuralReferencePaths | 新建建议 | 1～2 个形态相近的已完成云边版说明书 |
| screenshotMode | 否 | 默认 bracket（`【待补截图：…】`） |

🔴 **CHECKPOINT · STOP**：`moduleName` 与 `targetOutputPath` 齐全后，向用户确认任务模式（改版/新建）与结构参考路径，再进入 GREEN。

## 异常与 fallback

| 触发条件 | 一线处理 | 仍失败则 |
|----------|----------|----------|
| 改版但无模块切片 | 读 `references/enterprise-manual/目录索引.md` 定位全册 `##` 行号 | 询问用户提供切片路径或确认从全册摘录 |
| 新建但不知参考哪篇 | 查 `references/模块说明书编写指南.md` 页面形态表 | 列出 2 个候选参考路径请用户择一 |
| 找不到 views 目录 | grep `src/router` 按 route 或 meta.title 反查 | 读 `docs/menu/模块盘点/*.md` 找组件路径 |
| 企业版与源码差异过大 | 列 diff 提纲（保留/改写/新增/删除） | 仅将新增能力单列 `###`，不强行对应旧节 |
| 用户要求加粗体或列表 | 引用 `references/说明书格式约束.md` 说明 Word 模板限制 | 坚持纯段落输出，除非用户明确放弃转 Word |

## GREEN

每一轮固定五步：判定模式 → 读结构参考 → 读源码列提纲 → 写正文 → 验收落盘。

细则：`[[references/模块说明书编写指南.md]]`；格式：`[[references/说明书格式约束.md]]`；全册：`[[references/enterprise-manual/]]`。

### 1. 判定任务模式

输入：moduleName、referenceTemplatePath（若有）、目录索引检索结果。

输出：一行结论 `模式=改版|新建` + 结构参考文件列表（1～3 个路径）。

规则：

- 改版：存在 `云边版/原稿/{模块}/*-企业版.md` 或全册有收录
- 新建：全册无收录（已确认无：个人中心、安全配置）→ 按页面形态选参考 + 源码列节

结构参考优先级（改版）：模块切片 → enterprise-manual 全册章节 → 已完成 `*-云边版.md`（只学格式）。

### 2. 读结构参考

输入：上步确定的参考文件。

输出：骨架摘要（3 条以内）：总述怎么写、`###` 节命名习惯、截图占位写法。

约束：只学骨架不抄内容；禁止修改参考原稿与 enterprise-manual 副本。

### 3. 读源码提炼功能点

输入：sourceRepo、route 或 moduleName 映射的 views 路径。

执行顺序：

1. `src/router` → path、meta.title
2. `src/views/{模块}/index.vue` → 工具栏、弹窗、主流程
3. `components/`、`*-table-columns.ts`、表单组件 → 列、字段、操作项
4. grep `ElMessageBox.confirm` → 确认框原文
5. grep `$t('` 或读 zh_CN 词条 → 按钮与标签
6. `docs/menu/模块盘点/*.md` → 仅 agent 内部，不写入正文

输出：章节提纲（中间产物，格式如下，不写入最终 md）：

```text
模式：改版|新建
## {模块名}
### {功能节名} — {要点1；要点2}
...
```

🔴 **CHECKPOINT · STOP**：提纲覆盖全部用户可见操作后，再写正文；缺项则回到步骤 3 补读源码。

### 4. 写正文

输入：章节提纲、格式约束。

输出：`targetOutputPath` 的 md 草稿。

硬约束：仅 `##` / `###`、`【待补截图：xxx】`、纯中文段落；禁止粗体、列表、表格、Mermaid、错误节编号（2.2.2）。

落盘正文格式五检（任一项不通过则回到本步修正）：

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | 空行规则 | 叙述段之间保留 Markdown 空行；每个 `【待补截图：…】` 上下各一空行 |
| 2 | 节内分段 | 卡片/步骤/场景各占一行，非整节一行 |
| 3 | 弯引号 | 界面原文用 “ ”，禁止「」 |
| 4 | 纯叙述 | 无列表符号、无粗体、无表格 |
| 5 | 截图占位 | `【待补截图：…】` 上下各一空行；`##`/`###`/节内子块均覆盖 |

内容：文案与源码一致；改版保留节对应并单列新增；新建不写虚构对比叙述。完整细则见 `references/说明书格式约束.md`；新建样本见 `assets/few-shot-example/新建-安全配置.md`。

### 5. 验收落盘

对照 `[[assets/skill-output-checklist.md]]` 逐项勾选；任一项不通过则回到步骤 4 修正，不得落盘。

落盘前用 `[[evals/test-prompts.json]]` 做自检（干跑即可，不必真写文件）：

| 自检项 | 通过标准 |
|--------|----------|
| 改版 prompt（如用户管理） | 先读企业版切片再读源码，输出纯段落，未改企业版原稿 |
| 新建 prompt（如个人中心） | 已查目录索引确认无收录，未写“相较企业版” |
| 菜单管理等树形模块 | 结构参考指向菜单管理类，非列表 CRUD 模板 |
| 非说明书 prompt（如修 bug） | 不触发本 skill，改走业务代码流程 |

🔴 **CHECKPOINT · STOP**：验收与自检通过后写入 `targetOutputPath`；写入后告知用户输出路径与待补截图总数（grep 统计 `【待补截图` 行数）。

## REFACTOR

- 用户说不要格式 → 剥离 markdown 装饰，保留标题与截图占位
- 企业版 docx/md 更新后 → 维护者重复制 enterprise-manual 并更新目录索引
- 模块样本增多 → 只扩 references 形态表，主 SKILL 保持精简

## 使用示例

改版：

```text
使用 $写说明书
参考 用户管理-企业版.md，阅读 apex_dev 用户管理源码，
落盘 用户管理-云边版.md，截图用【待补截图：…】占位，正文纯段落无列表粗体。
```

新建：

```text
使用 $写说明书
编写个人中心云边版说明书，无企业版原稿；
结构参考 租户管理-云边版.md 的总述写法，功能点以 apex_dev profile 源码为准，
落盘到 个人中心-云边版.md。
```
