# 改版示例：租户管理

## 用户输入（摘要）

```text
参考 租户管理-企业版.md 结构，阅读 apex_dev 租户管理源码，
落盘 租户管理-云边版.md，截图用【待补截图：…】占位，正文无列表粗体。
```

## 输入路径

| 项 | 路径 |
|----|------|
| 结构参考 | 云边版/原稿/租户管理/租户管理-企业版.md |
| 源码 | apex_dev `src/views/tenant/` |
| 内部盘点 | docs/menu/模块盘点/02-租户管理-tenant.md |
| 输出 | 云边版/原稿/租户管理/租户管理-云边版.md |

## 模式判定

改版（有企业版切片 + 全册 297 行有收录）。

## diff 要点（企业版 → 源码）

| 类型 | 示例 |
|------|------|
| 改写 | 搜索改为关键字；新建改为三步向导；编辑拆为“管理信息” |
| 新增 | 管理项目、项目资源绑定、停用/启用租户、所有者状态、重发激活链接 |
| 删除 | 租户标识字段；行内平铺操作改为操作菜单 |

## 结构参考学到了什么

- `##` 总述：上中下布局一段说完
- `###` 每功能一节，节首截图占位
- 叙述：入口 → 界面 → 操作 → 确认框原文

## 输出要点

- 确认框须用源码原文，如 “删除租户的同时会解绑该租户的所有设备，确定删除租户?”
- 按钮用 “新增” 非 “新建”；界面文案一律用弯引号 “ ”，不用「」
- 全文纯段落，约 10 个 `###` 节覆盖源码全部用户操作
- 落盘时叙述段之间保留 Markdown 空行；`【待补截图：…】` 上下各一空行
- 完整紧凑排版见 `云边版/原稿/租户管理/租户管理-云边版.md`（总述分上中下三行；新增租户每步一行）

## 勿照搬

- 不要把租户专有字段（三步向导、项目资源绑定）写进其他模块
- 其他模块按各自源码重新列 diff
