# 新建示例：安全配置（完整落盘）

## 输入（摘要）

```text
编写安全配置云边版说明书，企业版无对应章节；
参考设置类页面叙述方式，源码 securityConfig。
```

## 判定

新建；`目录索引.md` 标记全册无收录。

## 结构参考

| 项 | 选择 |
|----|------|
| 形态 | 单页配置 / 标签页 + 卡片分区 |
| 叙述参考 | 租户管理-云边版.md 总述分段 + 截图占位习惯 |
| 源码 | `src/views/system/securityConfig/` |
| 输出 | 云边版/原稿/安全配置/安全配置-云边版.md |

## 格式要点（本样本示范）

- 段落空行：叙述段之间保留 Markdown 标准空行；`【待补截图：…】` 上下各一空行
- 截图占位：`##` 总述 1 个；每个 `###` 节首 1 个；节内每张配置卡片正文前再各 1 个
- 节内分段：每张卡片各占一行叙述
- 界面文案：弯引号 “ ”，不用「」
- 无列表/粗体/表格

## 输出节选（登录策略节，含子块占位）

完整文件见 `云边版/原稿/安全配置/安全配置-云边版.md`（共 10 处截图占位）。

