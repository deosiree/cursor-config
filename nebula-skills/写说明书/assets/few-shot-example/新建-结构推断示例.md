# 新建示例：结构推断（个人中心、安全配置）

企业版全册无“个人中心”“安全配置”收录。须走新建流程。安全配置完整样本见 `新建-安全配置.md`。

## 个人中心

### 输入（摘要）

```text
编写个人中心云边版说明书，无企业版原稿；
结构参考 租户管理-云边版.md 总述写法，功能点以 apex_dev profile 源码为准。
```

### 判定

新建；`目录索引.md` 标记全册无收录。

### 结构参考选择

| 项 | 选择 |
|----|------|
| 形态 | 个人资料 / 分区展示 + 部分可编辑 |
| 叙述参考 | 租户管理-云边版.md 的总述段落风格（非业务内容） |
| 源码入口 | `src/views/profile/index.vue`，路由 `/Apex/profile` |
| 内部盘点 | docs/menu/模块盘点/03-个人中心-profile.md |

### 建议章节提纲（编写前确认）

```text
## 个人中心
### （总述：页面分区、入口）
### 查看/编辑基本信息
### 修改密码（若有）
### …（按源码实际弹窗与表单项增补）
```

每节：截图占位（上下各一空行）+ 纯段落；不写“相较企业版”；叙述段之间保留 Markdown 空行。

---

## 安全配置

### 输入（摘要）

```text
编写安全配置云边版说明书，企业版无对应章节；
参考设置类页面叙述方式，源码 securityConfig。
```

### 判定

新建。

### 结构参考选择

| 项 | 选择 |
|----|------|
| 形态 | 单页配置 / 表单分区 |
| 叙述参考 | 企业版“安全管理”节的单页操作节奏（仅学叙述，字段以源码为准） |
| 源码入口 | `src/views/system/securityConfig/index.vue` |
| 内部盘点 | docs/menu/模块盘点/06-安全配置-securityConfig.md |

### 建议章节提纲

```text
## 安全配置
### （总述：配置项分区）
### 激活方式 / 密码策略 / …（按表单区块拆节）
```

---

## 新建通用注意

1. 先 grep 全册与目录索引确认无收录
2. 从 router → index.vue → 子组件梳理功能点
3. 形态表选 1 个已完成云边版学段落，不抄字段
4. 提纲确认后再写正文

待个人中心实际落盘后，可将本节升级为完整 after 样本；安全配置已完成，见 `新建-安全配置.md`。
