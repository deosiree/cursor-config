# 模块说明书编写指南

## 任务模式判定

### 改版

满足任一条件即可判定为改版：

- 用户提供了同模块 `*-企业版.md` 切片路径
- `references/enterprise-manual/目录索引.md` 中该模块标记为「全册有收录」
- `云边版/原稿/{模块}/` 下已有企业版切片

流程：读企业版结构 → 读源码 → 列 diff（保留/改写/新增/删除节）→ 写云边版。

### 新建

满足条件：

- 全册目录索引中模块标记为「无收录」
- 或用户明确说明企业版无此模块

已确认无企业版收录（编写时以索引为准）：个人中心、安全配置。

流程：按页面形态选结构参考 → 读源码归纳功能点 → 自行列 `##` + `###` → 写云边版。不虚构「相较企业版的变化」叙述。

## 结构参考优先级

### 改版

1. `F:/Documents/Default-Obsidian/思源/云平台/说明书/云边版/原稿/{模块}/*-企业版.md`
2. `references/enterprise-manual/PM2025286-...使用说明书.md` 中 grep `## {模块名}`
3. 已完成 `*-云边版.md`（学段落风格）

### 新建

1. 形态相近的已完成 `*-云边版.md`（见下表）
2. `docs/menu/模块盘点/*.md` 了解路由与组件入口（不写入正文）
3. 全册中同类页面的企业版写法（仅学叙述节奏，不抄过时字段）

## 页面形态 → 结构参考

| 形态 | 特征 | 可参考 |
|------|------|--------|
| 列表 CRUD | 搜索、表格、行操作、分页、批量删除 | 租户管理-云边版、用户管理-企业版 |
| 树形管理 | 树 + 增删改、父子级 | 菜单管理-企业版 |
| 单页配置 | 表单分区、保存按钮、无列表 | 安全配置（新建）、安全管理-企业版 |
| 个人资料 | 分区展示、部分可编辑 | 个人中心（新建） |

## 读源码（通用）

默认仓库：`apex_dev`。

| 步骤 | 位置 | 提取内容 |
|------|------|----------|
| 1 | `src/router/index.ts` | 路由 path、meta.title |
| 2 | `src/views/{模块}/index.vue` | 工具栏按钮、弹窗、主流程 |
| 3 | `components/`、`*-table-columns.ts` | 表格列、表单字段 |
| 4 | grep `ElMessageBox.confirm` | 删除/停用等确认文案 |
| 5 | grep `$t('` 或读 zh_CN.json | 按钮与标签原文 |
| 6 | `docs/menu/模块盘点/{nn}-{模块}.md` | 权限与行为补充（内部） |

## 改版 diff 规则

| 类型 | 处理 |
|------|------|
| 保留 | 企业版有、源码仍有且交互未变 → 改写表述对齐现行 UI，节名可保留 |
| 改写 | 企业版有但字段/流程/按钮已变 → 同节重写，不保留过时内容 |
| 新增 | 源码有、企业版无 → 新 `###` 节 |
| 删除 | 企业版有、源码无 → 不写进云边版 |

中间产物「章节提纲」列出每节要点，确认后再写正文。

## 新建列节规则

1. 从 `index.vue` 与子弹窗梳理用户可见功能点（每个独立操作倾向一节）
2. `##` 总述覆盖整页布局
3. `###` 节名用界面操作名，不用编号
4. 向导类流程可在一节内用「步骤 1…步骤 2…」文字描述，不用列表符号

## 输出与落盘

- 写入用户指定的 `targetOutputPath`，文件名建议 `{模块名}-云边版.md`
- 正文段落之间保留 Markdown 空行；截图占位上下各一空行
- 不修改企业版原稿与 skill 内 enterprise-manual 副本
