# 说明书格式约束

云边版用户使用说明书正文须便于后续转 Word，模板对格式有严格要求。

## 行距与空行（转 Word 优先）

带格式粘贴到 Word 时，Markdown 的**段落空行**决定 Word 是否识别为独立段落；缺少空行会被合并为同一段，格式刷无法逐段生效。

排版规则：

- **叙述段落之间**：保留 Markdown 标准空行（一段一行文字，段与段之间空一行）
- **`【待补截图：…】`**：上下各保留一行空行（占位独立成段，便于插图与格式刷）
- **`##` / `###` 标题前**：与上一段正文之间保留一空行
- 同一逻辑块内不要把多段内容挤在一行里；也不要省略段间空行
- 文件末尾保留单个换行符

示例（节选）：

```text
## 安全配置

【待补截图：安全配置-页面总览】

安全配置页面用于集中管理登录、密码与会话策略……

顶部为功能操作区……

中间为表格区……
### 登录策略

【待补截图：安全配置-登录策略】

在“登录策略”标签下……分为四张配置卡片。

【待补截图：安全配置-用户激活方式】

“用户激活方式”卡片……
```

## 允许

- `##` 模块总述标题
- `###` 功能节标题
- `【待补截图：模块名-功能描述】` 截图占位（默认，粘贴 Word 可见）
- 纯中文叙述段落，用分号、顿号、逗号串联信息

## 禁止（正文中不得出现）

- 粗体、斜体、删除线等行内强调
- 无序列表（`-`、`*`）
- 有序列表（`1.`、`2.`）
- Markdown 表格
- Mermaid、代码块（除非用户明确要求保留）
- 企业版遗留的错误节编号（如 `### 2.2.2 新建租户`），改用清晰功能名（如 `### 新增租户`）
- 权限标识（`sys:*`）、API 路径、前端实现细节（i18n wire、localStorage 等）
- HTML 注释式截图占位 `<!-- 待补截图：… -->`（粘贴 Word 会被吞掉，不可见）

## 界面文案引号

按钮、字段标签、弹窗标题、提示语、选项取值等界面原文，须用弯引号 “ ” 包裹，写法与旧版企业版说明书一致。

- 正确：点击 “搜索” 按钮；“新增租户” 功能；选项包括 “正常”“停用”
- 错误：点击「搜索」按钮；「新增租户」功能
- 连续多个并列文案时，闭合引号与下一开引号紧挨，如 “搜索”“新增”“删除”
- 引号内文字须与 apex_dev 源码 i18n 一致（如 “新增” 而非 “新建”）

## 标题与叙述习惯

模块总述（`##`）：一段话概括页面定位与整体布局（顶部操作区、中部表格或表单区、底部分页等），用分号分隔层次，不用列表。

功能节（`###`）：标题下空一行 → 截图占位（上下各一空行）→ 正文。节内有多张卡片、多个步骤或多个操作场景时，各块正文前各加占位（上下各一空行）；**每个叙述段落之间保留 Markdown 空行**。

## 截图占位（必填）

截图占位是落盘正文的一部分，不可省略；后续 Word 排版据此插入图片。

命名格式：`【待补截图：{模块名}-{功能描述}】`，模块名与 `##` 标题一致，功能描述用界面可见名称（如“用户激活方式”“步骤1基础信息”）。须用中文方括号，不用 HTML 注释。

占位规则：

| 层级 | 要求 |
|------|------|
| `##` 模块总述 | 标题下空一行 → 占位（上下各一空行）→ 总述正文 |
| `###` 功能节 | 标题下空一行 → 节首占位（上下各一空行）→ 正文 |
| 节内子块 | 每个子块正文前：空行 → 占位（上下各一空行）→ 该块正文 |

紧凑示例（登录策略含四张卡片）：

```text
### 登录策略

【待补截图：安全配置-登录策略】

在“登录策略”标签下……分为四张配置卡片。

【待补截图：安全配置-用户激活方式】

“用户激活方式”卡片……

【待补截图：安全配置-登录保护】

“登录保护”卡片……
```

反例：段与段之间无空行（粘贴 Word 合并为一段）、节内有多张卡片却只写节首 1 个占位、占位行上下无空行、或整篇无任何 `【待补截图：…】`、或使用 `<!-- -->` 注释写法。

## 截图策略

| 模式 | 写法 |
|------|------|
| bracket（默认） | `【待补截图：租户管理-列表页】` |
| obsidian_image | 仅用户明确要求时使用 Obsidian 图片链接 |
| none | 用户明确要求不写截图引用 |

## 与用户界面文案

按钮、字段标签、弹窗标题、确认框原文须与 apex_dev 源码 i18n 一致，并用弯引号 “ ” 标注（如 “新增” 而非 “新建”）。确认框须对照 `ElMessageBox.confirm` 原文。
