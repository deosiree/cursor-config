# 菜单树导入验证 — 验证清单

## Dry Run 验证

- [ ] 执行 `POST .../menu/project/import`（`dry_run: true`）
- [ ] 响应无 `[100000]未知错误`
- [ ] 无「ID 无效」错误
- [ ] 无重复 `code` 错误
- [ ] 所有节点的 `parent_id` 不为 `null`
- [ ] 层级关系正确

## 正式导入

- [ ] 备份当前菜单树
- [ ] 执行正式导入（`dry_run: false`）
- [ ] 确认导入成功
- [ ] 检查菜单管理页面是否显示新节点

## 角色配置

- [ ] 进入角色管理
- [ ] 为管理员角色勾选新增 perm
- [ ] 保存角色配置
- [ ] 通知相关人员重新登录或刷新权限

## 回归验证

- [ ] Owner 用户：所有新功能可用
- [ ] 普通用户（有 perm）：对应功能可用
- [ ] 普通用户（无 perm）：对应功能不可见/不可访问
- [ ] Hidden page 不在菜单中显示
- [ ] 全局状态类 perm 不参与 RBAC（仅登记）
