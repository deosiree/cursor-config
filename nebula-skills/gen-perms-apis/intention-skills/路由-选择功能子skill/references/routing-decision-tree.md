# 路由决策树

## 能力缺口 → Feature Skill 映射

```
用户当前状态
├─ 没有盘点文档
│  └─ → 扫描源码权限点与API（先产出盘点）
├─ 有盘点，但要设计权限
│  ├─ 需要人工裁决粒度 → 先提问，再 → 设计权限点与API映射
│  └─ 粒度已明确 → 设计权限点与API映射
├─ 设计已确认，要生成菜单补丁
│  └─ → 生成菜单树权限补丁
├─ 补丁已生成，要合并
│  └─ → 合并权限点到菜单树
├─ 设计已确认，要改源码
│  └─ → 源码集中式权限改动
├─ 缺 pageGate，UI 显示暂无数据 / 要 PageNoPermission
│  └─ → 编排-页面无权限空态落地（意图层）
├─ 扫描暂无数据冒充无权限
│  └─ → 盘点-页面权限空态反模式
├─ 源码已改，要验证
│  └─ → OpenCLI端到端验证
├─ 菜单补丁要导入
│  └─ → 菜单树导入验证
├─ 权限异常，要排查
│  └─ → 权限运行时排障
└─ 不清楚当前该干什么
   └─ → 返回父 agent，进入"分析-perms-apis现状"
```

## 不能路由到功能层的场景

以下场景应返回意图层而非直接进入功能 skill：

| 场景 | 应进入的意图 skill |
|------|------------------|
| 需要多方案比较 | 编排-权限点配置全流程 |
| 权限粒度/豁免/归属需裁决 | 策略-设计权限点 |
| 不确定是否改码还是只出补丁 | 编排-权限点配置全流程 |
| 全流程推进 | 编排-权限点配置全流程 |
| 整页空态策略未决 | 策略-页面权限空态 |
| PageNoPermission 落地编排 | 编排-页面无权限空态落地 |
