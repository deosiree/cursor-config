# 手工自测流程 — 方案 A：8081 直连 + Console 注入权限

> 技能唯一源；目标仓库副本：`{hytestsDir}/docs/workflow.md`（由本文件同步生成，勿在用例 README 重复粘贴全文）。

## 1. 为何不用 8080（子应用用例）

microfb（8080）在 **mock 关闭** 时将 `/dev-api` 代理到真实 `syncloud`。apex 的 vite mock 插件 **仅在 8081** 生效。  
在基座页面测**子应用**异常 UI 会看到真实数据、`code: 0`，误以为 mock 失败。

> **例外**：基座用例（如 3699）在 microfb mock 开启时于 8080 验证，见 [[手工自测流程-8080基座mock.md]]。

## 2. 启用 mock

在目标仓库根目录创建或编辑 `.env.development.local`：

```env
VITE_MOCK_DEV_SERVER=true
```

> `.env.development` 默认 `VITE_MOCK_DEV_SERVER=false`，优先级高于 `.env.local`。必须用 **`.env.development.local`**。

## 3. 启动 dev

```bash
cd apex_dev   # 或 targetRepoProfile 指定的仓库
pnpm dev
```

确认终端为 `http://localhost:8081/`（端口占用时按实际替换下文 URL）。

## 4. Console 注入权限

8081 独立运行无 qiankun 注入 `userInfo`，页面可能显示「暂无页面访问权限」。

打开 **8081** 页面 → DevTools → Console，执行：

```javascript
localStorage.setItem('userInfo', JSON.stringify({
  id: '1',
  userId: '1',
  username: 'admin',
  isOwner: true,
  isSystem: true,
  permissions: [
    'sys:user:query', 'sys:user:add',
    'sys:role:query', 'sys:role:add',
  ],
  roles: ['admin'],
}));
location.reload();
```

`isOwner: true` 时 `checkHasPerm` 直接放行。

### 权限标识不确定 — 人工门禁

若无法从源码稳定推断页面所需 `permissions` / `RoutePermDict`：

1. **停止猜测**，向人类确认权限码列表，或确认是否可用 `isOwner: true` 兜底
2. registry 标注 `perm_status: pending_human`
3. 用例 README 前置条件写「待确认权限」，浏览器步骤标 **blocked**
4. mock 端点可先完成；curl 快验不依赖页面权限

## 5. 场景切换

编辑 `.mock-shared/error-scenario.json`：

```json
{ "active": "3545" }
```

`active` 值对应用例 ID 或 registry 中的 `scenario_active`。保存后 **刷新浏览器**。

## 6. curl 快验

```bash
curl -X POST "http://localhost:8081/dev-api/forward/seccenter/v2/user/list" ^
  -H "Content-Type: application/json" ^
  -d "{\"pagination\":{\"page\":1,\"pageSize\":20}}"
```

期望：`code` 为非 0 的 mock 错误码（如 `40001`），而非真实业务数据。

## 7. 权限仍失败 / 其他故障

| 现象 | 处理 |
|------|------|
| 全是真实数据、`code: 0` | 确认访问 **8081** 非 8080；重启 `pnpm dev` |
| 「暂无页面访问权限」 | 执行第 4 节注入脚本后 reload |
| mock 未加载 | 检查 `.env.development.local` |
| 场景未切换 | 保存 `error-scenario.json` 后刷新 |
| curl 有 mock、页面没有 | 页面是否开在 8080；清缓存重开 8081 |
