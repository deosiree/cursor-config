## 保存闭环样例（P0）

### TC-R1：部分勾选功能项-保存重开-勾选态一致

```json
{
  "name": "编辑角色-部分勾选功能项-保存重开-勾选态一致",
  "steps": "…仅勾 2 项 → 保存 → 再编辑…",
  "expected": "1. 重开仍仅 2 项\n2. 未误全选"
}
```

## 字段对照

| cases 键 | CSV 列 | 说明 |
|---------|--------|------|
| name | 名称 | 页面-场景-期望摘要 |
| precondition | 前置条件 | 登录/测试角色/后加功能项 |
| steps | 测试步骤 | 区分「点击节点」与「勾选复选框」 |
| expected | 用例结果 | 界面语言，含保存重开或用户侧按钮 |
| — | 功能集合 | **强制留空** |

## 设计原则

1. 权限配置用例须含「保存→重开」或「保存→测试用户→按钮生效」之一
2. 禁止仅测「有菜单权限 Tab」
3. 后加功能项、部分勾选各至少一条 P0
