## 字段对照

| cases 键 | CSV 列 | 说明 |
|---------|--------|------|
| name | 名称 | 页面-场景-期望摘要 |
| precondition | 前置条件 | 登录/环境/路径 |
| steps | 测试步骤 | 编号动词列表 |
| expected | 预期结果 | 编号界面语言预期 |
| — | develop结果 | 默认 = 预期结果 |
| — | 功能集合 | **强制留空** |
| — | 用例ID | **留空**（系统分配） |
