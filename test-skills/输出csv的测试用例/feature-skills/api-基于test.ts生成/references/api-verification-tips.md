# API 层测试验证技巧

## 常见验证点

| 测试对象 | 验证方式 |
|---------|---------|
| localStorage | F12 Application → 存储 → 本地存储空间 → 查看键值 |
| 项目下拉默认值 | 进入页面查看下拉框的默认选中项 |
| 缓存写入 | Application → 查看 subAppMenuList 等键值结构 |
| mock 映射 | F12 Network → 查看请求体字段映射是否正确 |

## 与 gateway 层的区分

| API 层 | Gateway 层 |
|--------|-----------|
| 存储/缓存/默认值 | 网络请求/表单回显/权限面板 |
| localStorage 操作 | POST 请求体验证 |
| 项目选中状态 | 树节点字段映射 |
| 清会话行为 | 灰禁/锁定/祖先锁 |

## 用例特点

- 步骤通常更短（2-4 步）
- 前置条件更简单（常不需要环境说明）
- 预期结果偏「存不存在」「对/不对」
