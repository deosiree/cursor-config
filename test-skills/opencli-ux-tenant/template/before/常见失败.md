# 失败态模板：密码未配置

## 错误输出

```
profile「cloud」密码仍为 CHANGE_ME，请在 config/ux-test.config.local.json 中覆盖 password
```

## 根因

远程环境的 password 字段未从 `CHANGE_ME` 替换为真实密码。

## 修复命令

```bash
cp config/ux-test.config.local.json.example config/ux-test.config.local.json
# 编辑该文件，将 profiles.cloud.password 改为真实密码
```

# 失败态模板：验证码超时

## 错误输出

```
等待验证码输入超时（120s），请重试或切换 captchaMode
```

## 根因

profile 的 captchaMode 为 `manual`，但无人值守导致 read 超时。

## 修复方案

- 切换到 `bind-only` 模式：先手动登录后 `--skip-login` 跑测试
- 或在人工值守时重试

# 失败态模板：opencli doctor 未通过

## 错误输出

```
opencli doctor 未通过，请先修复浏览器桥接
```

## 根因

Chrome 扩展未安装或桥接异常。

## 修复命令

```bash
opencli doctor
# 按提示安装/修复 Chrome 扩展
```
