# 模板目录

本目录存放 `opencli-ux-tenant` skill 的典型成功态和失败态模板，供 agent 快速对照。

## 目录结构

```
template/
├── before/       # 失败态 / 问题态 — 常见的失败截图 + 日志 + 根因
├── after/        # 成功态 — 完整的通过输出 + 截图示例
└── README.md
```

## 使用场景

- **诊断失败**时：对照 `before/` 中的模式，快速定位根因
- **验证通过**时：对照 `after/` 中的成功输出，确认测试结果

## 模板类型

| 目录 | 内容 | agent 使用方式 |
|------|------|---------------|
| `before/` | 常见失败截图 + 错误日志 + 根因分析 | 模式匹配：用户的错误输出与哪个模板匹配 |
| `after/` | 完整通过的终端输出 + 截图 | 预期基准：用户的输出是否接近模板 |
