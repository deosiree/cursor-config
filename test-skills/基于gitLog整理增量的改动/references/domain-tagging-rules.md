# 域名标注规则

## 双轨原则

- **全部提交进 Excel**；用「是否主域」列区分惠岩日常主责，**不删非主域行**
- **域名标签**与问题树层级**分离**；问题根=主题，不是域名

## Nebula 默认主域（是否主域=是）

登录鉴权、租户/用户/角色/菜单/个人中心/安全配置、密码框、权限鉴权
