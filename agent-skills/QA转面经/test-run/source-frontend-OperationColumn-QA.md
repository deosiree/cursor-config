# 模拟 QA 上下文（前端 · OperationColumn）

**Q:** 表格操作列按钮太多挤在一起怎么办？  
**A:** 用 OperationColumn，多的收进「更多」下拉。

**Q:** `inline-visible-count` 传 2 和传 5 有什么区别？  
**A:** 是槽位总数，「更多」占 1 槽。2 = 最多 1 个行内按钮 + 更多；5 = 最多 4 个行内 + 更多。若下拉里只剩 1 个，则不显示「更多」，全部行内展示。

**Q:** 和原来 `el-table-column` 里一排 `el-button` 比呢？  
**A:** 旧写法列宽要么写死要么 v-auto-width 抖；新套件用 `list-data-length` 探针读表数据，`calcOpStrip` 统一算行内/溢出，列宽与折叠规则一致。

**Q:** `calcOpStrip` 为什么要单独抽？  
**A:** 行内切分和列宽估宽共用同一套规则，避免 UI 显示 3 个行内按钮但列宽按 5 个估的漂移。

**Q:** 面试里怎么讲这个组件？  
**A:** 强调「槽位语义」不是「可见按钮个数」，以及溢出时何时省略「更多」的边界 case。
