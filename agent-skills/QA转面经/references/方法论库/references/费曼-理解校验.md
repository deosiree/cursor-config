# 费曼 · 理解校验（写后门禁）

> 蒸馏自 `.cursor/role-skills/feynman-skill`（命名≠理解、反自欺、cargo cult）。**不**使用角色扮演或 WebSearch。

## 1. 命名 ≠ 理解

写完一章后自问：

- 能否去掉术语堆叠，用六年级能懂的话复述？
- 换种问法还能答吗？
- 有没有可感知例子（数字、界面、一次调用）？

若只有名词没有机制 → 补机制或删空话。

## 2. 反自欺（cargo cult 检测）

警惕「形式齐全、实质空洞」：

| 货物崇拜 | 合格 |
|----------|------|
| 有对比表但行列无决策信息 | 表驱动选型结论 |
| 有面试钩子但无追问链 | 钩子 + 递进追问 |
| 有代码块但与论证无关 | 代码支撑边界 case |
| 快问快答只背定义 | 每题有应答要点+边界 |

## 3. 写入门禁（写入节点可引用）

- [ ] 至少一处用**具体场景**替代纯定义开场
- [ ] 对比表/选型结论能回答「所以呢」
- [ ] 区分度标准可验证（规则、数字、反例），非「很有经验」
