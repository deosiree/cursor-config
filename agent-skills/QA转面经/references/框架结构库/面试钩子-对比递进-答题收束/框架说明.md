# 框架说明 · 面试钩子-对比递进-答题收束

> structureId = 目录名。样本 .md 保持原文件名，见本目录列表。

## 开场钩子模式

```
面试现场还原 → 具体追问链 → 学员卡住 → 面试官判断
```

特征：

- 用真实面试/业务场景制造张力（不限领域：前端、Agent、协议均可）
- 追问递进：概念 → 场景 → 边界 → 收口判断
- 开篇点明「要澄清的误解」

## 章节组织逻辑

```
本质差异 → 类比化理解 → 架构拆细 → 选型判断 → 为什么重要 → 怎么答题 → 快问快答/总结升华
```

## 技术深度要求

- 对比表（维度≥4）
- 关键处代码或配置片段
- 选型正反例各 1
- 量化或可数规则（槽位、复杂度等）
- 禁止纯 API 罗列

## 答题策略模式

```
分层答题：短结论 + 展开 + 关键数字/规则
追问预测：卷尾 K 题，K = min(max(3, N), 7)
```

## 收束升华模式

```
背答案 vs 做过的人 + 可验证的区分度细节
```
