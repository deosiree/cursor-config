## Agent 怎么用

1. 读目标目录的 `框架说明.md` 作为写作骨架
2. 可选读同目录样本 .md 感受语气与密度（不复制正文）
3. 用户指定 `structureId` 或样本文件名 → 见 `分析-参考框架就绪`

## 入库规则（提炼 feature）

- 判定与已有 structureId **同构** → 仅 copy 原文进该目录，不改文件名
- **新结构** → 新建 `{structureId}/` + `框架说明.md`，再 copy 原文
- 禁止用领域名（如「前端面经」）作为 structureId

## 推荐权重（未指定结构时）

| QA/意图信号 | 提高权重 |
|-------------|----------|
| 面经、面试、追问、对比、怎么答 | 面试钩子-对比递进-答题收束 |
| 复盘、方案、设计点、取舍、实现总结 | 背景-实现-核心-取舍 |

最终须向人类展示 **2～3 个** 推荐并等待选择（见编排步骤 1）。
