# 核心任务

读 `[[../../references/方法论库/SKILL.md]]`，输出本知识点应使用的学习方法。

## 何时触发

- 编排步骤 3，每个知识点写作前

## 输入

- `知识点特征`
- `上下文`（章首/决策点/中间段）

## 流程

```
1. 读 方法论库/SKILL.md 判断优先级
2. 需要细节 → 读 方法论库/references/{方法}.md
3. 输出 method + reason + suggestion
4. 若 method=费曼 → suggestion 注明写后执行 费曼-理解校验.md
```

## 输出

```json
{
  "method": "费曼 | 苏格拉底 | 金字塔 | 不嵌入",
  "reason": "一句话",
  "suggestion": "具体用法"
}
```

## 边界

- 只判断，不写作
- 每知识点最多一种方法

## 使用示例

```text
多术语层级混淆、章中段 → 费曼；写后跑理解校验
选型点 → 苏格拉底
```
