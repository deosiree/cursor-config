# 核心任务

接收已组织的章节内容，按 `框架说明.md` 骨架组装为完整面经文档。

## 何时触发

- `编排-QA沉淀为经验贴` 步骤 4，全部章节完成后

## 输入

- `章节列表`：标题与正文
- `行文框架`：`框架结构库/{structureId}/框架说明.md` 骨架
- `知识关系图`：全景图/关系表
- `方法论嵌入记录`
- `输出路径`
- `N`、`K`、`doc_type`（来自步骤 1.5）

## 文档结构模板

```markdown
---
title: "..."
source: ""
author: "[[知识沉淀]]"
created: {日期}
description: "..."
tags: [...]
knowledge_points: {N}
quick_qa_count: {K}
doc_type: {doc_type}
---

> 前置阅读（如有）

## 开场钩子
{按 doc_type / 行文框架钩子模式}

## 知识点全景图
{关系图}

## 一、…（按框架递进）
…

## 面试怎么答 / 答题策略（如有）

## 快问快答（或 面试追问预测）
共 K 题，每题：追问 → 应答要点

## 总结
背答案 vs 做过的人 + 一句话区分度
```

## 质量门禁

- [ ] 开场钩子已嵌入
- [ ] 至少一张概念关系全景图
- [ ] 至少一张对比表
- [ ] 至少一个正例+一个反例
- [ ] 卷尾快问快答 **K** 题与 YAML `quick_qa_count` 一致
- [ ] 结尾区分度标准
- [ ] 各章有承接引用
- [ ] 若用费曼：已对照 `方法论库/references/费曼-理解校验.md`

## 边界

- 只组装，不创作章节正文
- 框架不适用的章可跳过

## 使用示例

```text
N=5,K=5,doc_type=面经 → 五章+快问快答5题+总结区分度 → 写入指定路径
```
