name: 分析-参考框架就绪
description: 加载框架结构库中的 structureId；未指定时排序推荐2～3个行文框架供人类选择；样本按原文件名定位。
---

# 核心任务

解析 `structureId` 与可选样本 → 加载 `框架结构库/{structureId}/框架说明.md`；未指定时 **推荐后等人选**。

## 何时触发

- `编排-QA沉淀为经验贴` 步骤 1

## 输入

- `structureId`（可选）：如 `面试钩子-对比递进-答题收束`
- `参考样本文件名`（可选）：结构目录下的 .md 原名
- `QA上下文`：用于推荐排序
- `doc_type` / `N`（可选，来自步骤 1.5，若已执行则复用）

## 必读

- `[[../../references/框架结构库/README.md]]`

## 流程 A：用户已指定 structureId

```
1. 确认目录 references/框架结构库/{structureId}/ 存在
2. 加载 框架说明.md → skeleton
3. 若给了样本文件名 → 记录 samplePath（只读语气，不复制内容）
4. 输出 status: loaded
```

## 流程 B：用户指定样本（文件名或关键词）

```
1. 在 框架结构库/**/ 下 glob 匹配 *.md（排除 框架说明.md）
2. 命中唯一 → 取其父目录名为 structureId，加载该目录 框架说明.md
3. 多个命中 → 列出路径请用户选
```

## 流程 C：未指定（推荐-行文框架）

```
1. 读 框架结构库/README.md + 各 框架说明.md
2. 结合 QA、doc_type、关键词 对 structureId 排序
3. 向人类输出 2～3 个推荐（表格格式见下），status: awaiting_choice
4. 收到选择后 → 走流程 A，status: loaded
5. 未收到选择前 → 不进入步骤 2 写作
```

### 推荐输出模板

```markdown
## 推荐行文框架（请选一）

| 推荐序 | structureId | 适用理由 | 目录内样本（可选） |
|--------|-------------|----------|-------------------|
| 1 | … | … | …md |
| 2 | … | … | … |

请回复序号或 structureId；可补充「用某目录下的 xxx.md 当参考」。
```

### 推荐权重（见框架结构库 README）

- 面经/面试/追问/对比 → 提高 `面试钩子-对比递进-答题收束`
- 复盘/方案/设计点/取舍 → 提高 `背景-实现-核心-取舍`

## 输出

```json
{
  "structureId": "面试钩子-对比递进-答题收束",
  "skeletonPath": "references/框架结构库/.../框架说明.md",
  "samplePath": "可选，目录内原文件名.md",
  "status": "loaded | awaiting_choice | need_extract"
}
```

`need_extract`：无匹配结构 → 路由 `提炼-文档参考框架`。

## 边界

- 不做框架提炼、不写正文
- **禁止**按领域（前端/Agent）静默默认 structureId
- 推荐必须 2～3 个，不得只列目录不排序

## 使用示例

```text
用户：沉淀 MCP 讨论成面经（未指定框架）
→ 推荐 1 面试钩子… 2 背景实现… → 等人选 → 加载框架说明

用户：用面试钩子-对比递进-答题收束
→ 直接加载，可选读鹅厂 MCP 样本 md
```
