# 子技能路由决策

## 适用场景

- 需要决定当前轮次调用哪些子节点。
- 需要明确串并行关系、门禁和回退点。

## 核心规则

- 先看父级当前认知、缺失事实和目标范围，再选最小必要路径。
- 若路径选择依赖未确认的边界，先回到人工澄清，不允许硬猜。
- 输出必须包含 `selectedPath`、`parallelGroups`、`rollbackMap` 和 `nextIterationAction`。

## 最小节点契约

- 输入证据：任务意图、仓库现状、当前认知、缺失事实、阶段恢复点。
- 输出结果：本轮节点路径、并行组、门禁、回退方案、待提问问题。
- 失败条件：目标范围本身不清楚，无法稳定选路。
- 人工澄清回退：若选路依赖未确认边界，先提问再重判。

## RED

- 常见失败：默认全链路串行执行、忽略中间态恢复、没有把“先问人”作为路径分支。

## GREEN

- 至少给出一条最小路径、一组门禁和一条失败回退说明。

## REFACTOR

- 若路径仍然过重，继续收缩到最小必要节点。
- 若误触发到普通文档润色任务，收紧 description。

## 使用示例

```text
父级 agent 已完成仓库扫描，但文档范围未完全收敛。
请使用“子技能路由决策”输出本轮最小节点路径；若范围不清楚，先给出要问人的关键问题。
```
