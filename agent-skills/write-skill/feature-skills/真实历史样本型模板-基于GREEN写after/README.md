# 真实历史样本型模板-基于GREEN写after

## 作用
把真实修复后的成品态落成 `template/after`，防止 `after` 继续停留在说明壳。

## 资源入口
- 模板：`[[template/README.md]]`
- few-shot：`[[assets/few-shot-example/README.md]]`
- 校验：`[[evals/evals.json]]`

## 使用示例
```text
这个节点现在只有 after 的目标描述，没有真实成品样本。
使用 $真实历史样本型模板-基于GREEN写after 把修复后的真实结果落成 template/after。
```
