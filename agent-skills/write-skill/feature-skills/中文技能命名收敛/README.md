# 中文技能命名收敛

## 作用
统一 skill 套件中的节点命名，让名称直接表达功能职责，而不是保留提交顺序、英文占位或模糊中间层名称。

## 适用场景
- 节点名称像过程记录，不像长期节点名。
- 主 skill、README、template 和 few-shot 对同一节点使用了多种叫法。
- 当前名称让人无法判断该节点补的到底是哪一种能力。

## 与相邻节点边界
- 只改命名，不直接删结构。
- 若中间层本身无职责，继续配合 `[[../子skill上提与中间层删除/SKILL.md]]`。
- 若问题是 frontmatter 或文案润色，不应把所有问题都归入命名收敛。

## 资源入口
- 模板：`[[template/README.md]]`
- few-shot：`[[assets/few-shot-example/README.md]]`
- 校验：`[[evals/evals.json]]`

## 使用示例
```text
这些节点名现在更像提交备注，而不是长期维护的中文 skill 名。
使用 $中文技能命名收敛 给出中文命名方案，并标出需要同步修改的引用点。
```
