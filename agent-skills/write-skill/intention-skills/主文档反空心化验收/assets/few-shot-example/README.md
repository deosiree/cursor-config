# few-shot：主文档反空心化验收

## 作用
展示一次真实更新型闭环：一个 feature 节点先被判定为空心化，再回流修复，最后重新通过验收。

## 闭环步骤
1. 输入
   - 一个结构齐全，但主 `README.md` / `SKILL.md` 缺关键段落或示例的 feature
2. 判定
   - 输出 `needs_fix`
   - 指出缺的是任务、输入、输出、边界、示例还是分层关系
3. 回流
   - 根据缺口回流到对应修复 feature
4. 复验
   - 输出 `pass`

## 使用示例
```text
这个 feature 的模板和 few-shot 很多，但主文档读起来还是像空壳。
使用 $主文档反空心化验收 先判空心化，再输出需要回流的修复 feature。
```
