# 主文档反空心化验收 模板说明

这个 intention 只承接更新型门禁，因此模板直接收平为 `before` / `after`。

## 真实模板位置
- `[[before/README.md]]`
- `[[after/README.md]]`
- `[[after/sample-node/README.md]]`

## 如何阅读
1. 先看 `before`
   - 这是当前节点自身允许保留的空心问题态。
2. 再看 `after`
   - 这不是抽象解释，而是带有真实 sample node 的成品态。
3. 最后回到主节点
   - 判断当前门禁输出和回流映射是否与模板证据一致。
