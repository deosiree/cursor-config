# i18n-server 套件级 few-shot

这是一个“继续拆成 intention-skills / feature-skills，并把真实历史版本回填为模板与 few-shot”的真实套件案例。

## 本目录怎么看

- `add-skill/`
  观察新增型模板的真实 `mvp/snapshot`
- `update-skill/`
  观察更新型模板的真实 `before/after`
- `extracted-subskills/`
  观察意图层与功能层的真实节点实现

## 适合被哪些节点复用

- `迁移-拆分意图层与功能层`
- `中文技能命名收敛`
- `历史版本回填为few-shot`
- `references与evals补全`
- `模板类型判定` 的 `update-skill` 来源说明
