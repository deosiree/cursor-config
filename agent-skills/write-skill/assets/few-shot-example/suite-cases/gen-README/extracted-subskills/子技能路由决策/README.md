# 子技能路由决策

本目录是“基于源码生成文档”父级 agent 的路径选择节点。本 skill 采用“本地中文模式” frontmatter。

本节点按“新增型 skill”维护，真实模板位于 `template/mvp/` 与 `template/snapshot/`，内容直接拆自父级 `template/microfb/` 全量任务案例。

- 上游：父级当前认知、仓库扫描结果、缺失事实
- 下游：架构拓扑映射、源码符号定位、文档结构规划、源码证据抽取、文档内容生成等
- 关键职责：选路、定并行、定门禁、定回退、识别是否必须先问人

使用示例：

```text
基于当前任务意图与缺失事实，输出本轮最小节点路径和必须提问的人类问题。
```
