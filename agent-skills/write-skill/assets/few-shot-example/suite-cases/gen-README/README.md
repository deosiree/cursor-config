# gen-README 套件级 few-shot

这是一个“旧 skill 升级为父级 agent + 同级子skill”的真实套件案例。

## 本目录怎么看

- `add-skill/`
  放真实模板片段，适合观察新增型结构
- `update-skill/`
  放根级入口文件的真实片段，适合观察主 skill 被瘦身后的写法
- `extracted-subskills/`
  放真实子skill 套件，适合观察下沉后的职责边界

## 适合被哪些节点复用

- `迁移-主skill改造为agent`
- `子skill上提与中间层删除`
- `主SKILL瘦身与下沉`
- `模板类型判定` 的 `add-skill` 来源说明
