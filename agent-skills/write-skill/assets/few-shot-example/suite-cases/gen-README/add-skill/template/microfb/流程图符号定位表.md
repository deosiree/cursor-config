# microfb（基座）MVP：流程图符号定位表（源码 → 变量/函数）

本文档目标：把 `docs/mvp` 中 **拓扑图 / 运行时图 / 状态图**出现的关键“符号”（变量、常量、函数、store 字段）定位到 **源码文件 → 导出名 → 读写点**，便于快速掌握源码。

> 约定：以下“路径”均以 `microfb/` 为根；导出名按源码真实导出。

## 1. 路由与路径常量（入口/白名单/子应用根）

- **ROOT_PATH (`"/"`)**
  - **定义**：`src/constants/navigation-paths.ts` → `export const ROOT_PATH`
  - **使用**：`src/plugins/permission.ts`（入口路径判断、redirect 兜底）

- **LOGIN_PATH (`"/login"`)**
  - **定义**：`src/constants/navigation-paths.ts` → `export const LOGIN_PATH`
  - **使用**：`src/plugins/permission.ts`（白名单、入口判断、redirectToLogin）
  - **使用**：`src/store/modules/user/user.store.ts`（路由回退、logout 后本地兜底）

- **LOGIN_VERIFY_PATH (`"/login/verify"`)**
  - **定义**：`src/constants/navigation-paths.ts` → `export const LOGIN_VERIFY_PATH`
  - **使用**：`src/plugins/permission.ts`（白名单、特殊放行）

- **APEX_ROUTE_ROOT (`"/Apex"`)**
  - **定义**：`src/constants/route-paths.ts` → `export const APEX_ROUTE_ROOT`
  - **使用**：`src/plugins/permission.ts`（入口路径判断：直连 `/Apex`）
  - **使用**：`src/store/modules/appConfig.store.ts`（子应用 activeRule、fallback 生产入口）

- **OPSDECK_ROUTE_ROOT (`"/Opsdeck"`)**
  - **定义**：`src/constants/route-paths.ts` → `export const OPSDECK_ROUTE_ROOT`
  - **使用**：`src/plugins/permission.ts`（入口路径判断）
  - **使用**：`src/store/modules/appConfig.store.ts`（子应用 activeRule）

- **APEX_STATIC_ENTRY (`"/Apex?isSubApp=true"`)**
  - **定义**：`src/constants/route-paths.ts` → `export const APEX_STATIC_ENTRY`
  - **使用**：`src/plugins/qiankun/apps.ts`（dev 下 static entry 兜底）
  - **关联**：`vite.config.ts` 的 `serveApexDistForQiankunDev()` 会在 dev server 上复刻 `/Apex*` 静态入口（用于绕开 `@vite/client` 冲突）。

- **DEFAULT_HOME_PATH（默认首页）**
  - **定义**：`src/utils/menu.ts` → `export const DEFAULT_HOME_PATH`
  - **来源**：默认指向 `APEX_DASHBOARD_PATH`（`src/constants/route-paths.ts`）
  - **使用**：`src/plugins/permission.ts`、`src/store/modules/user/user.store.ts`

## 2. Base / 部署路径相关（history.base 与登录路径拼接）

- **getAppBase()**
  - **定义**：`src/gateway/route-base.gateway.ts` → `export function getAppBase`
  - **使用**：`src/router/index.ts`（`createWebHistory(getAppBase())`）
  - **关联**：`vite.config.ts` 也有 `normalizeAppBase()`（构建/预览 base）；运行时路由以 `getAppBase()` 为准。

- **stripBasePath(rawPath)**
  - **定义**：`src/plugins/permission.ts`（文件内私有函数）
  - **用途**：去掉 `history.base` 后再做白名单/入口判断，避免 `/cloud` 等前缀干扰业务路径判定。

- **getLoginPath()**
  - **定义**：`src/gateway/route-base.gateway.ts` → `export function getLoginPath`
  - **用途**：拼接 `${base}${LOGIN_PATH}`，供“构造云端登录地址”使用（间接被 `buildHostLoginUrl` 使用）。

## 3. “是否已登录”与会话语义

- **Auth.isLoggedIn()**
  - **定义**：`src/utils/auth.ts` → `export class Auth { static isLoggedIn(): boolean }`
  - **判定**：Cookie-Session 下以本地 `Storage.get("userInfo")` 是否存在 `id/username` 作为登录态信号。
  - **使用**：`src/plugins/permission.ts`（路由守卫拦截）

- **Storage（userInfo）**
  - **读写点**：
    - 写：`src/store/modules/user/user.store.ts`（`finalizeV2Login` / `resetUserState`）
    - 读：`src/utils/auth.ts`（`isLoggedIn`）、`src/plugins/qiankun/apps.ts`（透传到子应用 props）

## 4. 菜单缓存（menuList/menuVersion）与首个菜单落点

- **readMenuCache() / writeMenuCache() / clearMenuCache() / getMenuVersion()**
  - **定义**：`src/services/menu/menu-repo.ts`
  - **语义**：
    - `readMenuCache`：从 localStorage 读菜单并计算 version
    - `writeMenuCache`：唯一写入口，更新版本并派发 `menuListUpdated` 事件
    - `clearMenuCache`：清空并重置版本信号
    - `getMenuVersion`：返回内存中的版本号
  - **使用**：
    - `src/plugins/permission.ts`：入口菜单落点计算
    - `src/store/modules/permission.store.ts`：v2 菜单路径下生成动态路由
    - `src/store/modules/user/user.store.ts`：登录后置写入/登出清理/刷新菜单
    - `src/plugins/qiankun/apps.ts`：props() 动态读取并透传

- **findFirstValidMenuPath(menus)**
  - **定义**：`src/utils/menu.ts` → `export function findFirstValidMenuPath`
  - **使用**：
    - `src/plugins/permission.ts`：入口路径（`/`、`/Apex` 等）重定向到首个可用菜单
    - `src/store/modules/user/user.store.ts`：登录后置跳转策略与路由失效回退

## 5. 动态路由生成与注入（routesLoaded / generateRoutes / addRoute）

- **PermissionStore.routesLoaded**
  - **定义**：`src/store/modules/permission.store.ts` → `const routesLoaded = ref(false)`
  - **写入点**：
    - `generateRoutes()` 成功后置为 `true`
    - `resetRouter()` / 异常时置为 `false`
  - **读取点**：
    - `src/plugins/permission.ts`：判断是否需要生成并注入动态路由
    - `src/store/modules/user/user.store.ts`：菜单更新后是否需要 reload 动态路由

- **PermissionStore.generateRoutes()**
  - **定义**：`src/store/modules/permission.store.ts`
  - **策略**：
    - `isV2Enabled("menu")` 为 true：直接读取 `readMenuCache().menus` 并构建路由
    - 否则：调用 `RoleGateway.getRoleMenuList` 回退 v1

- **router.addRoute(route)**
  - **调用点**：`src/plugins/permission.ts` → `generateAndAddRoutes()`
  - **说明**：守卫仅在 `routesLoaded=false` 时批量注入动态路由，之后用 `next({ replace: true })` 重新进入当前路由。

- **并发互斥：isGeneratingRoutes / waitForRoutesGeneration()**
  - **定义**：`src/plugins/permission.ts`（文件内局部变量与函数）
  - **用途**：避免多个并发导航重复生成路由；最多等待 5s 兜底放行。

## 6. 登录后置初始化（finalizeV2Login）与子应用同步

- **UserStore.loginV2(payload)**
  - **定义**：`src/store/modules/user/user.store.ts`
  - **流程**：`AuthGateway.loginV2` → 若 `mfaRequired` 则提前返回 → 否则 `finalizeV2Login(res, { redirectToMenu: true })`

- **UserStore.finalizeV2Login(res, options)**
  - **定义**：`src/store/modules/user/user.store.ts`
  - **核心副作用**：
    - 写 `Storage.set("userInfo", normalizedUserInfo)`
    - 生成/兜底菜单树并 `writeMenuCache(normalizedMenus)`
    - 遍历 `getPersistedAppConfigs().filter(enabled)`，对每个子应用调用 `setMicroAppProps(app.name, { menuList, menuVersion, userInfo })`
    - 跳转首个菜单：`router.push(firstMenuPath || DEFAULT_HOME_PATH)`

- **setMicroAppProps(appName, partialProps)**
  - **定义**：`src/plugins/qiankun/apps.ts` → `export const setMicroAppProps`
  - **语义**：更新“下次子应用挂载时的 props 来源”（本质是写 menuCache 与 userInfo storage）。

## 7. qiankun 注册与 props（微前端核心符号）

- **registerApps()**
  - **定义**：`src/plugins/qiankun/apps.ts` → `export const registerApps`
  - **调用点**：`src/main.ts`（`router.isReady().then(registerApps)`）
  - **行为**：
    - 非 dev：`appConfigStore.loadConfig()` 拉取并持久化子应用配置
    - `buildApps()` 根据持久化配置构建注册列表
    - dev：`applyApexDevAutoFallback()` 按连通性选择 Apex dynamic/static entry
    - `registerMicroApps(apps)` + `start({ prefetch: true, singular: false })`

- **getAppProps(appName, routerBase)**
  - **定义**：`src/plugins/qiankun/apps.ts`（文件内函数）
  - **透传字段**：`menuList/menuVersion/userInfo/routerBase` + globalState 通道（actions）
  - **读来源**：`readMenuCache()`、`Storage.get("userInfo")`

## 8. API 网关分流（executeWithVersionFallback）

- **executeWithVersionFallback()**
  - **定义**：`src/gateway/gateway-executor.ts` → `export async function executeWithVersionFallback`
  - **使用**：`src/gateway/*.gateway.ts`（如 `auth.gateway.ts` / `menu.gateway.ts` / `role.gateway.ts`）
  - **用途**：统一封装 v1/v2 实现选择与降级策略，让业务层只依赖 gateway。
