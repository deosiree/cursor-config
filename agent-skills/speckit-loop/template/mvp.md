# MVP 样例：列表筛选默认值

> 说明性虚构示例。展示 small 流程，不构成项目历史记录。

## 请求

“管理列表默认只显示启用项；用户可切换显示全部。”

## 门禁判断

- taskSize：small
- 范围：单页面筛选状态，无 API、持久化或权限变化。
- 待确认：刷新后是否保留筛选；若仓库现有交互已定义则沿用并注明来源。

## 精简 Spec

- 启用页面时默认选择“启用”。
- 用户切换“全部”后显示启用和停用记录。
- 过滤无结果时显示现有空状态。
- 非目标：新增后端过滤接口、保存用户偏好。

## 验收与证据

- 默认状态下停用项不显示。
- 切换后两种状态都显示。
- 执行对应组件测试并核对 diff；按仓库可用命令报告真实结果。

## 完成边界

无需创建 Constitution 或完整 Plan；若发现 API 或持久化变化，则升为 medium 并补齐相应阶段。
