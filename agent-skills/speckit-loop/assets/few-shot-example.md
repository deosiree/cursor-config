# Few-shot：设置页批量停用

本例为说明性虚构场景，用于展示路由与回流；不是历史项目记录。

## 用户请求

“设置页增加批量停用，并保留操作记录，先确认边界再实施。”

## 路由结果

- medium：涉及列表、状态变更和审计记录。
- 先询问权限、部分成功时处理、审计字段与撤销要求。
- Spec 写批量范围、可观察状态、失败处理、非目标；Clarify 未确认权限策略时阻塞。
- Plan 分任务：审计契约、服务端状态操作、界面交互、异常测试；服务端契约冻结后再并行界面实现。

## 收敛回流

Converge 发现“部分失败时继续处理”没有测试。先对照 Spec：已定义则回实现任务补测试；未定义则回需求澄清。只有复验通过且用户确认交互与风险后才报告完成。
