# Darwin 最终评估与停止建议

## 结论

第三轮两位独立评审均高于 85 分：90.0 和 87.3（百分制归一化）。保守采用较低分 87.3，达到目标；建议当前收手，不为凑更多分数继续改写技能。

## 评估记录

Darwin 九维权重合计为 99。原始加权分为 Σ（维度分 × 权重）；百分制归一化分为原始加权分 ÷ 99 × 100。

| 轮次 | 评审 | 原始加权分 | 归一化分 | 模式 | 决策 |
|---|---|---:|---:|---|---|
| Baseline | A | 82.7/99 | 83.5 | dry-run | 继续优化 |
| Baseline | B | 79.3/99 | 80.1 | dry-run | 继续优化 |
| 第一轮 | A | 85.2/99 | 86.1 | dry-run | 保留 |
| 第一轮 | B | 82.0/99 | 82.8 | dry-run | 保留并继续 |

第三轮相对第一轮较低评审提高 4.5 分。两位评审在配对试跑中均判定三条用例符合预期。

## 关键改进

- 增加 small/medium/large 流程密度及敏感批量导出准入问题。
- 固定需求澄清中的字段、授权、审计、范围、时区、限额、格式和部分失败检查。
- 增加删除/不可逆操作执行前后的证据门槛。
- 增加阶段放行清单、结构化输出和已安装 Spec Kit 节点映射。
- 区分阶段命令未安装与调用失败；失败时停止并进入 Human Loop。
- paired trial 显示，小任务保持轻量，高风险删除不再由代理自行定义规则，批量导出在范围/权限未确认前不输出可执行计划。

## 最高价值的后续优化点

如果未来确有运行时接入需求，最值得补的是 D8 外部效度：在真实仓库用可安全丢弃的 fixture，调用真实可用的 Spec Kit 阶段技能，检查文档产物、测试证据和失败回流。高风险删除只做隔离环境 dry-run 与恢复演练，不触碰真实账号数据。

目前没有必要仅为评分继续投入：现有 paired trial 覆盖三条合成提示，目标阈值已通过。应等真实运行时或项目使用暴露具体失败后，再围绕该失败补一条回归用例，而非继续扩写通用规则。

## 限制

- paired trial 是两个隔离 Agent 生成的回复对照，不是 Spec Kit 运行时集成、真实仓库代码测试或真实导出/删除操作。
- 样本只有三条；分数是 Rubric 评审信号，不证明所有 runtime 和领域都有效。
- 最终评分存在评审分歧，报告按较低的 87.3 作为停止依据。
