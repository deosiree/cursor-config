# Feature Skills（功能层）

功能层提供可复用的原子能力，由 intention skills 调度。

## 可用 Features

### 扩展目录复制
生成跨平台的扩展目录复制脚本。

**输入**：源/目标编辑器，路径  
**输出**：复制脚本，扩展清单

### 兼容性检测
引导用户人工检查扩展视图，识别失效扩展。

**输入**：目标编辑器名称  
**输出**：失效扩展列表路径

### 失效扩展分析
解析失效扩展的 package.json，生成详细报告。

**输入**：失效清单路径，目标扩展目录  
**输出**：详细报告，扩展 ID 列表

### 冗余扩展识别
交互式列出扩展，引导用户选择要删除的冗余扩展。

**输入**：目标扩展目录，筛选模式  
**输出**：用户选择的删除清单

### 清理脚本生成
根据删除清单生成批量清理脚本。

**输入**：要删除的扩展列表  
**输出**：清理脚本，删除日志
