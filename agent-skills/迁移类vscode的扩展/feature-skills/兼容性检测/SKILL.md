# 功能
提供清晰的人工检查指引，帮助用户识别扩展迁移后的兼容性问题。

## 检查流程

### 步骤 1：启动目标编辑器
```text
请启动 {targetEditor}（如 Kiro），等待 10-15 秒让扩展完全加载。
```

### 步骤 2：打开扩展视图
```text
按快捷键打开扩展视图：
- Windows/Linux: Ctrl+Shift+X
- macOS: Cmd+Shift+X

或者通过菜单：查看 → 扩展
```

### 步骤 3：识别问题扩展
引导用户查找以下标记：

| 标记 | 含义 | 处理建议 |
|-----|------|---------|
| ⚠️ 黄色警告 | 扩展可用但有兼容性问题 | 记录下来，可选重装 |
| ❌ 红色错误 | 扩展无法加载 | 必须重装或放弃 |
| 🔄 "需要重新加载" | 扩展需要重启编辑器 | 先完成检查再重启 |
| 灰色禁用状态 | 扩展未启用 | 检查是否为 Workspace 专用扩展 |

### 步骤 4：记录失效扩展
```text
请将失效扩展的完整文件夹名记录到文本文件中。

示例记录格式（保存为 failed-extensions.txt）：
esbenp.prettier-vscode-10.1.0
dbaeumer.vscode-eslint-2.4.2
ms-python.python-2024.0.0

注意：
1. 每行一个扩展
2. 使用完整文件夹名（包含版本号）
3. 可以从扩展详情页复制 ID，然后加上版本号
```

### 步骤 5：提交失效清单
```text
完成记录后，请告诉我：
1. 失效扩展文件的路径（如 "D:\failed-extensions.txt"）
2. 或直接粘贴失效扩展列表

然后我会为你分析这些扩展并提供重装建议。
```

## 常见兼容性问题

### 问题 1：扩展显示"不兼容"
**原因**：编辑器版本与扩展要求的最低版本不匹配  
**解决**：在目标编辑器市场搜索该扩展的兼容版本

### 问题 2：扩展无法激活
**原因**：依赖其他扩展或系统组件  
**解决**：检查扩展详情页的依赖项，先安装依赖

### 问题 3：扩展签名验证失败
**原因**：直接复制破坏了扩展签名  
**解决**：从扩展市场重新安装该扩展

### 问题 4：扩展功能异常
**原因**：编辑器 API 差异导致部分功能不可用  
**解决**：查看扩展更新日志，或联系扩展作者

## 输入
- `targetEditor`: 目标编辑器名称

## 输出
- 人工记录的 `failed-extensions.txt` 文件路径或内容

## 使用示例
```text
Agent 提示：
"扩展已复制完成。现在请启动 Kiro，按 Ctrl+Shift+X 打开扩展视图，
滚动查看所有扩展，将有警告或错误的扩展名记录到文本文件中。"

用户完成后回复：
"我记录了 3 个失效扩展，保存在 D:\failed.txt"
```
