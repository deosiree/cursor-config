# Intention Skills（意图层）

意图层负责流程编排，根据用户场景调度对应的 feature skills。

## 可用 Intentions

### 一次性迁移
从源编辑器一次性完整迁移扩展到目标编辑器。

**适用场景**：
- 首次迁移到新编辑器
- 更换开发环境
- 恢复扩展环境

**关键特征**：
- 完整的生命周期（复制 → 验证 → 分析 → 清理）
- 有备份和回滚机制
- 人工验证和决策点

### 持续同步（待实现）
在多个编辑器之间定期或触发式同步扩展。

**适用场景**：
- 同时使用多个编辑器
- 需要保持扩展环境一致

**关键特征**：
- 增量同步（仅同步变化）
- 冲突检测和解决
- 定时任务或文件监控

### 批量部署（待实现）
为团队或多台机器批量安装统一的扩展集。

**适用场景**：
- 团队环境标准化
- 新机器快速配置
- CI/CD 环境搭建

**关键特征**：
- 扩展清单管理
- 批量安装脚本
- 安装日志和验证
