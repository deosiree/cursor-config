# 核心任务
生成批量安装脚本，在多台机器上部署统一扩展环境。

## 何时触发
- `migrationMode` 为 `batch`
- 用户提到"团队"、"批量"、"多台机器"等关键词

## 前置条件
- 已有标准扩展清单
- 目标机器已安装相同编辑器
- 有网络访问扩展市场（或本地 VSIX 文件）

## 流程设计（待实现）

### 方案 1：扩展市场安装
1. 导出扩展 ID 清单
2. 生成批量安装脚本：
   ```powershell
   code --install-extension ext1
   code --install-extension ext2
   ...
   ```
3. 分发脚本到目标机器
4. 执行并收集日志

### 方案 2：本地 VSIX 分发
1. 导出所有扩展为 .vsix 文件
2. 打包成压缩包
3. 分发到目标机器
4. 生成批量安装脚本（从 VSIX）

### 方案 3：网络共享目录
1. 复制扩展到网络共享目录
2. 生成脚本指向共享目录
3. 各机器从共享目录复制

## 输出
- 扩展清单（JSON/TXT）
- 批量安装脚本（PowerShell/Bash）
- 部署指南
- 验证脚本
