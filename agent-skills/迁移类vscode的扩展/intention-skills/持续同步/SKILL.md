# 核心任务
实现编辑器之间的扩展持续同步机制。

## 何时触发
- `migrationMode` 为 `continuous`
- 用户表示需要"保持一致"、"同步"、"双向"等意图

## 前置条件
- 已明确源和目标编辑器
- 两个编辑器都已安装
- 用户允许自动同步或定期同步

## 流程设计（待实现）

### 方案 1：定时同步
1. 生成定时任务脚本（Windows Task Scheduler / cron）
2. 定期检测扩展差异
3. 自动同步新增/删除的扩展
4. 记录同步日志

### 方案 2：文件监控
1. 监控扩展目录变化
2. 检测到变化后触发同步
3. 增量复制新增扩展
4. 删除已卸载的扩展

### 方案 3：手动触发
1. 生成同步脚本
2. 用户决定何时执行
3. 显示差异预览
4. 确认后执行同步

## 冲突处理
- 同一扩展的不同版本 → 保留较新版本
- 仅一方存在的扩展 → 复制到另一方
- 用户手动删除的扩展 → 询问是否同步删除

## 输出
- 同步脚本
- 同步日志
- 差异报告
