# 旅程：工作台导入到Excel人工译再到更新翻译与归档回写（摘录）

> journey_id: `J-EXCEL-LOOP`  
> 单模块 SOP 只覆盖一跳；本文件强调**模块切换与数据交接**。

## 前置条件

1. 已登录；侧栏可见「工作台」「词条管理」。  
2. 「配置管理」已下发任务；工作台「待办事项」能看到该任务。  
3. 证据：`translation/src/views/workbench/index.vue`、`entry/productEntry.vue`。

## 步骤（端到端）

### 步骤1：工作台 · 词条导入

**模块**：工作台。流程操作区点「导入」，打开「词条导入」（`importModal.vue`）。

交接物：任务内已有待审核/已导入词条（库内状态），不是 Excel 文件。

### 步骤2：工作台 · 词条审核

流程区点「词条审核」（`examineModal.vue`）。

交接物：词条状态达到可进入翻译/导出的审核进度。

### 步骤3：词条管理 · 批量选择与导出

**模块切换**：工作台 → 词条管理。使用「批量选择 / 已选词条」导出 Excel。

交接物：线下 Excel 文件。

### 步骤4：词条管理或工具箱 · 更新翻译

回填后进入工作台「翻译审核」，再「归档」或已选词条回写。

## 模块切换

工作台（导入/审核）→ 词条管理（已选/导出/更新翻译）→ 工作台（翻译审核/归档）→ 可选工具箱。

## 失败

- 未选 IP：`请选择IP！`  
- 未勾选保存：`请勾选需要保存的词条！`  
（文案须与 Vue `message.*` 一致。）

`importModal.vue`、`examineModal.vue`、`productEntry.vue`、`BackFillModal_v3` / `modal_v3.vue`、归档相关 modal。
