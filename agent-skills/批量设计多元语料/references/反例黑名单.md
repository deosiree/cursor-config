# 反例黑名单

执行本套件时以下行为视为 **RED**，不得作为达标手段。

## 验收作假

1. 人工勾选 GOALS / 矩阵单元格宣称 PASS  
2. 不跑门禁脚本，只报「文件很多了」  
3. 把脚本 `--skip-shots` 的跳过写成「截图已齐」

## 内容作假

4. 臆造按钮、菜单、弹窗文案（源码搜不到且未标动态）  
5. 「附录 / 加厚 / 召回填充」类垫字计入体积或篇数  
6. 同一段 FAQ 改标题复制成多篇凑 `MIN_MD_FILES`  
7. 金标同一问复制 N 行充 test/runtime

## 结构偷懒

8. 只有单模块 SOP/FAQ，无跨模块旅程或旅程无「模块切换」  
9. atoms 短片冒充旅程深度，主旅程空洞  
10. 矩阵 path 指向不存在文件仍标绿

## 截图与安全

11. 覆盖人类已拍摄截图路径  
12. 把密钥、生产口令、真实客户数据写入语料或 raw  

## 阈值作弊

13. 静默降低 `MIN_*` 使脚本变绿且不升/说明版本  
14. 升严阈值却不 bump `EVAL_GATES` 版本号  
15. 恢复 deprecated 垫字文件「临时过门」
