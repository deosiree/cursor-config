# 沉淀新协作方案

## 任务

把可重复的研发协作做法整理为包含角色、参数、门禁和验收的方案注册项。

## 输入

用户确认的目标、阶段角色、宿主与模型、交接契约、失败条件、测试和样本。

## 输出

候选方案、注册表差异、样本与回归用例，以及实际验证结果。

## 边界

方案必须在获批后才写入；默认方案变更单独确认。批处理 HTTP API 并发由兄弟 [多模型并发调度](../../../多模型并发调度/SKILL.md) 负责。

## 示例

新增模型备用链路时，先定义触发切换和授权边界；若备用模型能力尚未验证，就保留为提案，不更新默认方案。

入口：[SKILL.md](SKILL.md)，字段规则：[方案编写指南](../../references/scheme-authoring-guide.md)。
