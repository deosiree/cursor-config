# 扩展新 Agent 适配 Loop

## 任务

把未知宿主从“未支持”推进到有证据、可复测的适配提案；能力未验证时维持未支持状态。

## 输入

宿主名称与版本、运行平台、当前可见工具/CLI 证据、注册表和低风险烟雾任务。

## 输出

探测证据、适配提案、经过批准的最小实现、烟雾结果或明确的 STOP 报告。

## 边界

修改前必须通过 🔴 CHECKPOINT；最多两轮无进展。不能取得真实能力证据、需要用户密钥或异步链路未验证时，不登记为已支持。

## 示例

新 Agent 只有 --help 输出而无委派接口时，记录该事实并要求下一步探测授权。第二轮仍无接口就 STOP，不修改 agents-registry.json。

入口：[SKILL.md](SKILL.md)，数据契约：[适配器规范](../../references/agent-adapter-spec.md)。
