# 执行 T3 Code 分模型委派

## 任务

按登记方案委派研发工作，并由当前主 Agent 等待通知和独立验收。

## 输入

已选方案、实时能力检查、完整计划与验收、文件所有权和本次明确授权。

## 输出

委派请求 ID、改动文件清单、测试和静态检查的真实结果、未验证项、最终状态。

## 边界

原生工具优先；ACP 脚本只在环境验证通过时使用。缺少工具或环境就停止，不静默降级。异步模式等待完成通知，不轮询子任务状态。

## 示例

按 S-01 委派 src/menu/ 实现任务，复核其差异并复跑 npm test -- src/menu。通过才报告完成；失败或仍等待时如实记录。
