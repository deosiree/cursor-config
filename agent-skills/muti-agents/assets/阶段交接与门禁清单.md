# 阶段交接与门禁清单

## 派发前

- [ ] 探测宿主并展示不含敏感值的结果。
- [ ] 用户确认当前 Agent；注册表和本会话工具均支持目标传输。
- [ ] 方案 ID、目标角色、模型、隔离和执行模式均已展示。
- [ ] 计划、文件所有权、禁止操作和验收命令齐全。
- [ ] 简报不含令牌、密钥、私人绝对路径或无关上下文。
- [ ] 🔴 CHECKPOINT 获得对本次任务和范围的明确授权。

## 交接时

- [ ] 只发送已确认的任务简报。
- [ ] 记录请求 ID、目标宿主和所用传输。
- [ ] 异步任务等待完成通知；不轮询子任务状态。
- [ ] 环境缺失或子进程失败时保留错误码与安全说明，不尝试静默降级。

## 验收时

- [ ] 核对实际改动文件是否属于批准范围。
- [ ] 检查差异内容，不只读取执行者的文字摘要。
- [ ] 复跑计划要求的测试和静态检查，记录完整退出状态。
- [ ] 区分通过、失败、跳过和未验证项。
- [ ] 只有全部验收要求有证据时才报告 complete。
