# 选择多 Agent 协作方案

## 任务

把注册方案转成可比较的选择项，由用户决定是否采用及采用哪一个。

## 输入

已确认的宿主 ID、实时能力、研发任务、方案注册表和验收要求。

## 输出

可用方案表、用户选择的方案 ID、下一步动作和未决问题。

## 边界

默认方案只是注册表提示，不代表用户选择或批准委派。当前宿主不支持的方案不可选。本节点不会修改方案或执行任务。

## 示例

展示 S-01 的 Plan → Exec → Verify 角色及模型、共享隔离和异步模式，并询问用户选择 S-01、单 Agent 处理还是新建方案。
