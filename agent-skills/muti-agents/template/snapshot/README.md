# 脱敏运行快照

本目录保留已发生的协作案例结构，帮助复核方案、证据和边界。样本描述的是记录当时的执行结果；复用时仍须重新检查当前环境、工具和分支状态。

## 输入

已确认的方案、委派简报、实际子任务结果和验证输出。

## 输出

带来源、时间范围、改动、证据、限制和复验建议的运行记录。

## 边界

不记录令牌或私有路径；样本中的历史结果不等于当前分支的验证结果。假设示例必须标为假设。

## 示例

I-01 记录展示 S-01 分配的计划、实现、验收角色，并引用当时已有的 8/8 脚本回归结果；执行新的委派前须按当前状态重跑检查。
