# 委派简报

## 任务

向目标 Agent 提供足够且最少的上下文，让它完成一个可独立验收的工作单元。

## 输入

- 任务与完成定义：
- 已确认计划：
- 目标宿主 / provider / model / role：
- 可修改路径：
- 禁止操作：
- 环境前提：
- 验收命令与预期证据：
- 用户授权范围：

## 输出

改动文件清单、实现摘要、测试命令/退出码/摘要、未验证项、阻塞问题。

## 边界

只使用本次批准的路径和动作。没有完成通知时不可报告完成。不得包含密钥、无关个人数据或本地用户绝对路径。

## 示例

任务：按计划修复菜单状态映射。只修改 src/menu/；禁止提交和推送；完成后运行 npm test -- src/menu，提供 git diff --stat 和测试退出码。用户已批准本次委派。
