# MVP 模板

适用于一次范围清晰、需要单次协作验证的任务。复制需要的模板到任务记录位置，填写后在 🔴 CHECKPOINT 展示给用户；不要把本目录当作自动授权来源。

## 输入

计划、角色和目标模型、批准写入路径、禁止操作、测试命令。

## 输出

确认过的 Agent 检查记录与委派简报。

## 边界

模板中的占位符必须替换或明确标注缺失；不得填入密钥和个人绝对路径。测试结果由实际命令产生。

## 示例

delegation-brief.md 写明只允许修改 src/menu/，agent-check-record.md 记录探测到的宿主和确认人，再把两份内容作为本次人工确认预览。

模板：

- [Agent 检查记录](agent-check-record.md)
- [委派简报](delegation-brief.md)
