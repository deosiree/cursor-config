# few-shot 样例 · 多模型并发调度

## 样例 1：en2ru 全模型路权并发（baseline：旧版 round-robin）

来源：translate 套件 `template/few-shot-example/mon-1.9.0-dedup-en2ru-all-models/`

### 输入

- 3842 条词条（去重后，en2ru）
- 8 个模型（讯飞 1 + 硅基 6 + 智谱 1）
- 旧版调度：全局池 maxConcurrency=20，round-robin 摊批

### 旧版结果（round-robin / 8 路均分）

| 指标 | 数值 |
|------|------|
| 第一遍墙钟 | 10.27 min |
| 吞吐 | ≈374 条/分钟 |
| 空行率 | ~4%（152/3842，需补跑） |
| 补跑 | 1.55 min（4 批） |
| 端到端 | ≈12.48 min |

### 新版预期（weighted-lanes / 27 路）

| 指标 | 预期 | 理由 |
|------|------|------|
| 第一遍墙钟 | ≈7-9 min | 讯飞 20 路满跑 + 其余 7 路 1 lane 各 1 批，减少硅基拥塞 |
| 吞吐 | ≈500 条/分钟 | 总 in-flight 条目 ≈ 20×40 + 7×40 = 1080 vs 旧版 20×40 = 800 |
| 空行率 | <2% | 每个模型只跑自己擅长的批次数，减少超时/不匹配 |

## 样例 2：小规模平分缩批（270 条 / 27 路）

### 场景

- 270 条词条 → 27 路 → 10 条/路
- 每路 1 批 × 10 条 = 270 条，1 波次

### 预期

| 指标 | 预期 |
|------|------|
| 批大小 | 10（缩批） |
| 波次 | 1 |
| 墙钟 | ≈1-2 min |
