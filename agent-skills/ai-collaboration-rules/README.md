# AI 协作规则

`ai-collaboration-rules` 帮助多步任务在澄清、实施、验证和交付之间保持一致。它提炼多个 AI 规则摘录中可迁移的共通做法，不替代项目级说明、用户当前指令或领域专项 Skill。

## 适用场景

- 多步代码、文档、调查或知识库任务。
- 需要限定改动范围、判断是否澄清，或定义完成标准。
- 需要如实说明验证证据、未知项和未完成事项。

简单问答、纯翻译和一次性文案改写无需单独套用。目标项目已有专属流程时，先遵循专属流程。

## 使用示例

```text
使用 $ai-collaboration-rules 处理这个多步骤任务：先列出关键假设、影响文件和完成标准，再按目标项目规则实现并报告真实验证结果。
```

不触发示例：

```text
只翻译“同步失败，请重试”。
```
