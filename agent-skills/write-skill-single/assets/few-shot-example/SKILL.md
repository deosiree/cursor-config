# 目标
把散落在长对话中的事实、决策和待办，整理成可续接的中文总结。

## 与上游方法论的关系
- 本 skill 不依赖额外领域方法论。
- 它强调结构化沉淀和可续接性。

## frontmatter 模式
- 本次采用：本地中文模式

## 适用场景
- 对话接近上限。
- 已完成一部分分析或实现，准备切换会话。

## 输入
- `对话内容`
- `当前任务`

## 输出
- 阶段目标
- 关键事实
- 已完成事项
- 待完成事项
- 风险与阻塞

## 执行步骤
1. 提取本轮对话中的目标、约束和结论。
2. 区分“已确认事实”和“仍是猜测”的内容。
3. 输出一份结构化总结，便于下一位直接续接。

## 输出模板

```markdown
# 会话总结

## 当前目标
- …

## 已确认事实
- …

## 已完成
- …

## 待完成
- …

## 风险与阻塞
- …
```

## 验收清单
- [ ] 包含当前目标
- [ ] 区分事实与推测
- [ ] 给出可执行下一步

## 使用示例

```text
使用 $会话总结skill 总结当前关于接口版本切换改造的讨论，供新会话继续推进
```

## 常见误区
- 只摘录结论，不保留上下文前提
- 把推测写成事实
- 没有给出下一步
