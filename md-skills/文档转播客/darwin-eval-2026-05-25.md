### 强项

1. **doc_type 四分类**（面经/方案/教程/参考）+ 分类型 few-shot，教程体已实测过关。
2. **可验证输出**：`validate-podcast-md.py` 门禁（禁四段标签、双人、卷首/快问、N/K）降低 agent 跑偏。
3. **默认调用路径清晰**（optimize-r6）：stem 同名目录、禁止 `podcast/`、仅文档时默认完整且不二次确认。
4. **与 QA转面经 联动**：operating-guide / 编排步骤 6 已与主 SKILL 对齐。

### 通用性结论

- **面经 / 技术方案**：成熟度高，为 skill 设计原点，推荐作为默认标杆场景。
- **教程 / 参考**：结构已验证（test#2），通用性 **良好**。
- **轻量 / 短文档**：规则可用，但缺少实测；与「默认完整」并存时需 agent 严格读检查点 B 关键词表。
- **直接 `/skill` 调起**：optimize-r6 + fix-r7 后，契约与主 SKILL 一致。

**通用性评级**：**B+**（面经域 A，跨 doc_type B+；fix-r7 后契约一致性 **B+**，TTS 环境仍为 B-）。
