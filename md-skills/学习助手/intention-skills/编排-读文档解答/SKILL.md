# 编排：读文档 → 解答

> **定位**：带门禁的编排器。概念怎么讲、要不要图，由方法论skills / 渲染图skills 现场判断，不在此逐步填表。

## 输入

| 参数 | 来源 |
|------|------|
| `文档路径` | 用户入参 |
| `章节号` | 用户入参（如 `## 1.概念扫盲`） |
| `是否引用项目笔记` | 默认 true |

## 执行流程

### 步骤 1：读文档 → 定位章节 → 提取问题列表

```
1. read_file(文档路径) → 定位到 章节号
2. 提取：
   - "需要理解的概念" / "需要关注" 列表
   - "建议画出" 的链路描述
   - 推荐项目名
3. 输出：{ 概念列表, 建议链路, 推荐项目 }
```

**若路径不存在或章节未找到** → 🛑 STOP，说明原因并列出同级 `##` 标题供用户改章节号。

---

### 步骤 2：检查项目笔记与意图分叉

```
1. 检查 {文档同级}/{章节名}/ 是否存在
2. 若存在 → 读 00-架构总览.md 与相关篇 → 准备双链
3. 若不存在且章节含推荐项目：
   🔴 CHECKPOINT — 问用户：
   「该节推荐了 {项目名}，是否先沉淀项目笔记？[是 / 否 / 跳过]」
   - 是 → 切换 [[编排-读文档加项目沉淀/SKILL.md]]（同文档路径、章节号）
   - 否或跳过 → 步骤 3；答案中须标注 ⚠️ 未结合项目源码分析
```

---

### 步骤 3：对每个概念选择方法论

```
读 [[../../../../common-skills/方法论skills/SKILL.md]]
→ 每概念 { method, reason }，跳转对应方法文档
```

---

### 步骤 4：写答案

对每个概念：

1. 写可独立阅读的**核心结论**
2. 需要图 → `[[../../../../common-skills/渲染图skills/SKILL.md]]`
3. 有项目笔记 → 段末 `> 📘 完整分析 → [[双链]]`
4. `edit_file` 注入对应章节

---

### 步骤 5：输出小结

```
回答完成。共 {N} 个概念。
- 方法论：费曼 {x} / 苏格拉底 {y} / 金字塔 {z}
- 项目笔记双链：{M} 处
- 图表：{K} 张
- 若 ⚠️ 未结合源码：须出现在小结
```

## 失败与回退

| 触发 | 一线 | 兜底 |
|------|------|------|
| 概念列表为空 | 用 `[[../../feature-skills/分析-文档章节结构/SKILL.md]]` 再抽一次 | 仍空则 🛑 STOP，请用户指明要问的概念 |
| 注入失败 | 改搜相邻标题或列表块 | 输出「待粘贴块」给用户，禁止静默结束 |

## 约束

- 答案正文须可脱离项目笔记独立阅读
- 每概念 ≤ 1 种方法论
- 图表默认窄版 Mermaid
