# 编排：读文档 → 解答

## 编排器 vs Agent（本层定位）

| | 本 intention | 纯 Agent intention |
|--|--------------|-------------------|
| 固定 | 阶段顺序、RED、必答清单、写回主文档 | 步骤每轮自生成 |
| 可变 | **先答哪个概念**、是否配图、叙述详略 | 全部由模型临场规划 |
| 结论 | 步骤 3 用**必交付清单**；不规定概念 1→2→3 循环顺序 | 仅当章节结构极不规则时再考虑 |

父级 `学习助手` 判意图；本文件管 **清单交什么**；方法论/绘图交给 common-skills。

## 输入

| 参数 | 来源 |
|------|------|
| `文档路径` | 用户入参 |
| `章节号` | 用户入参（如 `## 1.概念扫盲`） |
| `是否引用项目笔记` | 默认 true |

## 主线流程（步骤 1 → 4）

### 步骤 1：读文档 → 定位章节 → 提取问题列表

```
1. read_file(文档路径) → 定位到 章节号
2. 提取：
   - "需要理解的概念" / "需要关注" 列表
   - "建议画出" 的链路描述（若有）
   - 推荐项目名
3. 输出：{ 概念列表, 建议链路, 推荐项目 }
```

**若路径不存在或章节未找到** → 🛑 STOP，说明原因并列出同级 `##` 标题供用户改章节号。

概念列表为空 → 先调 `[[../../feature-skills/分析-文档章节结构/SKILL.md]]` 再抽；仍空则 🛑 STOP。

---

### 步骤 2：检查项目笔记与意图分叉

```
1. 检查 {文档同级}/{章节名}/ 是否存在
2. 若存在 → 读 00-架构总览.md 与相关篇 → 记录可引用双链
3. 若不存在且章节含推荐项目：
   🔴 CHECKPOINT — 问用户：
   「该节推荐了 {项目名}，是否先沉淀项目笔记？[是 / 否 / 跳过]」
   - 是 → 切换 [[编排-读文档加项目沉淀/SKILL.md]]（同文档路径、章节号）
   - 否或跳过 → 步骤 3；清单项须能标注 ⚠️ 未结合项目源码分析
```

**允许收窄范围**：用户说「只答前 5 个概念」→ 未入选的记入清单 `已跳过`。

---

### 步骤 3：目标驱动清单（写答案到文档）

**不规定**概念回答顺序；先立清单，再自选顺序写满并注入。进入本步前须有步骤 1 的概念列表（及步骤 2 的双链/⚠️ 结论）。

#### 3.1 生成交付清单

```json
{
  "必交付": [
    {
      "id": "c1",
      "概念": "Agent",
      "方法论": "待选",
      "完成标准": ["方法论已选", "正文可独立阅读", "已注入主文档", "图或注明无需图"]
    }
  ],
  "章节级可选": [
    { "项": "建议链路图", "状态": "待画|已画|跳过", "说明": "来自步骤1建议链路" }
  ],
  "已跳过": []
}
```

- 每个概念一条 `必交付`；`方法论` 在写作前填入
- 章节级链路图：仅 1 项，不拆成多个概念

#### 3.2 单条完成标准（勾选制）

每条 `必交付` 在 `edit_file` 注入前须满足：

| 勾选 | 完成标准 |
|:---:|----------|
| ☐ | 已读 `[[../../../../common-skills/方法论skills/SKILL.md]]`，选定 **1 种**方法并将在正文标注 |
| ☐ | 正文为可**脱离项目笔记独立阅读**的核心结论（非仅双链） |
| ☐ | 需要图时已调 `[[../../../../common-skills/渲染图skills/SKILL.md]]`，或注明「本条无需图」 |
| ☐ | 有项目笔记时，段末已加 `> 📘 完整分析 → [[双链]]`（双链为延伸阅读，非答案本体） |
| ☐ | 无项目笔记且步骤 2 为跳过/否时，该条或小结含 **⚠️ 未结合项目源码分析** |
| ☐ | 已 `edit_file` 注入到主文档对应章节位置 |

#### 3.3 执行（顺序自选）

```
while 必交付 中仍有未勾选项：
  1. 自选下一条（建议：基础概念先、依赖链上的先后；可先攻难点再补定义）
  2. 勾选完成标准 → 写作 → 注入主文档
  3. 移入「已完成」；写不出则移入 已跳过 并说明原因
```

章节级链路图：在概念清单推进中任意时刻完成即可，不阻塞单条概念。

**退出条件**（满足其一即可进步骤 4）：

- `必交付` 全部已完成，或
- 剩余均已 `已跳过` 且已向用户说明原因

**禁止**：只贴双链无正文；同一概念叠两种方法论；未更新清单就静默少答。

---

### 步骤 4：输出小结

```
回答完成。
- 清单完成率：已完成 / 必交付
- 方法论计数：费曼 {x} / 苏格拉底 {y} / 金字塔 {z} / 不嵌入 {w}
- 项目笔记双链：{M} 处；章节级图：{已画|跳过}
- 已跳过概念及原因
- 若 ⚠️ 未结合源码：须出现
```

## 何时可偏离主线（仍须满足 RED）

| 情况 | 允许动作 |
|------|----------|
| 概念过多 | 步骤 2 后或清单生成后请用户删减 `必交付` |
| 某概念过长 | 拆成「主文档短答 + 双链延伸阅读」，须在清单注明 |
| 暂不改源文件 | 输出「待粘贴块」并标注未注入；禁止声称已写入 |

## 失败与回退

| 触发 | 一线 | 兜底 |
|------|------|------|
| 概念列表为空 | `分析-文档章节结构` 再抽 | 🛑 STOP，请用户列出概念 |
| 注入 SEARCH 无匹配 | 改相邻标题/列表块 | 待粘贴块 + 注入位置说明 |
| 方法论选不出 | 默认费曼或「不嵌入」并注明 | 禁止卡住整条清单 |

## 约束

- 答案正文须可脱离项目笔记独立阅读
- 每概念 ≤ 1 种方法论
- 图表默认窄版 Mermaid（`flowchart TD`，节点 ≤15 字）
