# 编排：渐进式教学

> **定位：** intention 编排器。一次只教一个概念，完成教学 → 追问 → 考核循环后进入下一个概念。
> **与「读文档解答」的区别：** 后者批量注入文档，本编排器逐个交互引导。

## 输入

| 参数 | 来源 |
|------|------|
| `文档路径` | 父级入口传入 |
| `章节号` | 父级入口传入 |
| `概念列表` | （可选）如未指定则由 分析-文档章节结构 提取 |

## 整体流程

```
1. read_file(文档路径) → 定位章节 → 提取概念列表
2. for each concept in 概念列表:
     a. 教学阶段
     b. 追问阶段
     c. 考核阶段
     d. 根据考核结果决定通过/回退
3. 输出进度小结
```

---

### 步骤 1：提取概念列表

→ `[[../../feature-skills/分析-文档章节结构/SKILL.md]]`

```
输入：文档路径 + 章节号
输出：概念列表 [{id, 名称, 描述}]
```

**若概念列表为空** → 🛑 STOP，列出文档中 `##` / `###` 级标题供用户指定。

---

### 步骤 2：教学循环（逐个概念）

#### 2.1 教学阶段

→ `[[../../feature-skills/讲解-概念教学/SKILL.md]]`

```
输入：当前概念 + 文档内容
输出：讲解正文（通过费曼/金字塔等方法论生成）
```

展示讲解正文给用户。

#### 2.2 追问阶段

→ `[[../../feature-skills/交互-苏格拉底追问/SKILL.md]]`

```
循环最多 3 轮：
  1. 生成追问 → 展示给用户
  2. 🔴 STOP — 等用户回答
  3. 收集回答 → 生成下一问
```

#### 2.3 考核阶段

→ `[[../判定-掌握度评估/SKILL.md]]`

```
1. call 评估-分析掌握画像（基于追问回答）
2. call 评估-出题引擎（生成试卷）
3. 🔴 STOP — 展示试卷，等用户作答
4. call 评估-判分（输出通过/边缘/不通过）
```

#### 2.4 判定与分支

| 考核结果 | 动作 |
|---------|------|
| **通过** ✅ | → 调 `[[../../feature-skills/回写-双链注入主文档/SKILL.md]]` 落盘 → 进入下一概念 |
| **边缘** ⚠️ | → 增加 1 轮追问 → 回到 2.3 重新考核 |
| **不通过** ❌ | → 回到 2.1，换角度重新讲解 |

---

### 步骤 3：进度小结

```
教学完成。
- 已完成：{N} / {总概念数}
- 方法论使用：费曼 {x} 次 / 苏格拉底 {y} 次 / 金字塔 {z} 次
- 一讲通过率：{M} / {N}
- 已跳过概念（如有）：{原因说明}
```

## RED（失败基线）

| 触发条件 | 一线修复 | 兜底 |
|---------|---------|------|
| 用户连续 2 个概念不通过 | 建议用户休息或切换学习方式 | 标记⚠️ 建议用户手动跳过这个章节 |
| 概念列表过长（>10） | 问用户是否只教前 5 个 | 只教前 5 个，其余标注已跳过 |
| 用户主动说"跳过" | 标记已跳过，进入下一概念 | 记录跳过原因 |

## 约束

1. 一次只教一个概念，禁止一次性讲解多个概念
2. 每个概念必须经过"教学 → 追问 → 考核"三阶段
3. 用户未反馈前不推进（🔴 STOP）
4. 每概念最多 1 次"边缘→再考"机会，仍不过则按不通过处理
