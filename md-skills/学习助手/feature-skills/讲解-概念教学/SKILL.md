# 讲解 · 概念教学

> **定位：** 功能 skill。负责选择一个概念的最佳讲解方式，路由到对应的 common methodology skill 完成执行。不自己实现教学法细节。

## 输入

| 参数 | 说明 |
|------|------|
| `概念` | 要讲解的知识点名称 |
| `文档内容` | 概念在文档中的原始描述 |
| `上下文` | 所属章节、读者水平 |

## 讲解方式选择

| 概念特征 | 讲解方式 | 路由目标 |
|---------|---------|---------|
| 单一术语，需通俗理解 | 费曼 · 概念解释 | `[[../../common-skills/方法论skills/费曼-skills/intention-skills/编排-概念解释/SKILL.md]]` |
| 多术语 + 层级/调用关系 | 费曼 · 统合叙事 | `[[../../common-skills/方法论skills/费曼-skills/intention-skills/编排-统合叙事/SKILL.md]]` |
| 章节开头/需建立全局认知 | 金字塔 · 结论先行 | `[[../../common-skills/方法论skills/金字塔-skills/intention-skills/编排-结论先行/SKILL.md]]` |
| 多术语 + 缺全局 | 金字塔顶层 + 费曼子节 | 先调金字塔，再调费曼 |
| 不明确 | 问用户：通俗理解 / 串联多术语 / 建立全局？ | — |

## 执行流程

```
Step 1：分析概念特征
  → 根据上述表选择讲解方式
  → 输出：讲解方式 + 路由目标

Step 2：路由到 common skill
  → 调用对应 common skill 生成讲解内容
  → 传入必要参数（术语、上下文等）
  🔴 CHECKPOINT：确认 common skill 返回的讲解内容与概念匹配

Step 3：接收返回的讲解正文

Step 4：落盘（可选）
  → 如果用了费曼 → 调用 [[../回写-双链注入主文档/SKILL.md]] 落盘
  🔴 CHECKPOINT：落盘前确认内容已通过理解校验
```

## RED

| 反模式 | 替代 |
|-------|------|
| 对单一术语选统合叙事 | 应选概念解释 |
| 对多术语选概念解释（只解释一个） | 应选统合叙事 |
| 不讲多术语也不讲全局时选金字塔 | 应选不嵌入或概念解释 |
| 自己实现了教学法细节而非引用 common | 必须引用 common-skills，本 skill 只做路由 |
| 没有分析概念特征直接默认用一种方法 | 必须按表逐条匹配概念特征 |

## 约束

1. 不实现教学法细节——所有教学法执行委托给 common-skills
2. 如果用了费曼方法，写后必须调用理解校验
3. 不得直接在本文件中写入教学方法的定义或规则（指向 common-skills 引用即可）

## 引用说明

本 skill 不实现教学法细节，所有教学法执行委托给 `common-skills/方法论skills/` 下的子 skill。
