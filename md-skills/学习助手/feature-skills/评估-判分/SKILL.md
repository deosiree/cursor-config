# 评估 · 判分

> **定位：** 纯功能 skill。判分 + 根据画面对比给出掌握等级。

## 输入

| 参数 | 说明 |
|------|------|
| `试卷` | 评估-出题引擎 生成的试卷（含正确答案/参考要点） |
| `用户答案` | 用户提交的答案 |
| `掌握画像` | 评估-分析掌握画像 的输出（用于对照薄弱点是否已改善） |

## 判分规则

### 选择题

| 情况 | 得分 |
|------|:---:|
| 选对 | 满分 |
| 选错 | 0 分 |
| 未答 | 0 分 |

判断标准：严格匹配正确答案。

### 填空题

| 情况 | 得分 |
|------|:---:|
| 完全正确（核心关键词全部匹配） | 满分 |
| 部分正确（核心关键词部分匹配） | 50% |
| 错误/空白 | 0 分 |

判断标准：核心关键词匹配，允许表述差异。

### 场景题

| 情况 | 得分 |
|------|:---:|
| 覆盖所有参考要点 | 满分 |
| 覆盖部分要点 | 按比例得分（如 3 个要点覆盖 2 个 → 67%） |
| 未覆盖任何要点 | 0 分 |
| 思路正确但表达不完整 | 参考要点的 50% |

## 掌握等级判定

🔴 CHECKPOINT：确认每题得分已核验，再输出最终掌握等级

| 总分占比 | 掌握等级 | 含义 |
|:-------:|:-------:|------|
| ≥ 80% | **通过 ✅** | 概念已掌握，进入下一概念 |
| 60% - 79% | **边缘 ⚠️** | 加强薄弱点后再考一次 |
| < 60% | **不通过 ❌** | 回退重讲，换角度 |

## 输出

```json
{
  "每题得分": [
    {"id": 1, "题型": "选择题", "得分": 10, "满分": 10, "用户答案摘要": "B", "评语": "正确"},
    {"id": 2, "题型": "场景题", "得分": 7, "满分": 10, "用户答案摘要": "写了路由定义但缺少错误处理", "评语": "部分正确，缺少错误处理"}
  ],
  "总分": {"得分": 17, "满分": 20, "占比": "85%"},
  "掌握等级": "通过"|"边缘"|"不通过",
  "薄弱点变化": {
    "已解决": ["原先的薄弱点1 — 本次考核表现良好"],
    "仍薄弱": ["薄弱点2 — 相关题目得分不足"]
  },
  "建议": "下一概念"|"加强后再考"|"回退重讲"
}
```

## RED

| 反模式 | 替代 |
|-------|------|
| 场景题评分凭感觉 | 严格按参考要点计分 |
| 总分跨等级边界（79%）建议不明确 | 建议"加强后再考" + 指出需加强的具体点 |
| 用户答案和参考答案完全不同但合理 | 用 LLM 判断语义合理性 |
