# 交互 · 苏格拉底追问

> **定位：** 功能 skill。负责管理追问交互流程（轮次控制 + 用户反馈收集），追问生成和深度判定委托给 common-skills。

## 输入

| 参数 | 说明 |
|------|------|
| `概念` | 当前正在讲解的概念 |
| `讲解内容` | 已输出的讲解正文 |
| `用户反馈` | 用户看完讲解后的反馈文本（如"理解了"、"还是不懂"） |

## 流程

### Step 1：首轮追问

```
call [[../../common-skills/方法论skills/苏格拉底-skills/feature-skills/交互-生成追问/SKILL.md]]
  → 传入：
    - 决策点 = 概念的核心理解难点
    - 当前认知 = "刚刚完成讲解，读者反馈：{用户反馈}"
    - 追问深度 = 1
  → 返回：第 1 个追问问题
```

### Step 2：交互循环（最多 3 轮）

```
for round = 1 to 3:
  🔴 STOP — 展示追问，等用户回答并收集回答
  
  if round < 3 and 读者未表现出充分理解:
    call 交互-生成追问:
      → 传入：上一问 + 用户回答 → 返回下一问
  else:
    → 进入 Step 3 (第 3 轮强制结束)

🔴 CHECKPOINT：追问链是否达到深度？→ 进入 Step 3 判定
```

**提前结束条件**：用户在第 1 轮回答显示出充分理解（如用自己的话准确复述了概念核心）→ 提前进入 Step 3。

### Step 3：判定追问深度

```
call [[../../common-skills/方法论skills/苏格拉底-skills/feature-skills/判定-追问深度/SKILL.md]]
  → 传入：追问链（所有追问 + 所有回答）
  → 返回：通过/边缘/不通过
```

## 轮次上限

- 严格上限 3 轮
- 第 3 轮后强制进入判定
- 如果用户在第 1 轮就显示出充分理解 → 提前结束

## RED

| 反模式 | 替代 |
|-------|------|
| 不等待用户回答直接出下一问 | 每问后 🔴 STOP |
| 追问轮次无限循环 | 严格 3 轮上限 |
| 自己生成追问而不引用 common-skills | 必须引用 common-skills 苏格拉底-skills |
| 用户说"理解了"就直接通过 | 必须经过深度判定，不能凭用户一句话 |
| 用户连续说"不懂"但仍在追问 | 应降级为重新讲解而非继续追问 |

## 约束

1. 严格 3 轮上限
2. 不自己生成追问内容——委托 common-skills
3. 每轮必须 🔴 STOP 等待用户回答
4. 追问结束后必须经过深度判定才能进入考核
