# 学习助手

阅读技术文档，回答指定章节的问题，结合项目源码沉淀知识点。

## 触发词

- `回答第X节` / `回答第X章`
- `解读项目` / `沉淀知识点`
- `概念扫盲` / `拆解项目`

## 两个意图

| 触发场景 | 意图 | 效果 |
|---------|------|------|
| 只问文档中的问题，不涉及项目源码 | 读文档-解答 | 读 → 分叉检查 → **步骤3目标清单**（概念顺序自选）→ 写回文档 |
| 需要探索项目源码并沉淀分析文档 | 读文档+项目-沉淀 | 读 → 探索 → CP1 → 总览 → **步骤5目标清单** → CP2 → 回写双链 |

**分层**：`学习助手` = Agent 入口（判意图）；`intention-skills` = 带 🔴 检查点的编排器。解答用**步骤3必答清单**、沉淀用**步骤5交付清单**（均为顺序自选 + 勾选标准，非逐步填表循环）。

## 入参

| 参数 | 必填 | 说明 |
|------|:---:|------|
| `文档路径` | 是 | .md 文件路径 |
| `章节号` | 是 | `## N.标题` |
| `项目名` | 否 | `owner/repo`；沉淀意图需要 |
| `--repo-path` | 否 | 本地 clone 路径 |
