# 学习助手

阅读技术文档，回答指定章节的问题，结合项目源码沉淀知识点。

## 触发词

- `回答第X节` / `回答第X章`
- `解读项目` / `沉淀知识点`
- `概念扫盲` / `拆解项目`

## 两个意图

| 触发场景 | 意图 | 效果 |
|---------|------|------|
| 只问文档中的问题，不涉及项目源码 | 读文档-解答 | 读 → 选方法论 → 写答案到文档 |
| 需要探索项目源码并沉淀分析文档 | 读文档+项目-沉淀 | 读 → 探索 → CP1 → 落盘 → CP2 → 回写双链 |

**分层**：`学习助手` = Agent 入口（判意图）；`intention-skills` = 带 🔴 检查点的编排器（固定阶段顺序，步骤内判断交给 common/feature skills）。沉淀流水线稳定，不宜把 intention 改成纯 Agent 逐步自规划。

## 入参

| 参数 | 必填 | 说明 |
|------|:---:|------|
| `文档路径` | 是 | .md 文件路径 |
| `章节号` | 是 | `## N.标题` |
| `项目名` | 否 | `owner/repo`；沉淀意图需要 |
| `--repo-path` | 否 | 本地 clone 路径 |

## 依赖

- 方法论路由：`common-skills/方法论skills/`
- 图形渲染：`common-skills/渲染图skills/`
- 源码探索：`common-skills/探索skills/`
- 自我迭代：`agent-skills/write-skill/`
- 质量评估：`darwin-skill/`
