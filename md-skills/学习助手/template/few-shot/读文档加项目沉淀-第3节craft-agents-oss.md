## 01-类型层抽离 摘录（费曼方法）

> **费曼式解释：** 类型层就像整个系统的"词汇表"。所有包在写代码之前必须先在 `packages/core/src/types/` 里定义好 Workspace、Session、Message、AgentEvent 这些核心概念的类型。编译期就能发现"用了不存在的字段"——不需要等到运行时崩溃。
>
> **源码证据：** `packages/core/src/types/index.ts` 只做 `export type { ... }`，`package.json` 没有任何 `dependencies`。

## 04-Agent后端抽象 摘录（苏格拉底方法）

> **追问 1：** 为什么不直接写两个 if/else？
> → 加新后端要改 7+ 文件，无法保证行为一致。
>
> **追问 2：** 那怎么保证 Claude 和 Pi 的行为一致？
> → 接口契约：`AgentBackend` 规定了所有后端必须实现的方法。
>
> **追问 3：** 回调注入是好的设计还是 hack？
> → 依赖反转：AgentBackend 依赖抽象回调，不依赖具体 Manager 类型。
