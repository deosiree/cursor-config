# 学习助手

> Skill ID：`学习助手`。目录：`md-skills/学习助手/`  
> **角色**：父级 **Agent 入口**（判意图 → 路由 intention）；具体步骤在子 skill，不在此逐步展开。

## 入口决策（5 步）

```
1. 解析入参：文档路径、章节号、是否含「解读/沉淀/项目」、--repo-path / 项目名
2. 若 文档路径 或 章节号 缺失 → 🛑 STOP，列出缺项，等用户补全
3. 判意图：
   - 只答章节内概念/问题、不改仓库结构 → intention：编排-读文档解答
   - 要探索仓库并落盘笔记 +（通常）回写主文档 → intention：编排-读文档加项目沉淀
   - 意图含糊（如只说「帮我学一下这节」）→ 问一句：「只写回答到文档 / 还要沉淀项目笔记？」
4. read_file(文档路径) 验证文件存在；定位章节失败 → 🛑 STOP，给出章节级标题列表供用户改章节号
5. 调用对应 intention 的 SKILL.md；禁止跳过 intention 直接在主入口写答案
```

## RED（失败基线）

| 不要做 | 后果 |
|--------|------|
| 只贴 `[[双链]]` 不写答案正文 | 失败；主文档须可独立阅读 |
| 对简单概念用苏格拉底长篇、对层级概念不嵌入 | 失败；走方法论skills |
| 项目笔记落盘后未回写双链 | 失败（沉淀意图） |
| 有推荐项目却既不探索也不标注 ⚠️ | 失败 |
| Mermaid 横向过长导致 Obsidian 溢出 | 失败；窄版 TD，节点 ≤15 字 |

## GREEN（意图路由）

| 场景 | 路由 |
|------|------|
| 读文档 → 回答指定章节问题 | `[[intention-skills/编排-读文档解答/SKILL.md]]` |
| 读文档 → 项目沉淀 + 双链回写 | `[[intention-skills/编排-读文档加项目沉淀/SKILL.md]]` |

> intention 层用 **带门禁的编排器**（顺序 + 检查点），不用逐步填表；探索/写作/回写的判断交给 common-skills 与 feature-skills。见沉淀 intention 文首「编排器 vs Agent」。

## 入参

| 参数 | 必填 | 说明 |
|------|:---:|------|
| `文档路径` | 是 | 要阅读的 .md 文件路径 |
| `章节号` | 是 | 如 `## 1.概念扫盲` 或 `第 3 节` |
| `项目名` | 否 | `owner/repo`；沉淀意图需要 |
| `--repo-path` | 否 | 本地 clone；未传则 GitHub 探索 |

## 关键约束

1. **答案在正文，不在链接**
2. **方法论不本地重复定义** → 方法论skills
3. **Mermaid 窄版**：`flowchart TD`，节点 ≤15 字
4. **项目笔记命名**：`{序号}-{关注点关键词}.md`
5. **双链**：`[[相对路径/文件名\|显示名]]`
6. **笔记目录**：`{文档所在目录}/{章节名}/`

## 何时不用

| 需求 | 用 |
|------|-----|
| 纯 QA 对话总结 | QA转面经 |
| 只读源码、不改文档 | 探索skills |
| 只画图 | 渲染图skills |

## 使用示例

```text
回答第 1 节概念扫盲 → 编排-读文档解答 → 写答案到文档

解读第 3 节 craft-agents-oss --repo-path C:\...\craft-agents-oss
→ 编排-读文档加项目沉淀 → 笔记目录 + 回写双链
```
