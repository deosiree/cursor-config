# 学习助手

> Skill ID：`学习助手`。目录：`md-skills/学习助手/`  
> **角色**：父级 **Agent 入口**（判意图 → 路由 intention）；具体步骤在子 skill，不在此逐步展开。

## 入口决策（5 步）

### 步骤 1：解析入参
```
提取 { 文档路径, 章节号, 是否含"解读/沉淀/项目", --repo-path/项目名 }
```
- 参数表见下方「入参」段
- 支持两种调用形式：直接参数 / 自然语言触发

### 步骤 2：参数完备性检查
```
if (文档路径 缺失 OR 章节号 缺失):
  → 🛑 STOP
  → 列出缺项
  → 等用户补全
```
**禁止**：参数不全仍试图运行（如猜章节号）。

### 步骤 3：意图判定（三分支）

| 条件 | 分支 |
|------|------|
| 只答章节内概念/问题、不改仓库结构 | → `[[intention-skills/编排-读文档解答/SKILL.md]]` |
| 含"解读/沉淀/项目" +（通常）回写主文档 | → `[[intention-skills/编排-读文档加项目沉淀/SKILL.md]]` |
| 意图含糊（如只说「帮我学一下这节」） | → **问用户**：「只写回答到文档 / 还要沉淀项目笔记？」 |

### 步骤 4：文档可读性验证
```
read_file(文档路径)
if 文件不存在 OR 定位章节号失败:
  → 🛑 STOP
  → 列出文档中所有 `##` 级标题供用户改章节号
```

### 步骤 5：路由执行
```
call 对应 intention 的 SKILL.md
```
- **禁止**：跳过 intention 直接在主入口写答案
- **禁止**：调错 intention（如沉淀意图走到了解答意图）

## RED（失败基线）

| 不要做 | 后果 |
|--------|------|
| 只贴 `[[双链]]` 不写答案正文 | 失败；主文档须可独立阅读 |
| 对简单概念用苏格拉底长篇、对层级概念不嵌入 | 失败；走方法论skills |
| 项目笔记落盘后未回写双链 | 失败（沉淀意图） |
| 有推荐项目却既不探索也不标注 ⚠️ | 失败 |
| Mermaid 横向过长导致 Obsidian 溢出 | 失败；窄版 TD，节点 ≤15 字 |

## GREEN（意图路由）

| 场景 | 路由 |
|------|------|
| 读文档 → 回答指定章节问题 | `[[intention-skills/编排-读文档解答/SKILL.md]]` |
| 读文档 → 项目沉淀 + 双链回写 | `[[intention-skills/编排-读文档加项目沉淀/SKILL.md]]` |

> intention 层用 **带门禁的编排器** + **必交付清单**（顺序自选）；见各 intention 文首「编排器 vs Agent」与步骤 3/5 目标清单。

## 入参

| 参数 | 必填 | 说明 |
|------|:---:|------|
| `文档路径` | 是 | 要阅读的 .md 文件路径 |
| `章节号` | 是 | 如 `## 1.概念扫盲` 或 `第 3 节` |
| `项目名` | 否 | `owner/repo`；沉淀意图需要 |
| `--repo-path` | 否 | 本地 clone；未传则 GitHub 探索 |

## 关键约束

1. **答案在正文，不在链接** — 每概念至少 1 段可独立阅读的正文（≥3 句），双链仅为延伸入口
2. **方法论不本地重复定义** → 路由到 `[[../../common-skills/方法论skills/SKILL.md]]`
3. **Mermaid 窄版**：`flowchart TD`，节点 ≤15 字，分支 ≤6 个；禁止横向 `graph LR`
4. **项目笔记命名**：`{序号}-{关注点关键词}.md`（如 `01-类型层抽离.md`）
5. **双链**：`[[相对路径/文件名\|显示名]]`（如 `[[3.拆解完整项日/01-类型层抽离\|类型层抽离]]`）
6. **笔记目录**：`{文档所在目录}/{章节名}/`（由 `create_directory` 创建）

## 何时不用

| 需求 | 用 |
|------|-----|
| 纯 QA 对话总结 | QA转面经 |
| 只读源码、不改文档 | 探索skills |
| 只画图 | 渲染图skills |

## 使用示例

| 场景 | 用户输入 → 路由 → 产出 |
|------|------------------------|
| Happy: 读文档解答 | `回答第 1 节概念扫盲` → 编排-读文档解答 → 每概念正文+方法论标注，小结含完成率 |
| Happy: 读文档加沉淀 | `解读第 3 节 craft-agents-oss --repo-path C:\...\craft-agents-oss` → 编排-读文档加项目沉淀 → 笔记目录(≥3 篇)+双链回写 |
| Edge: 含推荐项目但无笔记 | `回答第 2 节理解Agent Loop`（该节有推荐项目）→ 编排-读文档解答 → 跳检查点问是否沉淀 → 选否 → ⚠️ 标注 |
| Edge: 无本地源码 | `解读第 2 节 learn-claude-code`（无 --repo-path）→ 编排-读文档加项目沉淀 → web_search 推断 owner/repo → 远程探索 → 标注「来自 GitHub 远程探索」 |
| Edge: 参数不全 | `帮我学一下这节`（无文档路径/章节号）→ 🛑 STOP → 列出缺项 |
| Edge: 意图含糊 | `帮我学一下这节`（有文档路径）→ 问「只写回答到文档 / 还要沉淀项目笔记？」
