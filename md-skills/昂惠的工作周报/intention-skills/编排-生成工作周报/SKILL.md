# 编排-生成工作周报

## 输入

| 参数 | 说明 | 默认值 |
|------|------|--------|
| targetWeek | `"本周"` / `"上周"` / `"上上周"` / `"5.18那周"` / `"5.18-5.22"` | `"本周"` |

如用户未指定，默认生成本周周报。

## 编排步骤

### 步骤 1：日期确认

**执行：**
1. 获取当前日期（`new Date()`）
2. 解析 `targetWeek` 参数：`"本周"` → 本周一~五，`"上周"` → 上周一~五，`"MM.DD那周"` → 该日所在周，`"MM.DD-MM.DD"` → 精确范围
3. 计算目标周的周一~周五日期，格式 `MM.DD`

**示例：**
- 当前 2026-05-31(周日) + `"本周"` → `{start: "5.25", end: "5.29", label: "5.25-5.29第四周"}`
- 当前 2026-05-31(周日) + `"上周"` → `{start: "5.18", end: "5.22", label: "5.18-5.22第三周"}`

> 详细映射表见 `[[../../feature-skills/提取-本周飞书内容/SKILL.md]]` §步骤 2

**步骤间数据格式约定：**

| 传递 | 格式 | 示例 |
|------|------|------|
| 步骤 1→2 | `{start, end, label}` | `{start:"5.25", end:"5.29", label:"5.25-5.29第四周"}` |
| 步骤 2→3 | `[{text, checked, day}]` | `[{"text":"建联25位达人...","checked":true,"day":"周二"}]` |
| 步骤 3→4 | `[{domain, text, progress}]` | `[{"domain":"抖音bd","text":"建联25位...","progress":"100%"}]` |
| 步骤 4→5 | `string` (文件路径) | `D:\\FILE\\...\\工作周报-2026-05-31.md` |

### 步骤 2：提取本周内容

**执行：** 调用 `[[../../feature-skills/提取-本周飞书内容/SKILL.md]]`

| 输入参数 | 值 |
|----------|-----|
| 飞书 URL | `https://zru9fxhvq5.feishu.cn/wiki/IbuLwEv7fituvMkrSaWc86CjncX` |
| targetWeek | 步骤 1 的 `{start, end, label}` |

**输出：** `[{text, checked, day}]` — 约 17 条原始工作项

**门禁：**
- 输出 `[]` → 报错终止：未找到 `{label}` 的内容，检查飞书文档是否已更新
- 输出周范围不匹配 → 报错并展示实际匹配到的周，人工确认

### 步骤 3：聚合工作内容

**执行：** 调用 `[[../../feature-skills/聚合-本周工作内容/SKILL.md]]`

| 输入 | 输出 |
|------|------|
| 步骤 2 的 `[{text, checked, day}]` | `[{domain, text, progress}]` ≤10 条 |

**门禁：**
- 输出 `[]` → 报错终止
- 输出 `length > 10` → 重新聚合（放宽合并粒度），最多重试 2 次

### 步骤 4：生成周报

**执行：** 调用 `[[../../feature-skills/生成-周报文档/SKILL.md]]`

| 输入参数 | 值 |
|----------|-----|
| 聚合项 | 步骤 3 的 `[{domain, text, progress}]` |
| 输出路径 | `D:\FILE\Obsidian Vault\昂惠的工作周报\工作周报-{周日日期}.md` |

**输出：** 文件路径（string）

### 步骤 5：最终落盘

**执行：**
1. `read_file` 读取步骤 4 返回的文件路径
2. 校验三重：文件存在、`size > 0`、内容含 `"本周工作总结"`
3. 展示 Markdown 原文供用户复制

**异常：**
- 文件不存在 → 报错：周报未生成，检查步骤 4
- 文件为空 → 报错：写入失败，检查磁盘空间
- 缺少结构标记 → 警告后继续输出

## 检查点

| 时机 | 触发条件 | 动作 |
|------|----------|------|
| **步骤 2 之后** | 提取内容 > 0 条 | 展示提取到的日期范围和条目数，等待人工确认"继续"后再进入聚合 |
| **步骤 3 之后** | 聚合完成 | 展示聚合结果摘要（条数、各领域分布），等待人工确认"继续"后再生成 |
| **步骤 4 之后** | 文件写入成功 | 展示文件路径和内容概要，等待人工确认"落盘"后输出最终文本 |

如人工在任一检查点回复"不对"或指出错误，回到对应步骤重新执行。

## 边界条件

| 条件 | 处理 |
|------|------|
| 步骤 2 提取为空 | 报错终止，提示检查飞书文档是否已更新 |
| 步骤 2 提取到非本周内容 | 报错，展示匹配到的周范围，人工确认 |
| 步骤 2 download.js 失败 | 提示检查 OpenCLI 连接，人工决定重试或跳过 |
| 步骤 3 聚合后 0 条 | 报错终止 |
| 步骤 3 聚合后 >10 条 | 重新聚合（放宽合并粒度） |
| 步骤 4 模板文件缺失 | 报错：模板文件不存在，检查路径 |
| 步骤 4 embed 脚本执行失败 | 降级：LLM 直接 read_file 读取模板 |
| 步骤 5 输出文件不存在/为空 | 报错：写入失败，检查步骤 4 |
| 输出目录不存在 | 自动创建目录 |

## 关键约束

- 步骤 2 提取为空时不继续
- 步骤 3 聚合 >10 条时重新聚合
- 任何步骤失败不回退，需人工介入
