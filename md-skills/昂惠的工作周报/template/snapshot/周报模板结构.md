# 周报模板结构

## 四段结构

```
# 昂惠的工作周报

## 一、本周工作总结
## 二、本周工作内容
## 三、需要协调与帮助
## 四、下周工作计划
## 附件说明
## 图片说明
```

## 结构约束

### 一、本周工作总结
- 按领域分点，每点1-2句
- 包含关键数字（达人数量、预算金额等）
- 开头格式：`本周围绕**领域一、领域二**...方向推进本周工作（MM.DD-MM.DD 第N周）`

### 二、本周工作内容
- ≤ 10 条，按领域分组
- 格式：`序号. [**domain标签：**]{text}；（**进展XX%**）`
- domain 标签仅抖音bd、小红书pr、会议加粗
- 无 domain 项不加标签
- 本周写进度（100% / ____% / 50% 等），下周不写进度

### 三、需要协调与帮助
- 从工作内容中提取阻塞项
- 无则写 `* 无`

### 四、下周工作计划
- 从飞书文档"下周计划"部分提取
- 逐条列出，无进度标记

### 附件说明 / 图片说明
- 默认 `* --`

## 领域分组规则

| 领域 | 关键词 | 在"二"中的标签 |
|------|--------|---------------|
| 抖音达人BD | 建联、寄样、投流、星图、挂车、达人查找 | `**抖音bd：**` |
| 小红书PR种草 | 种草、小红书、达人建联、测评博主、报价筛选、KOC、预算 | `**小红书pr：**` |
| 素材 & 内容二创 | 素材、二创、千川 | 无标签或归入对应平台 |
| 运营 & 规划 | 包装、采购、费用、立项 | 无标签 |
| 会议 | 会议、拉齐 | `**会议参加：**` |

## 口吻约束

- 资深BD视角，以"推进/梳理/产出/完成/落地"驱动
- 避免"了解""学习""构思"等初级措辞
- 工作内容文本严格使用飞书文档原文，不编造细节
