# 聚合原则

## 核心定位

**Agent 驱动，非固定映射表。** 每周工作内容不同，Agent 需阅读实际内容后动态判断合并。以下为指导原则和历史参考，不作为硬编码规则。

## 指导原则

| 原则 | 说明 |
|------|------|
| 同领域同层合并 | 同一平台、同一执行阶段的操作优先合并，子项间分号连接 |
| 预算独立 | 涉及跨部门审批（财务/人事）的预算项一般不合并进执行层 |
| 策略独立 | 长期方向探索/策略规划区别于日常执行，可独立成条 |
| 跨平台分开 | 抖音和小红书永远不合并 |
| 会议汇聚 | 所有会议合并为一条，末尾标注关键结论 |
| 单项独立 | 包装采购、团建等非达人任务各自独立 |

## 硬约束

**聚合后 ≤ 10 条。**

## 混合进度处理

| 场景 | 处理 |
|------|------|
| 所有子项 checked=true | `进展100%` |
| 所有子项 checked=false | `进展____%` |
| 进度不一致 | Agent 给整体估计值 |

## Agent 判断流程

```
1. 通读所有原始项 → 标注 平台/层级
2. 同平台+同层级 → 判断是否同一执行阶段 → 是则合并
3. 预算/策略项 → 判断独立价值
4. 会议 → 汇聚
5. >10条 → 放宽粒度重新合并
6. 混合进度处理
```
