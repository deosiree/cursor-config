# 昂惠的工作周报

> Skill ID：`昂惠的工作周报`。目录：`.cursor/md-skills/昂惠的工作周报/`

## 路由表

| 场景 | 触发词 | 路由 |
|------|--------|------|
| 生成本周周报 | 周报、本周工作、weekly、生成周报 | `[[intention-skills/编排-生成工作周报/SKILL.md]]` |
| 生成历史周报 | 上周、上上周、X月X日那周、补周报 | `[[intention-skills/编排-生成工作周报/SKILL.md]]`（传入 targetWeek） |

## 何时不用

| 需求 | 用 |
|------|-----|
| 只是想编辑已有周报 | 直接编辑文件，不触发本 skill |
| 飞书文档 URL 已变更 | 先更新本 skill 的固定 URL，再运行 |
| OpenCLI 未安装或浏览器未连接 | 先修复环境，否则提取步骤会失败 |

## 边界条件

| 条件 | 处理 |
|------|------|
| 飞书文档无法访问（未登录/权限不足） | 提取步骤报错，提示用户检查浏览器登录态 |
| 文档中找不到本周内容 | 提示用户飞书文档可能尚未更新本周记录 |
| 文档格式异常（无周标记） | 报错并展示缓存文件前 500 字符供诊断 |
| download.js 执行失败 | 提示检查 OpenCLI 连接，人工决定重试或跳过 |
| 聚合后 >10 条 | 编排器自动重新聚合（放宽合并粒度） |
| 输出目录不存在 | 自动创建目录 |
| 输出文件已存在 | 覆盖（生成最新版本） |
| 用户中途回复"不对" | 回到对应步骤重新执行，不回退整个流程 |
| **入职第一周/特殊周**（原始项含"了解""学习""熟悉"等 onboarding 内容） | 领域标记为"入职融入"，工作总结用 senior 措辞改写（推进/梳理/产出）；工作内容项保留飞书原文 |
| **部分周（缺少某几天数据）** | 按已有数据正常生成，不编造缺失日期的内容 |
| **空白周（该周无任何数据）** | 报错提示：飞书文档该周无记录 |

## 关键约束

1. 飞书文档 URL 固定为 `https://zru9fxhvq5.feishu.cn/wiki/IbuLwEv7fituvMkrSaWc86CjncX`
2. 输出目录固定为 `D:\FILE\Obsidian Vault\昂惠的工作周报`
3. 输出文件名：`工作周报-YYYY-MM-DD.md`（YYYY-MM-DD 为当前周日日期）
4. 周报口吻：资深BD，体现对公司价值，避免"了解""学习""构思"

## 检查点

### 执行前检查（必须全部通过才进入编排）

- [ ] OpenCLI 可用（`opencli doctor` 通过）
- [ ] 飞书文档 URL 可访问（浏览器已登录飞书）
- [ ] 输出目录 `D:\FILE\Obsidian Vault\昂惠的工作周报` 存在且可写
- [ ] 模板文件 `昂惠的工作周报-template.md` 存在

### 运行时检查点（编排过程中暂停等待人工确认）

| 时机 | 检查内容 | 确认后动作 |
|------|---------|-----------|
| **提取完成** | 展示日期范围和条目数 | 回复"继续"→进入聚合 |
| **聚合完成** | 展示聚合结果摘要（条数、领域分布） | 回复"继续"→进入生成 |
| **生成完成** | 展示文件路径 | 回复"落盘"→在会话中输出完整周报原文 |

> 如人工回复"不对"或指出错误，回到对应步骤重新执行。

## 触发规则

| 用户输入 | 匹配 | 行为 |
|----------|------|------|
| `"生成周报"` / `"本周工作"` / `"weekly report"` | ✅ 精确命中 | 路由编排器，`targetWeek="本周"` |
| `"生成上周周报"` / `"补上上周的周报"` | ✅ 含"周报"+时间词 | 路由编排器，提取时间词→`targetWeek` |
| `"帮我写工作周报"` / `"输出这周周报"` | ✅ 含"周报" | 路由编排器，默认本周 |
| `"这周干了很多活帮我总结"` | ❌ 无"周报"关键词 | 不触发 |
| `"打开上周的周报看看"` | ❌ 非生成意图 | 不触发（待 v2） |

```text
补一下5.18那周的周报                        → 5.18-5.22
用 $昂惠的工作周报 生成周报                  → 本周（显式触发）
```
