# 更新技能源 — README

## 定位

从 cc-switch 管理的远程仓库拉取最新 skill，同步到 Hermes，重启 Gateway 使其生效。

## frontmatter 模式

本次采用 **本地中文模式**：
- `name`：更新技能源
- `description`：中文触发描述

## 目录职责

| 路径 | 用途 |
|------|------|
| `SKILL.md` | 核心流程、反模式、失败模式 |
| `template/` | 操作示例模板 |
| `assets/` | few-shot 示例 |
| `evals/` | 触发测试 |
