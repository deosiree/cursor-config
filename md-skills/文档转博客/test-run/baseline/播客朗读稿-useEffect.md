# Vue useEffect 技术说明 · 播客稿

> 本期把 useEffect 讲清楚，适合刚接触 React Hooks 的同学。

## 定义

useEffect 是 React 提供的 Hook，用于在函数组件中处理副作用。

## 问题

很多开发者不理解依赖数组，导致组件无限刷新或数据不更新。

## 解决

1. 把请求写在 useEffect 里。
2. 用 `[]` 表示只执行一次。
3. 把会变化的变量放进依赖数组。

## 价值

掌握 useEffect 可以减少 bug，提升代码可维护性。
