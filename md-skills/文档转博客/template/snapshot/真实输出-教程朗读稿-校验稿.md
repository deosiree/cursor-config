# 播客朗读稿：useEffect 与依赖数组（教程体）

## 卷首要点

**主播**：场景钩子——很多人照着文档写 useEffect，页面却无限刷新，多半是依赖数组没对齐。今天先记住三条：副作用和渲染分开管；依赖数组决定何时再跑；漏依赖和写错依赖是两类 bug。  
**嘉宾**：对，先分清画界面和画完再干活。  
[停顿]

## 一、副作用与 useEffect

### 铺垫

**主播**：本节搞懂副作用——会出现渲染、请求、订阅。  
**嘉宾**：渲染是画 UI；副作用是画完之后才去干的事，比如拉接口。  
[停顿]

### 追问

**主播**：useEffect 干什么？  
**嘉宾**：告诉 React 这轮 commit 之后跑这段函数。块末记一句：渲染归渲染，副作用归 useEffect。  
[停顿]

## 二、依赖数组

### 铺垫

**主播**：三种写法：不写、`[]`、写变量。  
**嘉宾**：不写是每画一次就响；空数组是挂载响一次；写变量是变了才响。  
[停顿]

### 追问

**主播**：无限刷新先查什么？  
**嘉宾**：effect 里 setState 是否把该 state 写进依赖。  
[停顿]

## 卷尾·快问快答（共 3 题）

**主播**：快问一，useEffect 管什么？  
**嘉宾**：渲染之外的副作用。  
[停顿]

**主播**：快问二，空数组表示什么？  
**嘉宾**：挂载后执行一次。  
[停顿]

**主播**：快问三，无限刷新先查什么？  
**嘉宾**：setState 与依赖是否互相打架。
