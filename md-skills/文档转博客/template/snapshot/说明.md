# Snapshot 模板说明

**用途**：完整交付（朗读稿 + 详细解答 + MP3 + SRT）的**真实成品快照**。Agent 生成完整三件套前**必须先读**本目录，模仿文件命名、frontmatter、U 型密度与口语/书面分工。

**真实案例**：

| 类型 | 文件 |
| --- | --- |
| 面经（完整三件套） | `真实输出-朗读稿摘录.md`、`产物清单.md` |
| 教程（半量，无面试） | `真实输出-教程朗读稿摘录.md`、`任务输入-教程示例.md` |
| 超长源文 N>7 | `任务输入-超长方案.md`（检查点 A 话术） |

**勿**：把面经摘录里的公司名 / RAG 数字照抄到无关源文；只学**结构与节奏**。
