# few-shot 示例

## 输入示例

```text
仓库根目录：microfb
目标输出目录：docs/mvp
文档目标：生成架构拓扑、状态链路、说明文档与 README 索引
输出粒度：多文件
目标受众：接手该基座的前端开发者
```

## 期望行为

1. 先扫描仓库，而不是直接写文档。
2. 如入口模块或输出范围不明确，先向人提问。
3. 信息充分后，再选择拓扑、符号定位、写作、索引等节点推进。
4. 输出本轮认知、缺失事实和下一步动作。
5. 子 skill 的 few-shot 必须来自真实模板成品，而不是抽象占位说明。
