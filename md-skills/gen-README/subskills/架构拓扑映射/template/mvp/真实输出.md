# 真实输出

- 主容器：`microfb`（Vue3 + Vite）作为 qiankun 主应用，挂载并管理多个子应用（示例：`Apex`）
- 权限链路：`setupPermission()` 负责“未登录拦截 -> 登录跳转 -> 动态路由生成 -> 入口菜单落点”
- 登录后置：`user.store.finalizeV2Login()` 负责写入 `userInfo`、菜单缓存、同步 props、跳转首个菜单
- 运行时主链路：`User -> Router -> Guard -> PermissionStore -> registerApps`
- 待确认问题：是否需要在当前轮补“首次登录关键组件关系”的拓扑补图

边界分层：

- 主容器：`microfb WebApp`
- 外部依赖：`SecCenter API`
- 本地存储：`Browser Storage`
- 子系统：`Qiankun 子应用`

关键链路骨架：

```text
用户 -> Router -> setupPermission -> PermissionStore.generateRoutes -> router.addRoute -> registerApps
```

真实边界样板：

```text
用户 -> microfb WebApp -> Browser Storage
microfb WebApp -> SecCenter API
microfb WebApp -> Qiankun 子应用
```
