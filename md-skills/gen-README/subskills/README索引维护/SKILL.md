# README索引维护

## 适用场景

- 文档结构已经变化，需要同步导航入口。
- 需要保证主题、目录和实际产物之间的可发现性。

## 核心规则

- 索引只反映真实产物，不预先占位不存在的文档。
- 索引层级要与结构规划保持一致。
- 读者导航方式不明确时先问人。

## 最小节点契约

- 输入证据：最新产物清单、原 README、结构规划结果。
- 输出结果：更新后的索引方案、缺失链接、待确认问题。
- 失败条件：无法判断哪些产物应进入顶层导航。
- 人工澄清回退：导航层级不清楚时先提问。

## RED

- 常见失败：正文更新了，索引没改；或索引提前挂上不存在的文档。

## GREEN

- 至少给出一份可导航的 README/索引更新方案。

## REFACTOR

- 若索引仍然过深或过散，继续压缩层级。

## 使用示例

```text
请根据最新产物清单更新 README 和主题索引，不要为不存在的文档占位。
```
