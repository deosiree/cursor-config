# Mermaid图语法修复

## 适用场景

- 需要修复 Mermaid 图的渲染失败、语法歧义或不稳定写法。
- 需要在不改变图意的前提下统一图语法。

## 核心规则

- 只修语法与表达稳定性，不擅自改图意。
- 如果修复会改变图意，先问人。
- 输出要包含问题列表和修复结果。

## 最小节点契约

- 输入证据：原始图块、图类型、图规范、上下文文档。
- 输出结果：修复后的图、问题列表、待确认歧义。
- 失败条件：仅靠语法修复无法保证图意不变。
- 人工澄清回退：修复会影响图意时先提问。

## RED

- 常见失败：把“修语法”做成“改语义”。

## GREEN

- 至少给出修复后的图和问题清单。

## REFACTOR

- 若仍频繁误改图意，继续收紧边界说明。

## 使用示例

```text
请修复这段 Mermaid 图语法，但不要改变原图表达含义。
```
