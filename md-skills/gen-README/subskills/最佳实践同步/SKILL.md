# 最佳实践同步

## 适用场景

- 当前 skill 规则需要外部依据支撑。
- Mermaid 或 Cursor Skills 规范可能已发生变化。

## 核心规则

- 先明确要验证的规则范围，再去同步外部依据。
- 只引入和当前节点直接相关的官方或主文档依据。
- 范围不清楚时先问人，不做泛泛搜索。

## 最小节点契约

- 输入证据：待验证规则、当前 skill 文案、相关本地规范。
- 输出结果：更新建议、依据来源、是否需要回写本地规则。
- 失败条件：无法明确要同步哪类规则。
- 人工澄清回退：范围不清楚时先提问。

## RED

- 常见失败：没有明确问题就泛搜，结果引入无关规范。

## GREEN

- 至少给出一条可追溯依据和一条回写建议。

## REFACTOR

- 若同步结果仍然过泛，继续收缩检索范围。

## 使用示例

```text
请核对当前 Mermaid 约束是否仍符合官方最佳实践，并给出必要的回写建议。
```
