# 文档内容生成

## 适用场景

- 需要把已收敛的事实与结构写成实际文档。
- 需要按既定结构插入符号定位和图决策结果。

## 核心规则

- 没有事实支撑的章节先不写，先回到人工澄清或上游证据节点。
- 正文必须服务于目标受众和既定结构，不擅自改主题矩阵。
- 图相关内容只消费上游判定结果，不自行改判。

## 最小节点契约

- 输入证据：结构规划、源码证据、符号定位、图类型决策、目标受众。
- 输出结果：文档草稿或修订稿、符号定位段、待确认缺口。
- 失败条件：关键章节必须依赖猜测才能完成。
- 人工澄清回退：事实不足以支撑正文时先提问。

## RED

- 常见失败：把模板当事实、边写边猜结构、没有缺口就硬凑完整稿。

## GREEN

- 至少产出一份与事实一致、结构一致的正文草稿。

## REFACTOR

- 若正文冗长或偏离受众，继续收缩到本轮最小可读版本。
