# 源码符号定位

## 适用场景

- 需要给正文或图中的节点提供源码落点。
- 需要把抽象概念收敛到真实实现。

## 核心规则

- 只输出能回溯到源码的定位结论。
- 多个候选实现无法裁决时，先问人。
- 定位结果必须包含文件和关键读写点。

## 最小节点契约

- 输入证据：待定位概念、源码候选文件、已有图或草稿。
- 输出结果：文件、函数、变量、读写点、待确认候选项。
- 失败条件：多个候选实现都合理且无法排除。
- 人工澄清回退：定位结论会改变文档含义时先提问。

## RED

- 常见失败：只给抽象描述，不给源码落点。

## GREEN

- 至少给出文件、函数或变量中的两类落点。

## REFACTOR

- 若定位粒度过粗，继续补充读写点。
