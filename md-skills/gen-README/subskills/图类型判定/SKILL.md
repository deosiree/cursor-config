# 图类型判定

## 适用场景

- 需要决定某一主题该用结构图还是时序图。
- 需要在出图前先做稳定的图类型收敛。

## 核心规则

- 先看表达目标，再看源码事实，不凭个人偏好选图。
- 图类型存在高歧义时先问人。
- 输出必须包含类型结论和选择理由。

## 最小节点契约

- 输入证据：目标主题、源码事实、已有草稿、图规范。
- 输出结果：图类型、选择理由、待确认问题。
- 失败条件：两类图都合理且无法排除其一。
- 人工澄清回退：歧义无法裁决时先提问。

## RED

- 常见失败：看到流程就默认 `flowchart TD`，或把交互时序误写成结构图。

## GREEN

- 至少给出图类型结论和理由。

## REFACTOR

- 若仍频繁误判，继续补 should-not-trigger 和 few-shot。

## 使用示例

```text
请判断“登录到首屏”更适合用结构图还是时序图，并说明原因。
```
