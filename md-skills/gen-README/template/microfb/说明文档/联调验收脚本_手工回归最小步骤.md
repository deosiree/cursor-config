# 说明文档：联调验收脚本（手工回归最小步骤）

本文档目标：给联调/提测/发布前提供一套“最小但关键”的手工回归步骤。  
特点：步骤短、覆盖高风险路径、失败后能快速定位到模块。

## 1. 前置条件

- 已启动 `microfb` 与至少一个子应用（建议 Apex）。
- 已准备两个测试账号：
  - 账号 A：权限较高（菜单较多）
  - 账号 B：权限较低（菜单较少）
- 已确认当前环境变量与目标环境一致（特别是 `VITE_APP_BASE`、`VITE_SUBAPP_MODE`、登录桥接相关变量）。

## 2. 回归用例脚本（建议顺序执行）

### 用例 1：未登录访问受保护页

**步骤**
- 清理本地登录信号（确保 `userInfo` 不存在）。
- 直接访问任意受保护路径（例如业务页面 URL）。

**预期**
- 被重定向到 host 登录页或本地 `/login?redirect=...`。
- 不出现跳转死循环。

**失败定位**
- `src/plugins/permission.ts`：`redirectToLogin`
- `src/utils/auth-mode.ts`：`buildHostLoginUrl`
- `src/utils/auth.ts`：`Auth.isLoggedIn`

---

### 用例 2：登录后首页落点

**步骤**
- 用账号 A 登录（非 MFA 流程）。
- 登录后观察首次落点页面。

**预期**
- 若菜单缓存有可用路径，落到 `findFirstValidMenuPath` 对应页面。
- 否则回退到 `DEFAULT_HOME_PATH`。

**失败定位**
- `src/store/modules/user/user.store.ts`：`finalizeV2Login`
- `src/plugins/permission.ts`：`resolveEntryMenuPath`
- `src/utils/menu.ts`：`findFirstValidMenuPath`

---

### 用例 3：并发导航稳定性（防重复生成路由）

**步骤**
- 在首次进入系统（动态路由尚未稳定时），快速连续点击多个菜单。

**预期**
- 页面最终进入可用路由，无卡死。
- 不应出现大面积 404。

**失败定位**
- `src/plugins/permission.ts`：`isGeneratingRoutes` / `waitForRoutesGeneration` / `generateAndAddRoutes`
- `src/store/modules/permission.store.ts`：`generateRoutes`

---

### 用例 4：菜单刷新无刷新生效

**步骤**
- 触发菜单刷新操作（调用 `refreshCurrentUserMenus` 的业务入口）。
- 保持当前页面不刷新，观察菜单与页面行为。

**预期**
- 菜单更新后生效。
- 如果当前路由已失效，自动回退到首菜单或默认首页。

**失败定位**
- `src/store/modules/user/user.store.ts`：`refreshCurrentUserMenus` / `rebuildDynamicRoutesAfterMenuUpdate`
- `src/store/modules/permission.store.ts`：`reloadRoutesFromCache`

---

### 用例 5：子应用挂载与 props 同步

**步骤**
- 进入子应用激活路径（如 Apex 对应路径）。
- 登录后再进行一次菜单刷新，观察子应用侧菜单/权限是否感知变化。

**预期**
- 子应用正常挂载。
- 子应用能读取到最新 `menuList/menuVersion/userInfo`。

**失败定位**
- `src/plugins/qiankun/apps.ts`：`registerApps` / `getAppProps` / `setMicroAppProps`
- `src/store/modules/appConfig.store.ts`：`getPersistedAppConfigs`

---

### 用例 6：登出强解散与切换账号防串权

**步骤**
- 使用账号 A 登录并进入业务页。
- 执行登出。
- 使用账号 B 登录并进入业务页。

**预期**
- 登出后即使后端登出失败，也会清理本地状态并跳回登录。
- 账号 B 不应看到账号 A 的菜单/权限（无串权）。

**失败定位**
- `src/store/modules/user/user.store.ts`：`logout` / `resetUserState`
- `src/services/menu/menu-repo.ts`：`clearMenuCache`
- `src/plugins/qiankun/apps.ts`：清空子应用 props
