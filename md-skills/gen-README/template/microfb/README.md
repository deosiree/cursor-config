# microfb 文档（MVP）

本目录用于把 `microfb` 的关键架构与状态链路“以源码为准”固化为可版本化文档。

## 1. 总览类文档

- `前端架构拓扑图.md`：静态拓扑（系统边界 + 关键组件关系）
- `架构拓扑补充_首次登录关键组件关系.md`：首次登录视角的组件边界与关键依赖流
- `运行时拓扑_登录到首屏.md`：从入口到首屏可用的运行时链路（sequenceDiagram：简洁版 + 细节版）
- `状态驱动说明书_登录与会话校验.md`：登录/会话校验的状态模型、事件、守卫、副作用与验收清单
- `流程图符号定位表.md`：图中符号到源码（常量/函数/store 字段）定位表
