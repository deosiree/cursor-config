# 目标
在不破坏 Markdown 结构的前提下产出可直接使用的中文文档。

## 执行步骤
1. 识别输入是单文件还是目录。
2. 校验路径并确定输出位置。
3. 翻译正文内容，保留代码块、表格、frontmatter。
4. 写入目标文件（单文件 `-cn.md`；目录 `-cn/`）。

## 约束
1. 只翻译 `.md` 文件。
2. 保持路径与层级一致。
3. 技术术语优先保持一致性而非字面直译。

## 输出要求
1. 返回源路径与目标路径。
2. 标注翻译文件数量与失败项（如有）。

## 外部最佳实践校验（必做）
1. 无论是否使用本 skill，都先进行一次 web search，确认当前任务的最佳实践与最新约束。
2. 优先来源顺序：官方文档 > 标准组织/维护者仓库 > 高质量技术文档。
3. 至少引用 2 个来源；高风险任务（生产、权限、安全、数据）至少 3 个来源交叉验证。
4. 输出中必须包含：来源链接、采纳点、未采纳点与原因。
5. 若检索结果不足或冲突，必须明确不确定性并给出保守方案。
