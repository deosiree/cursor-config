# 技术文档 N/K 与 doc_type 契约

> 唯一正文来源。`QA转面经` 与 `文档转播客` 均双链引用本文件，避免 N/K、doc_type、检查点 A 两处漂移。

## N 与 K

| 符号 | 含义 | 计算 |
|------|------|------|
| **N** | `knowledge_points`：独立知识点/主章节数 | 从源文或 QA 上下文统计 |
| **K** | `quick_qa_count`：卷尾快问快答题数 | `K = min(max(3, N), 7)` |

## doc_type 与场景钩子

| doc_type | 场景钩子（泛称，不写死公司） |
|----------|------------------------------|
| 面经 | 源文面试张力、递进追问链 |
| 技术方案 | 线上问题 / 需求冲突 |
| 教程 | 学习者卡点 |
| 参考 | 照文档仍踩坑 |

未指定时由分析节点自动判定；QA转面经 默认倾向 `面经`。

## 检查点 A（N > 7）

禁止静默输出超长单稿。必须先向用户确认其一：

1. **合并章节**（压缩 N）
2. **拆成多篇/多集**（每篇 N≤7）
3. **继续单篇**（用户明确接受超长，须在回复中警告）

话术模板见各 skill 的 `template/snapshot/任务输入-超长方案.md`（文档转播客）或编排步骤 1.5 输出。

## 检查点 B（仅文档转播客 · 摘要）

> **完整条文与决策树**以 [`文档转播客/SKILL.md`](../../md-skills/文档转播客/SKILL.md) §检查点 B 为准；本段仅为摘要，避免双处维护漂移。

- **不因 N≤2 或篇幅自动降级为轻量**，也不因未指定模式而二次询问用户。
- 用户已明确 `交付模式` 时：采用并在回复中写明，**不询问**。
- 仅当用户表述**互相矛盾**（如同时要 MP3 又只要稿）时反问确认。

| 用户表述 | 交付模式 |
| --- | --- |
| 「只要朗读稿」「只要稿」「只要文字」 | **轻量** |
| 「不要音频」「不要字幕」「不要 MP3」 | **半量** |
| 「要 MP3/字幕/详细解答」，或 **未提模式**（含 `$文档转播客` + 文档路径） | **完整**（默认） |

## 联动约定（QA转面经 → 文档转播客）

| 项 | 约定 |
| --- | --- |
| 触发 | 经验贴落盘后**询问**用户，禁止静默调用 |
| 输出目录 | `{面经父目录}/{stem}/`，`stem` = 面经文件名去 `.md`；**禁止**默认 `podcast/` |
| 交付模式 | 用户未指定 → **完整**（不再检查点 B 二次确认） |

详见 QA转面经 [`references/operating-guide.md`](../../agent-skills/QA转面经/references/operating-guide.md)。
