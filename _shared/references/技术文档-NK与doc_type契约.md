# 技术文档 N/K 与 doc_type 契约

> 唯一正文来源。`QA转面经` 与 `文档转播客` 均双链引用本文件，避免 N/K、doc_type、检查点 A 两处漂移。

## N 与 K

| 符号 | 含义 | 计算 |
|------|------|------|
| **N** | `knowledge_points`：独立知识点/主章节数 | 从源文或 QA 上下文统计 |
| **K** | `quick_qa_count`：卷尾快问快答题数 | `K = min(max(3, N), 7)` |

## doc_type 与场景钩子

| doc_type | 场景钩子（泛称，不写死公司） |
|----------|------------------------------|
| 面经 | 源文面试张力、递进追问链 |
| 技术方案 | 线上问题 / 需求冲突 |
| 教程 | 学习者卡点 |
| 参考 | 照文档仍踩坑 |

未指定时由分析节点自动判定；QA转面经 默认倾向 `面经`。

## 检查点 A（N > 7）

禁止静默输出超长单稿。必须先向用户确认其一：

1. **合并章节**（压缩 N）
2. **拆成多篇/多集**（每篇 N≤7）
3. **继续单篇**（用户明确接受超长，须在回复中警告）

话术模板见各 skill 的 `template/snapshot/任务输入-超长方案.md`（文档转播客）或编排步骤 1.5 输出。

## 检查点 B（仅文档转播客）

交付模式：N≤2 或「只要朗读稿」→ 轻量；「不要音频」→ 半量；否则完整。用户已指定时跳过询问。

## 联动约定（QA转面经 → 文档转播客）

经验贴落盘后，经用户确认再调用文档转播客；播客目录 = 经验贴文件 **stem** 同名子目录（见 QA转面经 `references/operating-guide.md`）。
