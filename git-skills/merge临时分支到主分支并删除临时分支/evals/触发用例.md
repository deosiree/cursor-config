# 触发用例

## should-trigger

1. 「把临时分支合进 main，然后删掉，先别 push。」
2. 「不需要 auto-optimize/… 了，整支 merge 到 main。」
3. 「收工：merge 进 develop 并删除功能分支。」

## should-not-trigger

1. 「只要中间三次 commit」→ cherry-pick skill
2. 「工作区还有未提交改动，先帮我合进去」→ 先停下清干净 / 提交
3. 「推上去开个 PR，不要本地 merge」→ PR 工作流，非本 skill

## 验收要点

- 脏树必须 STOP
- 合并范围须 CHECKPOINT-1
- 默认删本地临时分支但仍须确认
- 默认不 push
