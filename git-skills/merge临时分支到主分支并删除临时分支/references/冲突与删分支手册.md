# merge 冲突与删分支手册

## 冲突

`git merge` 冲突时：

1. 解决文件
2. `git add <files>`
3. `git commit`（完成 merge；勿再 `merge --continue`，那是 rebase/cherry-pick 用语）

放弃整次：

```bash
git merge --abort
```

须用户明确选择后再 abort。

## 删除本地临时分支

merge 已验收后：

```bash
git branch -d <source_branch>
```

`-d` 在「尚未合入」时会拒绝，这是保护。仅当用户明确强制删除且知情时才用：

```bash
git branch -D <source_branch>
```

## 远端（默认不做）

```bash
git push <remote> <target_branch>
git push <remote> --delete <source_branch>
```

须分别确认。
