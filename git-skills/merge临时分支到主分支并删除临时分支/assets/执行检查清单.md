# 执行检查清单

## 启动前

- [ ] 已解析 `repo` / `source_branch` / `target_branch`
- [ ] `git status --short` 为空
- [ ] 已展示 `target..source` 范围并过 🔴 CHECKPOINT-1
- [ ] 未误用 cherry-pick 代替整支 merge

## 执行

- [ ] `git checkout <target_branch>`
- [ ] 仅授权时才 `pull`
- [ ] `git merge --no-ff <source>`（或用户指定的模式）
- [ ] 冲突时停在 CHECKPOINT-2，不擅自 abort

## 收尾

- [ ] log/status/ancestor 验收通过
- [ ] CHECKPOINT-3 后才 `branch -d`
- [ ] 未默认 push（CHECKPOINT-4）

## 输出字段

`currentUnderstanding` / `worktreeClean` / `plannedCommand` / `status` / `nextAction`
