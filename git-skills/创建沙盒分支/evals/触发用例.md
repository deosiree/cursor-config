# 触发用例

## should-trigger · 创建

1. 「基于 develop 给 apex_dev 开沙盒分支 devmgr，恢复 stash@{0}。」
2. 「开一个 worktree 沙盒并发做场站名称，主仓继续做菜单导入。」
3. 「按 sibling 惯例新建沙盒，先别 push。」

## should-trigger · 删除

1. 「devmgr 沙盒不要了，安全删掉 worktree 和本地分支。」
2. 「拆掉 apex_devmgr；未合入的话先问我。」
3. 「沙盒收工了（已合入），清掉本地沙盒目录。」

## should-stop-or-ask

1. 「给我开个沙盒吧」无分支名 → 追问，禁止猜测
2. 「删掉但未授权放弃未合入 / 丢弃脏树」→ CHECKPOINT / STOP

## should-not-trigger

1. 「整支 merge 进 develop 再删临时分支」→ merge skill
2. 「只要中间三次 commit 挑过去」→ cherry-pick skill
3. 「把 develop 删了」→ STOP / 不激活删除
4. 「在沙盒里把场站名称功能写完」→ 业务实现，非本套件生命周期

## 验收要点

- 创建：主仓干净、stash 冲突不 drop、默认不 push
- 删除：先风险检查点；先 remove 再删分支；默认不 force、不删远端
- 父级只路由；细节在 intention/feature
