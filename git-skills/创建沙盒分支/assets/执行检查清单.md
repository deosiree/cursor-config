# 执行检查清单

## 共用

- [ ] 已解析 `repo`
- [ ] 已跑 `分析-沙盒现状`
- [ ] `策略-创建或删除` 给出唯一 `intent`
- [ ] 未误用本套件做 merge/cherry-pick/业务实现

## 创建

- [ ] 主仓干净
- [ ] 路径/分支无碰撞
- [ ] `worktree add -b` 成功；主仓仍在原分支
- [ ] stash：apply → 无冲突才 drop
- [ ] 切仓失败时已给出绝对路径
- [ ] 未默认 push

## 删除

- [ ] 非受保护分支
- [ ] 已展示脏树 / 合入 / 远端风险
- [ ] CHECKPOINT 已确认
- [ ] 先 `worktree remove` 再 `branch -d/-D`
- [ ] 未授权不 `--force`、不 `-D`、不删远端

## 输出字段

`currentUnderstanding` / `intent` / `sandboxPath` / `sandboxBranch` / `status` / `nextAction` / `riskFlags`
