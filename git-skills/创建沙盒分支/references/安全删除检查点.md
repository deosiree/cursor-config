# 安全删除检查点

删除前必须向用户展示：

1. `sandbox_path`、`sandbox_branch`
2. `dirty` 与脏文件摘要
3. `mergedIntoBase`（相对 `base_branch`）
4. `hasUpstream` / 是否拟删远端
5. 将使用的命令级别：`worktree remove` 是否 `--force`；`branch -d` 还是 `-D`

## 授权矩阵

| 标志 | 默认 | 含义 |
| --- | --- | --- |
| `allow_discard_dirty` | false | 允许丢弃未提交改动后 remove |
| `allow_delete_unmerged` | false | 允许放弃未合入分支（启用 `-D`） |
| `force_remove_worktree` | false | 允许 `worktree remove --force` |
| `delete_remote` | false | 允许 `push --delete` |

## 受保护

永远拒绝：`develop`、`main`、`master`、主仓当前检出分支。
