# 示例：安全删除未合入沙盒

## 用户请求

`devmgr` / `apex_devmgr` 不要了（未合入 develop），帮我安全删除；有未提交改动先问我，不要默认 force。

## Agent 执行摘要

1. **分析-沙盒现状**：worktree 列表含 `apex_devmgr` → `devmgr`。
2. **策略**：`intent=delete`（非 merge）。
3. **检查风险**：
   - `dirty=true`（若有 WIP）→ STOP，询问丢弃 / 先 stash / 取消
   - `mergedIntoBase=false` → CHECKPOINT：确认「放弃未合入分支」才继续
4. 用户确认：`allow_discard_dirty`（如需要）+ `allow_delete_unmerged=true`。
5. **移除 worktree**：`git worktree remove <path>`（无二次 force 授权不用 `--force`）。
6. **删分支**：`git branch -D devmgr`（因未合入且已确认放弃）。
7. **验收**：worktree list 无该路径；本地无 `devmgr`；未删远端。

## 若用户改口「先合进 develop」

改路由到 `merge临时分支到主分支并删除临时分支`，本编排不执行 merge。
