# 缺少段落空行的反例与修正

## 反例

下面是一段被压成单行的 Issue 正文：

```text
问题描述：筛选后的导出内容与页面不一致。复现步骤：选择一个筛选条件并导出。实际结果：文件包含筛选范围外的数据。预期结果：文件只包含当前筛选结果。验收标准：导出内容符合当前筛选条件。
```

在 GitLab Markdown 中，单个换行不会开始新段落；这种写法无法清楚呈现每个字段的层级。

## 修正版

```markdown
## 问题描述

筛选后的导出内容与页面不一致。

## 复现步骤

选择一个筛选条件并导出。

## 实际结果

文件包含筛选范围外的数据。

## 预期结果

文件只包含当前筛选结果。

## 验收标准

- [ ] 导出内容符合当前筛选条件。
```

修复只调整区块和空行；对真实 Issue 做格式修复时，应保留原有业务文字、事实、标题、状态和验收含义。
