**标题：** `配置保存后列表没有保留其他条目`

**正文：**

```markdown
## 问题描述

在配置列表中编辑并保存一项后，页面提示保存成功，但列表内容看起来不完整。

## 复现步骤

1. 打开包含多条记录的配置列表。
2. 编辑其中一条记录并保存。
3. 查看保存后的列表。

## 实际结果

列表只显示当前编辑的记录。

## 预期结果

列表仍显示所有原有记录，只有当前编辑项发生变化。

## 验收标准

- [ ] 保存后列表记录数与保存前一致。
- [ ] 当前编辑项显示新值，其它记录保持原值。
```
