## 已确认背景与范围

- API 响应错误经 `src/http/request.js` 的 `message.error` 展示；前端异步错误也经 `notification.error` 和 `src/utils/notificationUtils.js` 展示。错误通知 helper 默认 `duration: 0`，部分生产调用也显式设为 `0`。
- 词条字段校验失败只显示对应单元格红字，不弹全局 notification。
- 本 Issue 覆盖的 API 响应错误与前端异步错误统一样式并显示在右下角。
- 普通错误通知默认在 `3000ms` 后自动关闭。
- 响应包含 `response.data.code` 时按原值显示 `[code]` 前缀，包括通用错误码 `201`；不修改后端协议，不以 HTTP status 推测业务码。
- 高频和批量错误逐条显示并按时关闭；不合并、不去重、不限制同时显示数量。
- 顶层全局错误历史抽屉显示最近 3 天内记录，最多 100 条；过期清理，满额淘汰最旧记录。历史只存在前端，不新增后端 API、数据库或其他后端功能。
- 词条字段校验失败只显示单元格红字，不弹全局 notification；非字段校验的请求/保存失败仍按统一错误通知展示。
- 同一次失败不得由响应拦截器和调用方 catch 重复提示。
- 登录过期后的清理与跳转行为保持原样；成功、普通信息和警告通知不在本 Issue 范围内。
