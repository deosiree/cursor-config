# MVP 模板

按以下顺序创建项目材料：

1. `goal.md`：项目目标和全局验收锚点。
2. `issue-graph.md`：Issue 依赖表和展示图。
3. `issues/<issue-id>/develop.md`：每个 Issue 一份计划。

先在当前会话澄清高影响歧义，再确认 Goal。未获 GitHub 写入授权时只保留本地 Issue 草稿。

下方 `goal.md` 和 `issue-graph.md` 是项目草稿。创建 Issue `#N` 后，将 `I-01` 的计划复制为 `issues/I-01/develop.md`，并补全 Issue URL、路径边界和实际验证命令。
