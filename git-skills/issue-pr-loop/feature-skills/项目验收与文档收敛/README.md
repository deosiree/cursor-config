# 项目验收与文档收敛

负责在 Issue 实现阶段结束后，对照项目 Goal 验证集成行为、性能、安全和文档一致性。

## 适用场景

- 所有实现 Issue 合并后，准备最终交付。
- 需要证实功能是否正常，而不是只看 Issue 状态或 PR 文字。
- 对照初始目标排查代码、测试、PR、用户文档的漂移。

## 与相邻节点边界

- [[../../intention-skills/项目规划与Issue图谱/SKILL.md]] 负责建立和修订验收目标。
- [[../单Issue开发与PR闭环/SKILL.md]] 负责修复单 Issue 的实现和 PR 审查意见。
- 本节点不降低指标、不代替安全授权或人工产品验收。
