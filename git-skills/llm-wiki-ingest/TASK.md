# 可复用任务：LLM Wiki 来源摄取

## 任务输入

- **来源：**填写用户明确指定的 URL、文件、对话文本或笔记。
- **目标 Wiki：**填写本机 Wiki 根目录；先确认目录和本地规范。
- **范围：**只处理本次明确指定的来源及必要的 canonical 关联页。
- **目标读者：**同时面向人类阅读与 Agent 检索；按来源主题补充背景和适用边界。

## 执行指令

请使用同目录 `SKILL.md` 的 LLM Wiki ingest 流程，并遵守目标 Wiki 的 `AGENTS.md`、`SCHEMA.md` 和现有页面格式。

完整阅读来源，保存可核验的原始快照，不修改原始来源文件。来源没有独立 URL 时，注明它来自用户消息，不得伪造出处。把内容整理到合适的 canonical 目录，区分来源事实、综合解释与推断；链接相关页面并更新索引、页面总数和日志。

复杂技术内容不能只生成纯文字页面：按内容识别概念层级、实体关系、架构/决策结构和调用顺序，分别使用 `mindmap`、`erDiagram`、`flowchart`、`sequenceDiagram`。图放在对应正文附近，每图后添加阅读提示；所有实体、箭头、关系和基数须有来源依据，推断须明示。仅当 Mermaid 不适用时才生成独立 HTML 图，并核验所有资源路径。

完成写入后立即 lint 本次变更，检查 frontmatter、标签、来源和哈希、双链、索引覆盖与页数、日志、原文保留、Mermaid 围栏、图文一致性、图的位置、阅读提示及 HTML/资源路径。修复后重跑。未通过项未解决前，不得报告完成。

## 最终报告

逐项报告：

- 新建和更新文件的相对路径。
- 生成的图及其类型。
- 来源快照保留与哈希核验结果。
- 索引、页面总数和日志检查结果。
- Mermaid、图文依据、位置、阅读提示及资源路径检查结果。
- 未通过或无法验证的项目；若存在，明确说明任务尚未通过 lint。
