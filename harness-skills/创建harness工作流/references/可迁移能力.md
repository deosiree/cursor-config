## 使用规则

1. 无 harness：先 P0 全绿，再选 P1 中的审查导览 + 质量 Loop（含证据阶梯）。  
2. 旧 harness：按表勾缺口，合并进现有文档，不毁历史。  
3. **禁止**把「样例仓特例」写成与上表并列的「必学能力」。特例只放 `[[样例-Nebula.md]]`。  
4. 源仓学会新范式后：走套件 `intention-skills/编排-同步skill收益`，经 `提炼可迁移能力条目` 追加本表；**不要**手改父 `SKILL.md` 堆流程。
