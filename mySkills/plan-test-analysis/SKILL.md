# 目标
降低“做完才发现没法验证”的返工风险。

## 执行步骤
1. 计划：拆解目标、范围、假设、里程碑。
2. 测试：定义成功标准、关键测试集、失败判据。
3. 分析：记录结果、偏差原因、风险与后续动作。

## 输出模板
1. 计划清单（P0/P1）。
2. 测试矩阵（场景/预期/结果）。
3. 分析结论（通过项/失败项/风险项）。

## 约束
1. 每个 P0 项必须有对应验证项。
2. 失败项必须有处置路径（修复或降级）。

## 外部最佳实践校验（必做）
1. 无论是否使用本 skill，都先进行一次 web search，确认当前任务的最佳实践与最新约束。
2. 优先来源顺序：官方文档 > 标准组织/维护者仓库 > 高质量技术文档。
3. 至少引用 2 个来源；高风险任务（生产、权限、安全、数据）至少 3 个来源交叉验证。
4. 输出中必须包含：来源链接、采纳点、未采纳点与原因。
5. 若检索结果不足或冲突，必须明确不确定性并给出保守方案。
