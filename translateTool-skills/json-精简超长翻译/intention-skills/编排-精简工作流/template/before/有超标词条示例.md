# 检测报告有超标

## 检测报告摘要

```json
{
  "totalEntries": 8,
  "overlongCount": 8,
  "overlongEntries": [
    { "index": 0, "source": "所属数据时段描述", "bytes": 70, "limit": 63, "charBudget": 30 },
    { "index": 1, "source": "单表秒级采样点数上限", "bytes": 150, "limit": 63, "charBudget": 25 }
  ]
}
```

## 判断

hasOverlong = true → nextAction = "shorten"
