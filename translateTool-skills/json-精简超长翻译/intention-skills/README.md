# 意图层

## 职责

判断"当前该做什么"——校验输入、编排流程，而不是直接执行。

## 节点

| 节点 | 判断内容 | 输出到 |
|------|---------|--------|
| `分析-输入确认` | inputPath / fieldPath / byteLimit 是否有效 | 下一步 intention 或直接中止 |
| `编排-精简工作流` | 检测报告有无超标、走缩短还是跳过 | feature 节点 |

## 边界

- 意图层只输出判断结论和路由目标，不执行具体功能。
- 具体功能落地（运行脚本、LLM 缩短、写输出）下沉到 `feature-skills/`。
