# 完整使用示例

以下演示从检测到缩短再到回验输出的全流程，使用上一个任务的真实数据。

## 1. 检测

```bash
node scripts/check-russian.js \
  --mode detect \
  --input "F:\Documents\Repertory\Sieyuan\translationtool\docs\1.9.0翻译过长\db" \
  --field-path "translation.ru_RU" \
  --byte-limit 63
```

**检测结果**：8 条全部超标，检测报告给出每条字符预算。

## 2. LLM 缩短

参考检测报告的 charBudget 缩短俄语。示例对照：

| index | 原译文 | 原字节 | charBudget | 缩短后 | 新字节 |
|-------|--------|--------|-----------|--------|--------|
| 0 | Описание назначенного периода данных? | 70 | 29 | Описание заданного периода данных | **63** |
| 1 | Верхний предел количества точек дискретизации на уровне секунд для одной таблицы | 150 | 26 | Лимит точек дискр./сек на таблицу | **60** |
| 2 | Включает дневной временной интервал | 67 | 30 | Включает дневной интервал | **48** |
| 3 | Диапазон дискретизации по умолчанию | 67 | 30 | Диапазон дискретизации по умолч. | **60** |
| 4 | Количество параллельных потоков дискретизации | 87 | 30 | Число парал. потоков дискр. | **49** |
| 5 | Назначённое описание дневного периода | 71 | 30 | Описание дневного периода | **48** |
| 6 | Максимальное количество точек дискретизации на одну таблицу | 112 | 28 | Макс. точек дискр. на таблицу | **52** |
| 7 | Включает временной интервал данных | 65 | 30 | Включает врем. интервал данных | **56** |

## 3. 回验输出

```bash
node scripts/check-russian.js \
  --mode verify \
  --input "缩短后的文件.json" \
  --field-path "translation.ru_RU" \
  --byte-limit 63 \
  --output-suffix "_new"
```

**回验通过** → 输出到 `db_new/hisparam.dic`，目录结构保持一致。
