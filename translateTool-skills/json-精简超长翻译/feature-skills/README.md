# 功能层

## 职责

落地"怎么做"——运行检测脚本、LLM 缩短俄语翻译、回验并写输出。

## 节点

| 节点 | 能力 |
|------|------|
| `扫描-JSON词条检测` | 运行 check-russian.js --detect，输出检测报告 |
| `执行-俄语LLM缩短` | 参考字符预算，用 LLM 缩短俄语字符串 |
| `执行-回验输出` | 运行 check-russian.js --verify，通过后写输出到 _new 目录 |

## 边界

- 功能层不判断"要不要做"，只执行"怎么做"。
- 每个节点以 SKILL.md 中的输入为前置条件，输出给下个节点或最终用户。
