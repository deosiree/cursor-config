# 解析输出示例（UTF-8 字节视角）

## 原始 .report 条目

```json
{
  "entry": { "source": "修改用户信息", "translation": { "ru_RU": "Изменить информацию пользователя" } },
  "interpretation": "译文长度:62,限制:32"
}
```

## 解析结果

| 字段 | 值 | 说明 |
|------|-----|------|
| source | 修改用户信息 | |
| langKey | ru_RU | 自动检测 |
| actualBytes | 62 | UTF-8 实际字节数 |
| maxBytes | 32 | interpretation 中的字节上限 |
| actualMax | **31** | 开区间：实际最大字节 |
| overBy | 31 | 超出 31 字节 |
| charBudget | **14** | 最多可写 14 个俄文字母 |

## 输出到 _new 目录（无 interpretation）

```json
[
  {
    "comments": "",
    "source": "连接超时",
    "tag": "auditEventDefine/name",
    "translation": { "ru_RU": "缩短后译文" }
  }
]
```
