# 执行-俄语LLM缩短

## 作用

参考检测报告中的字符预算，用 LLM 逐条缩短超长俄语翻译，保留原意，适配 C++ 字符串的 UTF-8 字节限制。

## 资源入口

- 参考：`[[../../references/编码约束说明.md]]`
- 模板：`[[template/before/]]` 超长词条 + 字符预算
- 模板：`[[template/after/]]` 缩短后通过验证的词条
- 校验：`[[evals/evals.json]]`

## 使用示例

```text
检测报告显示第 0 条 70 字节，字符预算 30 个俄文字母。
使用 $执行-俄语LLM缩短 参考预算将其缩短。
```
