# 核心任务

根据检测报告提供的超标词条和字符预算，逐条缩短俄语翻译，保留核心语义。

## 何时触发

- `workflowPlan.nextAction = shorten`

## 输入 / 前置条件

- `workflowPlan.overlongEntries`（超标词条列表，含每条字符预算）
- 字符预算含义：`byteLimit 减去已有空格/符号字节后 ÷ 2` ≈ 可写入的俄文字母数

## 缩短规则

1. **先缩写长词**：`дискретизации` → `дискр.`，`максимальное` → `макс.`，`назначенного` → `назнач.`
2. **删冗余修饰词**：如"временной"在"временной интервал"中可以省略为"врем."或直接删除
3. **换短近义词**：`назначенного` → `заданного`（短 2 字母）
4. **删标点符号**：末尾问号、感叹号可删除（省 1 字节）

## 输出

- `shortenedData`（与原 JSON 同结构，仅更新目标字段）
- `shorteningLog`（每项的 index、原长度、新长度、是否达标）

## 下一步路由

- `shortenedData` → `[[../执行-回验输出/SKILL.md]]`

## 边界

- 它只负责 LLM 缩短，不负责回验字节合规性。
- 缩短后必须保留源语言语义，不允许跳跃式删减导致歧义。
