# Darwin 实跑报告 · db 目录缩短（2026-07-16）

## 背景

路径：`仍然超长\db`（`fileinfo.report` + `secinfo.report`）

| 指标 | 旧流程 | 问题 |
|------|--------|------|
| unique 超标 | 17 条 | 量不大 |
| 总耗时 | **~423s（7min）** | 效率极低 |
| Worker | DeepSeek batch=5 串行 | 多轮 API |
| 轮次 | 3 轮全量重试 | 已 OK 条目重复调用 |
| 讯飞尝试 | batch=15 | **180s timeout** |

## 根因

1. **无 T0 规则层**：`автоматическая`→`авто` 等可机械处理，却全走 LLM
2. **batch 过小 + 串行**：5 条/批 × 多轮 ≈ 8+ 次往返
3. **重试策略差**：round 2/3 重跑全部 pending，含已达标项
4. **讯飞误用**：缩短任务 batch≥15 不稳定

## v2.1 改动

| 改动 | 文件 | 预期收益 |
|------|------|---------|
| T0 `ruleShorten.js` | `lib/ruleShorten.js` | 17 条中预计 8~12 条零 API 达标 |
| 并行 LLM | `shorten-from-report-dir.js` | 3 批并发，latency ÷2~3 |
| batch 12 + max-rounds 2 | CLI 默认 | 减少往返 |
| 仅重试 still | 脚本逻辑 | 不重复计费 |
| SKILL 性能纪律 | `SKILL.md` | Agent 不再跳层 |
