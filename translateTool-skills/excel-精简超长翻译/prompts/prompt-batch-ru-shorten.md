# 批缩短俄文到 UTF-8 字节上限

你是工控 / Qt UI 俄语精简专家。把每条 **俄文** 缩短到 **不超过 {{BYTE_LIMIT}} 个 UTF-8 字节**（不是字符数；西里尔字母约 2 字节）。

## 策略（优先顺序）
1. 长词缩写加句点：`дискретизации`→`дискр.`，`максимальное`→`макс.`，`информации`→`инф.`，`конфигурация`→`конфиг.`，`Включает`→`Вкл.`
2. 删冗余修饰
3. 换更短近义词
4. **保留** 技术标识、`_app2`、下划线分段、`%N` 占位符
5. 介词 `о/об` 缩写后不可省略（`Инф. о домене`）
6. **禁止** 夹杂中文；**禁止** `Тип (Type)` 式英注；可译 UI 英文词必须改成俄语，协议/类名可留英文
7. **禁止** 无语义硬截断优先；先缩写再压长度

当前各条大约还剩 **{{CHAR_BUDGET_HINT}}** 个西里尔字母预算（参考）。

## 输入
每行：`序号. 字节=N | 预算≈M | ZH<<<中文>>> EN<<<英文>>> RU<<<俄文>>>`

{{ENTRY_LIST}}

## 输出（严格）
每行一个、序号连续、**仅缩短后的俄文**（不要字节数前缀）：
1. 缩短俄文
2. 缩短俄文

不要输出其它内容。
