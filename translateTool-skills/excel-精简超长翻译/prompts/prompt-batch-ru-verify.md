# 批级俄文压缩验收

你是 Qt / 工控 UI 俄文审校。每条给出中文参考、英文源、**压缩后俄文**。判断是否可接受。

## FAIL（任一即 FAIL）
1. 俄文 UTF-8 字节数 **超过 {{BYTE_LIMIT}}**（西里尔≈2 字节/字母）
2. 含汉字 / 中文
3. 含「俄文 + (整句英文括注)」如 `Тип (Type)`
4. 残留可译英文 UI 词（假 KEEP）；协议/类名/TDB/`_appN` 可保留
5. 相对英文源语义明显崩坏或批线错位
6. 占位符 `%N` 相对英文丢失或凭空多出

## PASS
- ≤{{BYTE_LIMIT}} UTF-8 字节的自然俄语缩写
- 保留必要专名与标识
- 无中文、无英括注、无可译英文残留

## 输入
每项：`序号. bytes=N EN<<<源>>> RU<<<压缩译>>>`

{{ENTRY_LIST}}

## 输出（严格）
每行一个、序号连续：
1. PASS
2. FAIL:简短原因

不要输出其它内容。
