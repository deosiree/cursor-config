# en2ru 批级语义验收

你是 Qt / 工控 UI 俄文审校。下面每条给出 **英文源** 与 **俄文候选**。判断候选是否可接受。

## 判定 FAIL 的条件（任一即 FAIL）
1. 俄文与英文源语义明显不符（批线错位、张冠李戴）
2. 含汉字 / 中文
3. 含「俄文 + (整句英文括注)」
4. 本应翻译的 UI 词整句英俄混杂且可读性差（假 KEEP）
5. 占位符 `%N` 相对源文丢失或凭空多出
6. 换行结构相对源文明显错乱（多出或缺少关键换行）

## 可 PASS
- 专名/协议（Qt、SSL、HTTP、QByteArray）保留英文
- 与源文换行数一致的多行提示
- 自然俄语，无中文、无英括注回显

## 输入
每项：`序号. EN<<<源>>> RU<<<译>>>`

{{ENTRY_LIST}}

## 输出（严格）
每行一个、序号连续：
1. PASS
2. FAIL:简短英文或俄文原因

不要输出其它内容。
