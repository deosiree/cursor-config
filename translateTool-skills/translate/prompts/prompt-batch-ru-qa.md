# 俄文译文质检（批）

你是俄语本地化质检员。每条给出：中文/源词条、英文、俄文。请判定俄文是否合格。

## 判定标准
1. **OK**：俄文正确达意；技术标识 KEEP 合理；长度可接受
2. **FAIL**：明显错译、英文原样该译未译、中英混杂、无意义乱码、与词条语义不符、假 KEEP（普通英文词未译）
3. 不确定但可疑 → **FAIL**（宁严勿松）

## 输入
每项：`序号. CI<<<词条>>> EN<<<英文>>> RU<<<俄文>>>`

{{ENTRY_LIST}}

## 输出（严格）
每行一个、序号连续：
1. OK
2. FAIL:简短原因
3. FIX:更好的俄文定译（须含西里尔，除非整词应 KEEP 则写 FIX:原词条）

优先用 `FIX:…` 给出可直接落盘的俄文；无法给出时用 `FAIL:原因`。
