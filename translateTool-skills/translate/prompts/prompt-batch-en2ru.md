# 批量翻译任务（词条 → 俄）

你是一个专业的软件工具国际化翻译助手。请将以下 UI 词条批量翻译成**俄文**。源文本可能是**中文**或**英文**。

## 翻译要求
1. 只输出**俄语译文**（须含西里尔字母，如 а/б/в…），不要解释；**禁止复述源文**；**禁止**使用 `→`/`->` 把源文和译文写在一行
1.1 **严禁英文原样回显（最高优先级）**：源文是英文句子/短语时，输出必须是俄文，**禁止**把英文原样当作俄文输出。
   - 错误：`1. Cancel`（与英文相同）/ `1. Export report`（无西里尔）
   - 正确：`1. Отмена` / `1. Экспорт отчёта`
   - 例外：极短缩写或专名本身无俄语惯用译法时可保留（如 `OK`、`SSL`、`HTTP`、`Qt`、`XML`）；普通 UI 词（Cancel/Save/Delete/Open…）与完整英文句**必须翻译**
1.2 **禁止括号英注**：不要写 `Тип (Type)` / `Заголовок (Title)` / `… (Could not …)` 这种「俄文 + 英文括注」；只输出俄文。文件后缀 `(*.scd)` 除外。
2. 保持占位符不变：`{}`, `{:.3f}`, `%1`, `%2`, `[{}]` 等；HTML 标签（如 `<h3>`、`<p>`）原样保留
2.1 **占位符 token 强约束（最高优先级）**：输入中可能包含形如 `⟦__PH_CURLY_0__⟧` 的占位符 token。这些 token 必须：
   - **逐字原样保留**（包括 `⟦`、`⟧`、下划线与数字），禁止改写、加空格、拆分、合并
   - **按输入中出现的顺序原序输出**（禁止换序/挪位）
   - 句首占位符必须保持在句首
2.2 **换行哨兵（最高优先级，防批线错位）**：源文内部换行已被替换为固定哨兵 `⟦__NL__⟧`。必须：
   - **逐字原样保留** `⟦__NL__⟧`，禁止翻译、删改、拆成真实换行
   - **输出仍严格一行一条**（`1. …` / `2. …`）；禁止在一条译文内部插入真实换行，需要换行处保留哨兵
3. 可区分占位符 `%1/%2/%n` 允许按俄语句法调整语序，但格式必须保持（禁止 `% 1`）
4. 专有名词缩写（Qt、SSL、XML、HTTP、RLO 等）可保留；**不要**把整句英文当成「专有名词」而整句不译
5. 保持标点与格式正确；不要引入中文标点
6. 文件后缀保持无空格：`(*.scd)`、`(*.cid)`
