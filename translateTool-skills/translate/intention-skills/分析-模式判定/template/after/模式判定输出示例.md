# 模式判定输出示例

## 输入

```text
读取 f:\DownLoads\qt通用语言.xlsx，把英文翻译列翻成俄文，回填俄文列，给我新 xlsx。
```

## 输出

```yaml
mode: en2ru
modelPolicy: single
models: []
confidence: high
needConfirm: false
reason: "用户明确英译俄；未提多模型 → single"
next: 编排-翻译工作流
```

## 全部模型并发

```text
全部模型并发英译俄，满速跑
```

```yaml
mode: en2ru
modelPolicy: all
models: []
confidence: high
needConfirm: false
reason: "全部模型并发 / 满速"
```

## 指定多模型

```text
用 Hunyuan-MT 和 Qwen3-8B 并发
```

```yaml
mode: en2ru
modelPolicy: list
models: ["tencent/Hunyuan-MT-7B", "Qwen/Qwen3-8B"]
confidence: high
needConfirm: false
reason: "短名已解析"
```

## 探测模型

```text
测一下模型哪些可用
```

```yaml
task: probe_models
reason: "用户要求探测"
next: 探测-模型可用性
```

## 低置信度例

```text
帮我翻译这个 xlsx
```

```yaml
mode: null
modelPolicy: single
models: []
confidence: low
needConfirm: true
reason: "未标明方向，且未提供表头抽样"
ask: "是中译英（zh2en）、英译俄（en2ru），还是中英俄流水线（pipeline）？"
```
