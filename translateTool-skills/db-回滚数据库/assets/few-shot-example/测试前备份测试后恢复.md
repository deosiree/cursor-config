# 测试前备份 · 测试后恢复（few-shot）

## 用户请求 1 · 测试前备份

```text
使用 $db-回滚数据库 测试前备份 translationtool 数据库
```

### agent 应做

1. **分析-回滚模式判定** → `rollbackMode=backup`
2. 运行 `backup-database.ps1`：

```powershell
& "F:\Documents\Default-Obsidian\huiyanSkills\translateTool-skills\db-回滚数据库\scripts\backup-database.ps1" `
  -ProjectRoot "F:\Documents\Repertory\Sieyuan\translationtool" `
  -Label "before_test"
```

3. 输出 `backupPath`、`sizeHuman`、提示「测试后可恢复到 .latest」

### 预期输出示例

```json
{"backupPath":"F:\\...\\db\\backups\\translationtool_20260702_150000_before_test.sql","sizeHuman":"12.34 MB","createdAt":"2026-07-02 15:00:00"}
```

---

## 用户请求 2 · 测试后恢复

```text
测试完了，恢复到最新备份
```

### agent 应做

1. **分析-回滚模式判定** → `rollbackMode=restore`
2. **查询-备份清单** → 展示 `.latest` 与文件大小
3. **人工门禁** — 等用户说「确认恢复」
4. **执行-整库恢复**：

```powershell
& "...\restore-database.ps1" -UseLatest -ProjectRoot "F:\Documents\Repertory\Sieyuan\translationtool" -Force
```

5. **验证-整库恢复** → tableCount、关键表抽样

### 禁止

- 未确认就 `-Force`
- restore 后声称成功但未 verify

## 与 audit 回滚对比

| 步骤 | backup+restore | audit 逐条 |
|------|----------------|------------|
| 测试前 | mysqldump 一次 | 可选 |
| 测试后 | restore 一次 | inspect + 4 步 UPDATE |
| 适用 | 本地杂项测试 | 精确撤销部分同意 |
