# 扩展场景：预翻译与工作台

首版 **仅 inspect + 文档指引**，不自动 execute，避免误伤人工译文。

## 1. pre_translate auto_approved

源码：`terminology-agent/app/services/pre_translate/single.py`

- `review_status=auto_approved` 时调用 `_sync_auto_approved_to_workbench`
- **不写** `term_agent_audit`
- **不写** 术语库 state=3（除非另有 merge 逻辑）

### inspect 思路

按 `entry_info_id` + 时间窗查工作台挂载翻译：

```sql
SET NAMES utf8mb4;

SELECT ei.id, ei.entry, ei.en_trans_id, t.translate, t.translate_state, t.delete_state, t.last_use_time
FROM t_entry_info ei
LEFT JOIN t_translate t ON t.id = ei.en_trans_id
WHERE ei.task_id = '<task_id>'
  AND t.last_use_time >= NOW() - INTERVAL 1 HOUR
  AND t.delete_state = 0;
```

（其他语种将 `en_trans_id` 换为对应列。）

### 回滚思路（需人工确认）

1. `UPDATE t_entry_info SET en_trans_id = NULL WHERE id IN (...)`
2. `UPDATE t_translate SET delete_state = 1 WHERE id IN (...)`

**不要** UPDATE `term_agent_audit`（不存在记录）。

## 2. 工作台手工改译

- 可能写入 `t_entry_operate` 操作日志
- 可能更新已有 `t_translate` 而非新建

### inspect 思路

```sql
SELECT * FROM t_entry_operate
WHERE entry_id IN (...)
  AND operate_time >= NOW() - INTERVAL 1 HOUR
ORDER BY operate_time DESC;
```

### 回滚

- 无法安全自动还原旧译文
- 建议：inspect 后人工决定，或从备份恢复单条
