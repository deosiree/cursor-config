# 扩展场景：预翻译与工作台

## 推荐回滚方式

手工预翻译 / 工作台改译验收：**整库 backup + restore**（见 translationtool `docs/ops/DEV_DB_CHECKPOINT.md`）。  
逐表手撕易漏（尤其 US-3E-01 后多写了 audit / `segment_trace`）。

## 1. pre_translate（含 auto_approved）

源码：`terminology-agent/app/services/pre_translate/single.py`、`write_result`

可能写入：

| 目标 | 条件 |
| --- | --- |
| `t_translate` + 工作台外键 | `auto_approved` 且 `WorkbenchEntrySync` 成功 |
| `term_agent_audit` | `needs_human`，**或**走过切分（含 `auto_approved`，`segment_trace`） |
| `t_entry_info.segment_trace` | 走过切分且有 `entry_info_id` |

### inspect 思路（可选，非整库恢复时）

```sql
SET NAMES utf8mb4;

-- 最近预翻译 audit（含 auto_approved）
SELECT id, source_text, review_status, retrieval_method, entry_info_id, created_at
FROM term_agent_audit
WHERE created_at >= NOW() - INTERVAL 2 HOUR
ORDER BY created_at DESC
LIMIT 50;

-- 工作台切分列
SELECT id, entry, segment_trace IS NOT NULL AS has_seg, comment
FROM t_entry_info
WHERE segment_trace IS NOT NULL
  AND is_delete = 0
LIMIT 50;
```

### 回滚

- **默认**：restore 到测试前 `db/backups/.latest`
- 未建备份时：勿盲目 DELETE；先 backup 现状再与用户确认范围

## 2. 工作台手工改译

- 可能写入 `t_entry_operate` 操作日志
- 可能更新已有 `t_translate` 而非新建
- 无法安全自动还原旧译文 → 整库备份优先

## 3. 术语库 UI 删除

- 前端：`/Syk/deleteSykEntry` → 软删除
- 若仅删术语库、不解绑工作台，仍可能挂脏 trans_id → audit 模式四步或整库恢复

## 4. 何时转 audit_rollback / adm_matrix_reset

| 意图 | 模式 |
| --- | --- |
| 术语学习「确认」副作用要精确撤销 | `audit_rollback` |
| ADM 矩阵 retrieval 塌缩为全 exact | `adm_matrix_reset` |
| 预翻译几条后整段还原 | **backup + restore** |
