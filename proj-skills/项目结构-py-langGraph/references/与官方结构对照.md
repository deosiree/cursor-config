# 与官方结构对照

## LangGraph 官方（Application structure）

```
my_agent/
├── utils/
│   ├── state.py
│   ├── nodes.py
│   └── tools.py
└── agent.py          # 图组装
```

来源：[LangGraph Application structure](https://docs.langchain.com/oss/python/langgraph/application-structure)

## 本项目扩展

| 官方 | 本项目 | 原因 |
|------|--------|------|
| `agent.py` | `builder.py` + `runner.py` | compile 与 invoke 分离，便于 mock |
| nodes 单文件 | `nodes/intentions` + `nodes/features/*` | 意图/功能分层 |
| （无） | `edges/` | 条件边与节点对称 |
| （无） | `domain/` | 枚举与格式化 |
| （无） | `services/` | FastAPI Application 编排层 |

## FastAPI 分层

- api 薄 + services 编排 + repository 数据
- 来源：FastAPI in Layers 生产实践

## 社区多 agent

```
agents/<agent_name>/
├── nodes/
├── edges/
├── state.py
└── builder.py
```

本项目 `graph/<workflow>/` 与之等价，外层再包 FastAPI `services/`。
