# 读取问题记录文档

提取本次记录来源中的行、表头和筛选元数据，供编排层与仓库扫描使用。

## 适用场景

处理钉钉文档、附件或本地记录文件；来源可被读取且筛选条件明确。

## 与相邻节点的边界

- 不判断代码是否实现需求；交给 `[[../扫描参考仓库/SKILL.md]]`。
- 不生成最终报告；交给 `[[../生成指定列报告/SKILL.md]]`。
- 不修改来源文档。

## 输入、输出与配套

输入为来源、负责人、版本、可选业务记录 ID 或 `{sheet, row}` 物理行定位及目标列；输出为保留实际来源定位的记录数据。物理行号不冒充业务 ID。失败规则见 `[[../../references/证据分级与只读边界.md]]`。

## 使用示例

```text
从问题台账.xlsx 提取惠岩负责的 2.4.0 记录，并保留每行原 ID 和当前测试状态。
```
