# 扫描参考仓库

按指定 refs 静态检查一个或多个仓库，为每条问题记录提供当前代码证据和范围限制。证据固定来自解析后的 commit SHA；dirty 工作区状态照实记录但排除在扫描之外。

## 适用场景

问题记录已提取，且用户明确提供目标仓库和版本范围。

## 与相邻节点的边界

- 不读取或修改问题表；由 `[[../读取问题记录文档/SKILL.md]]` 处理。
- 不运行任何测试或构建；生成字段交给 `[[../生成指定列报告/SKILL.md]]`。
- 不将“仓库外待核实”写成“未实现”。

## 输入、输出与配套

输入为仓库路径列表、全局 refs、可选的仓库级 `repoRefs` 和筛选后的记录；每个仓库独立解析最终 refs，输出为逐行证据映射。`targetVersion` 是记录筛选版本，`targetRef` 是代码快照；发布版本对应关系未确认时，不推断历史状态。状态定义见 `[[../../references/证据分级与只读边界.md]]`。

## 使用示例

```text
比较前端和后端仓库；前端用最近可达 tag 到 HEAD，服务端按 repoRefs 指定版本范围。核对租户创建记录并分别列出代码路径、符号和可确认范围。
```
