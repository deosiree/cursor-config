# 生成指定列报告

## 核心任务

把筛选后的问题行和证据映射整理成可审阅、可逐列抄填的 Markdown 文件。

## 何时触发

- 意图编排已完成记录筛选和静态代码核对。
- 用户只要求按现成记录/证据生成或重排指定列报告。

## 输入 / 前置条件

- `targetColumns`：非空、有顺序的列名列表。
- `selectedRows`：记录 ID、标题、负责人、版本和原表状态。
- `evidenceMap`：每条记录的证据状态、定位与限制。
- `reportPath`：明确文件路径，或由默认报告目录生成唯一文件名。

## 执行与输出

1. 按 `[[../../template/问题和修复记录报告.md]]` 生成报告头和逐行内容。
2. 每行只输出本次要求的列，列名与顺序逐字匹配；每个值单独成项，便于人工抄填。
3. 源码路径、ref、行号、证据状态及相关原表状态放在“审核辅助（不填入目标列）”项；多个原表状态按原列名逐项列出，不新增目标列。
4. 自测建议与本轮执行结果分开；只读限制下结果写“本轮未执行，待人工验证”。
5. 核对记录数、每行列数、编码和报告路径后，只创建这一份报告文件。

## 边界

- 报告目标文件已存在时停止，不覆盖；输出路径在源仓库内时也不得写入，除非用户本次明确指定该路径为报告输出。
- 输入记录与证据缺项时保留缺项标记，不编造结论。
- 不回写线上表格，不生成代码补丁或其他文件。

## 使用示例

```text
用给定记录和证据，仅生成“改动方案说明”和“开发自测结果”两列；保留来源 ID 和审核辅助证据，不修改源文档。
```
