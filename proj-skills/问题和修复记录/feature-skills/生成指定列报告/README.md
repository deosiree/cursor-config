# 生成指定列报告

将本次选定记录映射为指定列的 Markdown 报告，供用户审阅并手动录入。

## 适用场景

列集合每次可能不同；列名必须按用户输入或有效默认配置逐字保留。

## 与相邻节点的边界

- 不读取在线表格或扫描代码；分别交给 `[[../读取问题记录文档/SKILL.md]]` 和 `[[../扫描参考仓库/SKILL.md]]`。
- 只创建报告文件，不回写任何来源。

## 输入、输出与配套

输入为记录、证据映射、列名和报告路径；输出为一份 Markdown 文件。格式见 `[[../../template/问题和修复记录报告.md]]`，状态语义见 `[[../../references/证据分级与只读边界.md]]`。

## 使用示例

```text
按“问题、影响、验证建议”三列组织以下已核对记录，未运行的验证统一标为未执行。
```
