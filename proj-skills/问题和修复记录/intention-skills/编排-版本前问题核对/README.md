# 编排-版本前问题核对

← [[../../SKILL.md]] · 负责组织一次完整的发版前记录核对。

## 适用场景

父级已解析出本次文档、仓库、开发人员、目标列和目标版本，需要协调读取、扫描和报告三步。

## 与相邻节点的边界

- 父级负责触发边界、默认值和输入校验。
- 本节点负责顺序、行范围和失败门禁。
- `feature-skills/` 节点只执行各自的数据读取、代码证据收集或报告生成。
