## 样例四：操作入口被注释且快照不代表目标发布版

记录主题：租户所有者转移。原记录注明“未开放，后续版本实现”。

- 改动方案说明：当前 `HEAD` 的租户列表转移入口位于 HTML 注释块内；弹窗和 API 仍有源码，但当前列表没有可触发的入口。
- 改动影响分析：当前快照下列表不提供该操作；若后续开放，会影响租户所有者及关联数据归属，仍需确认后端权限和提交结果。
- 开发自测记录：核对 `TenantTable.vue` 中入口是否可执行；若目标版本开放，再检查权限、转移提交和列表刷新。
- 开发自测结果：本轮未执行，待人工验证。
- 审核辅助：证据状态为“部分定位”；注释入口只证明操作未启用，弹窗/API 只证明代码痕迹存在。
- 版本口径：问题记录属于 β1，而当前 `HEAD` 注释写明 beta2 暂不开放。该 HEAD 不能证明 β1 发布时的状态；需要 β1 对应发布 ref 才能确认历史行为。
