# Darwin Baseline：问题和修复记录

## Target

- `skill`: 问题和修复记录
- `path`: `proj-skills/问题和修复记录/SKILL.md`
- `scope`: 父级入口；其他节点作为上下文
- `mode`: `evaluate-only`
- `eval_mode`: `dry_run`
- `branch`: `main`
- `git`: 目标套件为未跟踪目录；工作区含其他用户改动，本轮不切分支、不暂存、不提交

## 失败基线

- 典型请求：使用钉钉问题表、指定开发人员和列集合，结合一个或多个仓库生成手工填写报告。
- 可能漏掉的步骤：缺少显式阶段检查点时，可能先扫描代码再发现版本或记录范围不明确；也可能在生成报告前未核对逐仓库 refs、来源行数和目标文件冲突。
- 误触发风险：一般代码修复、要求回写表格或定时扫描的请求可能被误路由。
- 输出漂移风险：动态列集合、逐仓库 refs、原表状态与本轮验证结果可能混写。
