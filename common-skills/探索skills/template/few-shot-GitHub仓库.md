一个面向工程实现者的中文项目：系统拆解 Claude Code 的架构、运行机制与产品设计，
并把这些内容整理成一套可落地的构建教程。

你应该如何设计它、拆解它、实现它。

- agent loop 与模型调用主循环
- 上下文管理与消息拼装
- 工具系统、tool-call 契约与执行编排
- 权限控制与命令执行边界
- 记忆系统、持久化与状态回流
- subagent、task、session 等多阶段工作流
- React/Ink 终端 UI
- MCP、插件、IDE bridge 与外部系统集成
