# 面试官皱眉：「你知道 Claude Code 记忆机制吗？」我：「何止知道？我还看过源码」

> 作者：小林 | 来源：微信公众号

大家好，我是小林。我在公众号已经陆陆续续写过好几篇图解 Claude Code 原理的文章...
agent 的记忆机制，如今已经是个不折不扣的面试热点。那这一篇，我们就把 Claude Code 的记忆机制，从源码层面翻个底朝天。

## 一、先聊聊「LLM 其实没记忆」

LLM 本身根本「记不住」任何东西，它是彻头彻尾无状态的。每次你按下回车，对它来说都是「从头看一遍」：把系统提示词、所有历史对话、当前问题，全部塞进去，然后输出一个回复。

短期记忆 vs 长期记忆：
- 短期记忆：上下文窗口本身，装着当前这轮对话
- 长期记忆：持久化存到磁盘、能跨会话活下来

## 二、业界主流方案为什么不够看

四大方案：滑动窗口、对话摘要、向量检索、分层存储
共同病根：自由文本无约束、不区分类型、没有老化机制、重检索轻写入

## 三至七、Claude Code 的两层记忆架构

静态层（CLAUDE.md 六层级）+ 动态层（自动记忆系统：四种类型、Sonnet 选 top-5、老化警告）...
