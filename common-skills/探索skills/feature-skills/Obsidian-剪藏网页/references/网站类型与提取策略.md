# Obsidian-剪藏网页 参考文档

## 支持的网站类型及提取策略

| 网站类型 | 识别特征 | 提取策略 |
|---------|---------|---------|
| 微信公众号 | `mp.weixin.qq.com` | `js_content` div + `msg_title`/`msg_author` 变量 |
| 技术博客 | 常规 `<article>` 或 `<main>` | `article` 或 `main` 标签 |
| 知乎文章 | `zhuanlan.zhihu.com` | `article` 或 `.Post-RichText` |
| 掘金 | `juejin.cn` | `article` 标签 |
| 通用 | 无特定匹配 | `<body>` 全文降级 |

## Obsidian 文件格式

```yaml
---
source: "URL"
title: "文章标题"
clipped: "YYYY-MM-DD"
tags: [clipped, web]
---

# 文章标题

正文内容...

---
*原文链接：URL*
```

## Vault 路径参考

- WSL: `/mnt/d/FILE/Obsidian Vault/Clippings/`
- Windows: `D:\FILE\Obsidian Vault\Clippings\`

## 常见 HTML 解析库

- `html.parser` — Python 标准库，无需安装
- `beautifulsoup4` — 更健壮，`pip install beautifulsoup4`
- `readability-lxml` — 自动提取正文，`pip install readability-lxml`
