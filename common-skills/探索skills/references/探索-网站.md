# 探索-网站 策略

> 当目标不是代码仓库而是一个网站/博客时使用。

## 主策略：OpenCLI JS 渲染抓取

```bash
npx opencli fetch <url> --render --wait-for="article,main,.content,h1" --timeout=15
```

参数说明：
- `--render`：启用 JS 渲染（解决 SPA 空壳问题）
- `--wait-for`：等待指定 CSS selector 出现后才抓取
- `--timeout`：超时秒数

**前置检测：** 如果报 `command not found` 或 `npx: not found`，跳过主策略直接走回退 1。不尝试自动安装 OpenCLI。

## 回退策略

### 回退 1：web_fetch 拿骨架

```typescript
// 用 web_fetch 拿 HTML，提取结构化信息
const html = await web_fetch(url);
// 提取：<title> <meta description> <h1>-<h3> <a href>
```

**SPA 空壳检测：** 如果提取到的 `<title>` 是空字符串或通用默认值（如"React App""Vite App""Loading..."），且 `<h1>` 不存在 → 判定为 SPA 空壳，跳过回退 1 直接走回退 2（web_search）。

### 回退 2：web_search 补充

```typescript
// 搜索 "{网站名} about" "{网站名} 介绍"
const results = await web_search(`${domain} about documentation`);
// 从搜索结果片段拼凑内容摘要
```

**查询模板（中文站点）：**
- `web_search("{domain} 介绍")`
- `web_search("{domain} 功能 特点")`
- `web_search("{domain} 文档 教程")`

**查询模板（英文站点）：**
- `web_search("{domain} about")`
- `web_search("{domain} documentation")`
- `web_search("{domain} features guide")`

尝试 2-3 个查询后取信息最丰富的结果拼凑摘要。如果所有查询都无结果，输出"⚠️ web_search 也未找到有效信息，建议用户直接访问该 URL"。

## 输出格式

```markdown
## {网站名} — 探索结果

**来源：** {url}
**抓取方式：** OpenCLI / web_fetch / web_search
**抓取时间：** {timestamp}

### 网站结构
- / → 首页：{摘要}
- /docs/ → 文档：{摘要}
- /about/ → 关于：{摘要}

### 关键内容摘要
{从页面提取的核心信息}

### 与当前任务的相关性
{这个网站的信息如何帮助回答文档中的问题}
```

## 约束

- 不递归爬取：最多抓入口页 + 3 个关键子页
- 不下载二进制文件（图片、PDF 等）
- 超时 15 秒，超时后直接用回退策略
