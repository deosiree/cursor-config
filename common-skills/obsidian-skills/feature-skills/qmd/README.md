# qmd — 语义搜索

> NousResearch 出品，安装量 153K。

## 作用

本地混合检索引擎：语义搜索 + 关键词排序。比全文搜索智能很多。

## 安装方式

### 方式一：Hermes Agent（推荐）

```bash
hermes skills install qmd
```

安装后文件位于 `~/.hermes/skills/qmd/`

### 方式二：手动查找

GitHub 上搜索 `qmd` + `hermes-agent` 或 `qmd skill` 查找社区版本。

## 路由状态

route-obsidian 路由表中 qmd 是 **检索知识类**的次选（首选为 llm-wiki query），可选安装。
