# obsidian-vault

> NousResearch 出品，安装量 153K，安全评分 90。

## 作用

读取/搜索/创建/编辑笔记。使用文件 API（非 shell），日常笔记读写专用。

## 安装方式

### 方式一：Hermes Agent（推荐）

```bash
hermes skills install obsidian-vault
```

安装后文件位于 `~/.hermes/skills/obsidian-vault/`

### 方式二：手动查找独立实现

GitHub 上搜索 `obsidian-vault` + `hermes-agent` 或 `obsidian vault skill` 可找到社区独立版本。
