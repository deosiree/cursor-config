# ruralocity-vault-skills

> 填补 OpenClaw vault-maintainer（374K★）不可用的维护缺口。

## 提供的 skill

| skill | 功能 | route-obsidian 路由 |
|-------|------|-------------------|
| **vault-weekly-review** | System Health 检查 + 活跃度简报 + 本周动态 | 🔧 Vault 维护类的首选 |
| **vault-duplicate-detection** | 查找内容重叠或标题相似笔记 | 由 vault-weekly-review 触发 |
| **vault-consolidation-detection** | 发现可合并的关联笔记组 | 由 vault-weekly-review 触发 |

## 安装方式

已作为 git submodule 安装，完整路径：
`feature-skills/ruralocity-vault-skills/.claude/skills/<skill-name>/SKILL.md`
