# obsidian-vault-management — MVP 测试输入

## 任务
验证 obsidian-vault-management 的核心笔记操作是否正确。

## 前置条件
- `VAULT_ROOT` 已设置（或 `.env` 文件存在）
- vault 根目录有 PARA 结构（00-07 目录）

## 测试用例

### 测试 1：创建 Daily Note
请求："创建今天的 daily note"
预期：`06 - Daily/YYYY/MM/YYYYMMDD.md` 被创建
验证：文件存在、frontmatter 完整（created/title/type/tags）

### 测试 2：搜索笔记
请求："搜一下关于 Wikilink 的笔记"
预期：在 `$VAULT_ROOT` 下搜索含 "Wikilink" 的 .md 文件
验证：返回结果列表

### 测试 3：创建项目笔记
请求："在项目目录下新建一篇笔记，标题是 'Obsidian 技能体系设计'，内容用 [[wikilink]] 关联到 route-obsidian"
预期：在 01 - Projects/ 下创建，含 frontmatter + wikilink
验证：文件内容和引用正确

### 测试 4：使用 Dataview
请求："列出本周创建的所有笔记"
预期：执行 Dataview 查询
验证：语法正确

### 测试 5：编辑笔记
请求："在昨日 daily note 末尾追加一段今天的思考"
预期：使用 patch 或 read+write 追加内容
验证：追加内容在末尾，不破坏原有结构

## 验收标准
- [ ] 所有笔记操作使用文件工具（非 shell 命令）
- [ ] frontmatter 始终包含 created/updated/title/type/tags
- [ ] 新笔记至少包含一个 [[wikilink]]
- [ ] vault 路径从 VAULT_ROOT 环境变量读取
