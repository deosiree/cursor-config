# 执行：类比生成

> **定位：** 纯功能 skill。生成类比。不涉及编排、不涉及写后校验。

## 输入

| 参数 | 说明 |
|------|------|
| `术语` | 需要解释的技术概念 |
| `标准定义` | 术语的官方定义（1-2 句） |
| `读者背景` | 目标读者的已知领域（"程序员"、"产品经理"、"初中生"） |
| `核心特征` | 术语的 2-5 个关键特征（来自标准定义） |

## 输出

```json
{
  "类比": "一句话类比，
  格式：{术语} 就像 {熟悉事物} — 因为 {共享特征}",
  "映射表": [
    {"术语特征": "核心特征1", "类比要素": "类比中的对应物1"},
    {"术语特征": "核心特征2", "类比要素": "类比中的对应物2"},
    ...
  ],
  "覆盖度": "类比覆盖了 X% 的核心特征",
  "边界说明": "这个类比在哪里不适用（1-2 句）",
  "示例": "一个具体例子展示类比如何运作"
}
```

## 类比选择检查清单

- [ ] 类比领域与读者背景匹配？
- [ ] 类比覆盖 80%+ 核心特征？
- [ ] 类比不会引起误解（边界说明已覆盖剩余 20%）？
- [ ] 类比可一句话说完？
- [ ] 类比不包含需要另外解释的概念？

## RED

| 反模式 | 替代 |
|-------|------|
| 类比领域与读者背景不匹配 | 选读者熟悉的领域 |
| 类比覆盖度不足 80% | 换一个更贴切的类比 |
| 类比需要额外解释 | 用读者已知事物，不要用同样复杂的概念做类比 |
