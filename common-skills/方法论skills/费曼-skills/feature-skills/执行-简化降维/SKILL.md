# 执行：简化降维

> **定位：** 纯功能 skill。把术语之间的层级/派生/调用关系降维为一条可理解的时间线或结构图。

## 输入

| 参数 | 说明 |
|------|------|
| `术语关系` | 术语间的层级/派生/调用描述 |
| `降维方式` | "时序"（步骤链）或 "结构"（分层/树形） |

## 降维方式选择

| 输入关系类型 | 推荐降维方式 | 输出格式 |
|------------|------------|---------|
| 调用链/先后顺序 | 时序 | 步骤 1→2→3 |
| 包含/层级关系 | 结构 | 树形/分层 |
| 混合（既有层级又有调用） | 时序为主，标注层级归属 | 时序 + 标注 |

## 输出

### 时序降维

```
步骤 1：{术语A} 发生
  → 触发条件：{什么情况下发生}
  → 输出：{给下一步的输入}
步骤 2：{术语B} 接收 {术语A} 的输出
  → 处理逻辑：{简述}
  → 分支到 {术语C} 或 {术语D}
步骤 3：{...继续}
```

### 结构降维

```
顶层：{术语A（总称）}
  ├── 子层 1：{术语B}
  │   ├── {术语B.1}
  │   └── {术语B.2}
  └── 子层 2：{术语C}
      └── {术语C.1}
```

## RED

| 反模式 | 替代 |
|-------|------|
| 时序和结构混在一起 | 选一种主导方式，另一种做辅助标注 |
| 降维后仍然超过 7 步/7 个节点 | 先分组再降维，每层 ≤ 7 |
| 降维丢失了关键关系信息 | 在每一步/节点后加一句话说明 |
