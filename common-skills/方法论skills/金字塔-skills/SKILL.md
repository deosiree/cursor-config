# 金字塔-skills

> **定位：** 父级 agent 入口。先给结论再分层展开，帮助读者建立全局认知。
> **核心原则：** "塔尖一句话说清核心结论，下层论据 MECE 展开。"

## 何时使用

- 章节开头需要建立全局认知（"概述"、"全貌"、"架构"）
- 读者面对多概念缺少"地图"，需要先看全景再下钻
- 知识本身有层次依赖关系（先理解 A 才能理解 B）

## 何时不要使用

- 只解释单个术语 → 用 `[[../不嵌入/SKILL.md]]` 或 `[[../费曼-skills/SKILL.md]]`
- 对决策点/选型做分析 → 用 `[[../苏格拉底-skills/SKILL.md]]`
- 知识不需要分层，只需要顺序叙述 → 用不嵌入

## 入口判断

| 用户需求 | 路由 |
|---------|------|
| 章节开头需要建立全局认知 | → `[[intention-skills/编排-结论先行/SKILL.md]]` |
| 需要将凌乱信息做层级提炼 | → 直呼 `[[feature-skills/执行-层级提炼/SKILL.md]]` |
| 需要确保论据 MECE 分组 | → 直呼 `[[feature-skills/执行-MECE分组/SKILL.md]]` |
| 不明确 | → 问用户：写章首金字塔 / 提炼信息层级 / 检查 MECE？ |

## RED（失败基线）

| 触发条件 | 一线修复 | 兜底 |
|---------|---------|-----------|
| 塔尖结论不可验证（"很重要""很灵活"） | 改为可检验的断言（"三步骤""两种模式"） | 标注⚠️ 塔尖无验证标准 |
| 用在细节对比段（两三个选项的对比） | 改用对比表 | 去掉金字塔结构 |
| 层级超过 3 层 | 合并次要层级，保持 2-3 层 | 保留 2 层，第三次下沉为附录 |
| 论据不 MECE（重叠或有遗漏） | 调分组逻辑直到互斥且完整 | 标注⚠️ "论据间有重叠" |
| 塔尖与下层论据脱节 | 塔尖必须能自然分解为下层论据 | 重写塔尖或重组论据 |
| 只用金字塔没有后文呼应 | 最后一层加一个到后文对比表的过渡句 | 标注⚠️ "与正文脱节" |

## GREEN（执行主线）

### Step 1：接收路由指令

```
输入：method = "金字塔·结论先行"
      主题 = 章节主题
      关键概念 = 该章节涉及的术语列表
```

### Step 2：路由执行

🔴 CHECKPOINT：确认主题适合金字塔结构（有层级关系/需要全局认知），再跳转

跳转 `[[intention-skills/编排-结论先行/SKILL.md]]`，传入主题和关键概念。

### Step 3：返回结果

将生成的金字塔结构（塔尖 + 2-3 层论据 + 过渡句）返回给调用方。

## REFACTOR

- 分组维度超过 6 种 → 拆出 `references/金字塔-MECE维度库.md`
- 与费曼组合使用的场景增多 → 在入口判断中增加"金字塔顶层 + 费曼子节"的专用路由
- 论据生成逻辑复杂化 → 拆出 `feature-skills/执行-论据扩展/SKILL.md`

## 输入契约

| 参数 | 来源 | 说明 |
|------|------|------|
| `主题` | 方法论路由 | 章节主题，如 "微服务架构三组件" |
| `关键概念` | 方法论路由 | 该章节涉及的概念列表，如 `["API Gateway", "Service Mesh", "Load Balancer"]` |
| `目标读者` | 方法论路由 | 读者当前认知水平，如 "有单体架构经验的开发者" |

## 使用示例

```
输入：
  主题 = "微服务架构的三组件"
  关键概念 = ["API Gateway", "Service Mesh", "Load Balancer"]
  读者 = "有单体架构经验的开发者"

路由 → intention-skills/编排-结论先行
输出：
  塔尖："三个组件是按请求路径依次排列的：Gateway 入口 → Mesh 路由 → Balancer 分发"
  第 2 层：
    - API Gateway：统一的 API 入口（鉴权/限流/协议转换）
    - Service Mesh：服务间通信基础设施（服务发现/重试/熔断）
    - Load Balancer：实例级别的流量分发（负载均衡/健康检查）
  第 3 层：Gateway 决定"谁来" → Mesh 决定"找谁" → Balancer 决定"找哪个实例"
  过渡句："下面的对比表展示三者各自的选型考量..."
```

## 约束

1. 每层论据 MECE（相互独立、完全穷尽）
2. 层级不超过 3 层
3. 塔尖必须可验证（"X 由三步组成"而非"X 很重要"）
4. 最后一层必须与后文建立连接（"下面将...展开"）
