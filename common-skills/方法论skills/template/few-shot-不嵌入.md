# 不嵌入 — 真实输出

**触发：** "什么是 JSONL？"  
**来源：** 对 `Agent开发学习路线` 的真实回答

---

JSONL（JSON Lines）是一种文本格式，每行是一个独立的 JSON 对象，用换行符 `\n` 分隔。

```jsonl
{"id": "1", "type": "header", "messageCount": 42}
{"id": "2", "role": "user", "content": "你好"}
{"id": "3", "role": "assistant", "content": "你好！有什么可以帮你？"}
```

**与 JSON 的区别：** JSON 是一个完整的数组 `[{...}, {...}]`，必须一次性解析全部内容。JSONL 每行独立，可以追加写入、逐行读取——非常适合日志和会话持久化场景。
