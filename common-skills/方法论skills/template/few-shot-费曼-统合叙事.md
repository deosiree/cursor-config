# 费曼 · 统合叙事 — 真实输出

**触发：** "解释 Agent Loop 和 Tool 的关系"  
**来源：** 对 `Agent开发学习路线` 第 1 节"概念扫盲"的真实回答

---

Agent 是一个能**自主理解目标、制定计划、调用工具、执行行动并迭代推理**的 AI 程序。它不只是"问答机器人"，而是一个带有循环（loop）的行动者：

- **感知**：接收用户输入或环境反馈
- **推理**：大模型分析当前状态，决定下一步动作
- **行动**：调用工具（Tool）、生成回复、或请求用户确认
- **观察**：接收工具返回结果，融入上下文
- **循环**：重复推理→行动→观察，直到任务完成或达到终止条件

在工程层面，Agent 对应一个**运行时循环（Agent Loop）**，而不是一个 HTTP 接口封装。

Tool 是 Agent 与大世界交互的**接口**。每个 Tool 是一个有明确输入/输出 schema 的函数。Tool 在架构上对应**工具注册中心（Tool Registry）**，所有工具集中注册，由 Agent Loop 统一调度。

- ✅ 每个术语在场景中有明确的"动作"
- ❌ 没有"XX 就像 YY"的独立类比（遵循了费曼统合叙事规则）
