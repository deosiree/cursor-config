# 交互：生成追问

> **定位：** 纯功能 skill。不负责编排追问链长度，只负责生成单条追问问题。

## 输入

| 参数 | 说明 |
|------|------|
| `决策点` | 正在分析的选择/判断 |
| `当前认知` | 读者当前的理解程度（来自之前问答的分析） |
| `前序问答` | 上一轮追问 + 读者的回答 |
| `追问深度` | 当前是第几轮（1-based），用于选择追问策略 |

## 追问策略（按轮次）

| 轮次 | 追问策略 | 句式模板 |
|------|---------|---------|
| 第 1 问 | 指向表面矛盾或直觉矛盾 | "如果...你首先会遇到什么？" |
| 第 2 问 | 指向深层权衡或隐含假设 | "那这种情况呢...？" |
| 第 3 问 | 逼出核心约束或决策原则 | "所以归根结底，关键在于...？" |
| 第 4+ 问 | 验证理解深度或边界条件 | "如果条件变成...，你的结论还成立吗？" |

## 输出

```json
{
  "追问": "问题文本（具体、场景化、可回答）",
  "意图": "这一问想逼出什么认知/揭示什么矛盾",
  "预期回答方向": "如果读者理解正确应该怎么答"
}
```

## RED

| 反模式 | 替代 |
|-------|------|
| 问题太抽象读者无法回答 | 放到具体场景中："如果...你会怎么选？" |
| 问题与上一问无关 | 基于上一问的答案追问 |
| 问题变成审讯（"你确定吗？"） | 先肯定再递进（"你说得对，那再考虑..."） |
| 问题答案只是"是/否" | 改成开放式问题（"怎么..."），引导表述 |
