# 判定：追问深度

> **定位：** 纯功能 skill。不负责生成追问，只判断追问链是否达到足够的认知深度。

## 输入

| 参数 | 说明 |
|------|------|
| `追问链` | 到目前为止的所有追问 + 回答记录 |
| `决策点` | 原始的分析对象（用于对照是否已触及核心） |

## 判定标准

| 条件 | 判定 | 动作 |
|------|------|------|
| 已经逼出核心约束或决策原则 | **通过 ✅** | 收尾输出结论 |
| 读者连续 2 问答不上来或答非所问 | **边缘 ⚠️** | 降维重问或直接给出结论 |
| 还在表面问题绕圈（3 问未深入） | **不通过 ❌** | 调整追问策略（改句式/换角度） |
| 已经 5 问但仍未触及核心 | **强制收尾 ⚠️** | 直接输出当前最佳结论 + 标注"追问链已超过合理长度" |
| 读者主动给出正确答案 | **通过 ✅** | 验证后立即结束，不需要继续追问 |

## 通过确认列表

判定为"通过"前确认：
- [ ] 读者是否能用自己的话复述核心结论？
- [ ] 读者是否能说出这个结论的适用边界？
- [ ] 读者是否能举一个反例？

全部 ✅ → 通过。否则视为"边缘"或"不通过"。

## 输出

```json
{
  "判定": "通过/边缘/不通过/强制收尾",
  "理由": "根据判定标准的哪一条得出",
  "建议动作": "收尾输出结论 / 降维重问 / 调整追问策略 / 直接输出",
  "已达深度": "读者已理解的内容要点",
  "未达深度": "读者的理解盲区（仅边缘/不通过时输出）"
}
```
