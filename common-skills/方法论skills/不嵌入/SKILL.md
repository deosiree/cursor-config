# 不嵌入

> **定位：** 兜底方法。当知识点单一、无歧义、读者只需要知道"是什么"时使用。

## 适用条件

- 单一术语/格式定义
- 概念有标准定义、无歧义
- 读者只需知道"是什么"（而非"为什么"或"怎么选"）

## 使用形式

```
定义：{一句话标准定义}
示例：{具体可感知的例子}
注意：{边界条件或常见误解}
```

## 示例

> **定义：** JSONL 是每行一个 JSON 对象的文本格式。
> **示例：**
> ```json
> {"id": 1, "text": "hello"}
> {"id": 2, "text": "world"}
> ```
> **注意：** JSONL 不是标准 JSON 数组，无法用标准 `JSON.parse` 解析。

## 禁忌

- 对层级概念/多术语关系使用不嵌入 → 改用金字塔或费曼
- 对决策使用不嵌入 → 改用苏格拉底或对比表
