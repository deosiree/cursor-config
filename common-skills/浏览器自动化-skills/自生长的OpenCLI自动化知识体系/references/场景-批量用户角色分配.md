# 场景：批量用户角色分配

> 自生长自 `nebula-ux` (2026-06-06)，由用户请求 "帮我在系统里批量给 50 个用户分配角色权限" 触发。

## 适用条件

用户需要在用户管理页面对多个用户逐一分配角色（勾选角色 → 提交），且角色选项较多需脚本批量化。

## 输入 / 输出

| 方向 | 内容 | 示例 |
|:----:|------|------|
| **输入** | 目标用户列表 / 角色名称 / profile | 用户=前50条, 角色=["系统管理员","业务审批"], profile=local |
| **输出** | 分配结果（成功数/失败数）+ 失败截图 | ✅ 48/50 成功, 2 用户跳过（已离职） |

## 核心命令

```bash
SESSION="nebula-ux"
PROFILE="local"

# 打开用户管理 → 进入第一个用户
opencli browser $SESSION open "http://localhost:8080/cloud/Apex/system/user"
opencli browser $SESSION wait text "用户管理" --timeout 5000

# 点分配角色（eval 兜底，因 Element Plus 按钮文本含图标）
opencli browser $SESSION eval "document.querySelector('.el-table__body-wrapper tbody tr:first-child .btn-assign-role').click()"
opencli browser $SESSION wait text "选择角色" --timeout 5000

# 勾选角色（按索引选择 checkbox）
opencli browser $SESSION eval "document.querySelectorAll('.el-checkbox__input')[0].click()"
opencli browser $SESSION eval "document.querySelectorAll('.el-checkbox__input')[2].click()"

# 提交（eval 兜底，因按钮文本有空格）
opencli browser $SESSION eval "document.querySelector('.el-dialog__footer .el-button--primary').click()"
opencli browser $SESSION wait text "角色分配成功" --timeout 3000

# 截图存证
opencli browser $SESSION screenshot "./screenshots/assign-role-1.png"
```

## 边界处理

| 条件 | 处理 |
|------|------|
| 用户列表翻页 | 循环前判断底部是否有「下一页」按钮，有则 `.pagination .btn-next.click()` |
| 用户已离职（弹窗报错） | eval 捕获弹窗文本含「用户不存在」→ 跳过 + 记录到失败列表 |
| 弹窗关闭后 DOM 重置 | 每次循环重新 querySelector tbody tr，而非缓存行引用 |

## 踩坑记录

- `click --role button --name "分配角色"` 失败 → Element Plus 按钮含图标子节点。**解法**: eval `.btn-assign-role` CSS class 兜底
- `click --role button --name "确 定"` 失败 → 中文按钮文本含空格。**解法**: eval `.el-dialog__footer .el-button--primary` 兜底
- 循环中 DOM 引用失效 → 每次迭代重新 querySelector 而非缓存
