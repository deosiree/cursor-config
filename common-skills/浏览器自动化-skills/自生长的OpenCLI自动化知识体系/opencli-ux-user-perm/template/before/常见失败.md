# Before — 常见失败（会话真实）

## 场景 A：OpenCLI 创建用户

- 使用 `/dev-api/seccenter/v2/user/create` → 404
- `opencli type` 填登录框 → 提交后仍空
- eval 内 `location.href='/cloud/Apex/system/user'` → CDP disconnected
- 无 `sys:user:add` → 找不到「新增」，误以为不能创建

## 场景 B：操作列

- 列表只有 user0601 一行 → 只有「编辑」，误判 perm 配置错误
- 有 resetPassword perm 但菜单 isVisible:false → 仍不显示（显示兜底）
- 忘记 OperationColumn inline=2 → 以为按钮丢失

## 场景 C：数据

- 重复跑 seed → 73+ 用户
- UI 显示人数与 API list 不一致 → 未分页拉全

## Agent 典型错误

- 不读 skill 直接写新脚本
- 把 isCurrentUser 与 selectable 混为一谈
- 批量删除无确认
