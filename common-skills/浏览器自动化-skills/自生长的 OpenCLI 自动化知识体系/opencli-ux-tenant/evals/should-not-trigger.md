# should-not-trigger — 不应触发本 skill 的场景

## 与租户管理无关

```text
用户: "帮我看看用户管理页面的问题"
→ 不应触发。本 skill 只覆盖租户管理，不覆盖用户管理。
```

## 只需要文档阅读

```text
用户: "租户管理有哪些配置项？"
→ 不应触发。应直接回复 README.md 或 config 内容，不执行自动化。
```

## 无浏览器环境

```text
用户: "在服务器上跑一下测试"
→ 不应触发。无 Chrome / OpenCLI 环境时无法执行。
```

## 混合请求

```text
用户: "帮我改一下租户创建的代码，再跑一下测试"
→ 不应直接触发。需停下来确认：改代码和跑测试需分开处理。
```

## 环境未就绪

```text
用户: "跑测试" 但 opencli doctor 未通过 / 密码未配置 / baseUrl 不可达
→ 先停在 preflight，修复后再进入执行 flow。
```
