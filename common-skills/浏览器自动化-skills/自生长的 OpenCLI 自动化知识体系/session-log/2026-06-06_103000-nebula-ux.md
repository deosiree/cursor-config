## 关键命令序列

```bash
# 1. 打开用户管理页面
opencli browser nebula-ux open "http://localhost:8080/cloud/Apex/system/user"
opencli browser nebula-ux wait text "用户管理" --timeout 5000

# 2. 点击第一个用户的「分配角色」按钮
opencli browser nebula-ux click --role button --name "分配角色"
# → 失败: Element Plus 按钮文本带图标，--name 无法匹配
# 降级: eval JS 兜底
opencli browser nebula-ux eval "document.querySelector('.el-table__body-wrapper tbody tr:first-child .btn-assign-role').click()"

# 3. 等角色弹窗出现
opencli browser nebula-ux wait text "选择角色" --timeout 5000

# 4. 勾选「系统管理员」和「业务审批」
opencli browser nebula-ux eval "document.querySelectorAll('.el-checkbox__input')[0].click()"
opencli browser nebula-ux eval "document.querySelectorAll('.el-checkbox__input')[2].click()"

# 5. 点击确定
opencli browser nebula-ux click --role button --name "确 定"
# → 失败: 按钮文本含空格，Element Plus button 实际包含图标
opencli browser nebula-ux eval "document.querySelector('.el-dialog__footer .el-button--primary').click()"
opencli browser nebula-ux wait text "角色分配成功" --timeout 3000

# 6. 截图为证
opencli browser nebula-ux screenshot "./screenshots/assign-role-success.png"

# 7. 循环到下一用户（重复步骤 2-6）
```

## 踩坑

1. `click --role button --name "分配角色"` 失败 → Element Plus 的按钮 DOM 含图标子节点，`--name` 匹配的是纯文本节点而非可见文本。**解法**: eval JS 用 querySelector + .click() 兜底
2. `click --role button --name "确 定"` 失败 → 中文文本中间有空格。**解法**: eval 直接选 `.el-dialog__footer .el-button--primary`
3. 弹窗关闭后 DOM 滚动重置，循环脚本需要重新获取 table 行引用。**解法**: 每次循环重新 querySelector tbody tr
