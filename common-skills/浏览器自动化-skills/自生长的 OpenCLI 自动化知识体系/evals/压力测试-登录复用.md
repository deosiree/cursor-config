# 压力测试：跨 skill session 复用

> 验证 OpenCLI 通用路由中心的核心承诺：**固定 session 名（`nebula-ux`）可在多个 skill 间复用登录态**。

## 前置条件

- opencli 已安装 + doctor 通过
- microfb 在 `http://localhost:8080` 已启动
- 各个子 skill 目录存在且可执行（opencli-ux-tenant、opencli-ux-role-tab-validation）

## 测试场景

### 场景 1: session 跨脚本共享

**目的：** 验证 `opencli-ux-tenant` 登录后，`opencli-ux-role-tab-validation` 可直接复用 session，无需再次登录。

```bash
# 步骤 1: 登录（租户 skill）
cd opencli-ux-tenant
bash login.sh --profile local

# 步骤 2: 验证已登录（角色 skill，--skip-login）
cd ../opencli-ux-role-tab-validation
bash role-tab-validation.sh --profile local --skip-login
```

**预期结果：** 步骤 2 不经过登录流程，直接进入角色 Tab 校验。截图正常生成。

**失败模式：** 步骤 2 停在登录页 → session 名不一致 或 session 已过期。

### 场景 2: 手动 bind 后复用

**目的：** 验证 `bind` 模式能接管现有浏览器标签，供后续脚本使用。

```bash
# 步骤 1: 在浏览器中手动登录 http://localhost:8080
# 步骤 2: 绑定 session
opencli browser nebula-ux bind

# 步骤 3: 运行角色测试（无需再登录）
cd opencli-ux-role-tab-validation
bash role-tab-validation.sh --profile local --skip-login
```

**预期结果：** 步骤 3 直接使用绑定的登录态执行测试。

### 场景 3: session 过期后重新登录

**目的：** 验证 session 过期后，`login.sh` 能重新建立登录态。

```bash
# 步骤 1: 登录 + 等待超时（或手动在浏览器中登出）
cd opencli-ux-tenant
bash run-e2e.sh --profile local

# 步骤 2: 确认 session 过期后重新登录
bash login.sh --profile local
```

**预期结果：** `login.sh` 能正常打开登录页、填写凭据、等待跳转。

## 验证检查清单

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| session 复用不重复登录 | 角色 skill 用 `--skip-login` 成功执行 | 不弹出验证码 / 不出现 login 页面 |
| bind 接管已有标签 | `opencli browser nebula-ux bind` 返回 ok | session 可正常 get url |
| 截图保存 | 检查 screenshots/ 目录 | 有 `.png` 文件且非空 |
| 断言结果正确 | 用例通过 | 无 exit code 1 |
| 失败时截图 | 模拟一个断言失败 | screenshots/ 下生成 `fail-*.png` |

## 如果测试失败

| 失败现象 | 可能原因 | 修复 |
|---------|----------|------|
| Session 名不匹配 | 两个 skill 用了不同 session 名 | 统一改为 `nebula-ux`（默认值） |
| `opencli: command not found` | 未安装 | `npm install -g @jackwener/opencli` |
| `opencli doctor` 报错 | 浏览器桥接未连接 | 按 doctor 提示修复 |
| `wait text` 超时 | 页面路径 / 端口不对 | 检查 `http://localhost:8080` 可访问 |
| 登录后仍在 /login | 验证码拦截 | 改为 `captchaMode: manual` |

## 注意

- 这些测试依赖本地开发环境（microfb + apex_dev），不是所有环境都能跑
- session 在 `opencli browser nebula-ux bind` 后 5 分钟内无操作可能自动过期
- 测试结果应截图存证
