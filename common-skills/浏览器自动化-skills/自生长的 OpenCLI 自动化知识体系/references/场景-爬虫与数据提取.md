# 场景：爬虫与数据提取

## 适用条件

用户需要从**JS 渲染的网站**（SPA / 动态页面）提取文本或结构化数据，例如：

- 飞书/语雀文档全文下载
- SPA 文档站内容抓取
- 动态渲染的列表/表格数据
- 需登录才能访问的页面内容
- 分页/无限滚动数据的批量提取

## 输入 / 输出

| 方向 | 内容 | 示例 |
|:----:|------|------|
| **输入** | 目标 URL / 提取策略（一次性/分页/结构化） / 输出路径 / 是否需要登录 | URL=`https://xxx.feishu.cn/wiki/xxx`, 策略=分页滚动, 输出=`./output/doc.md`, 需登录=是 |
| **输出** | 本地文件（Markdown / JSON）+ 统计信息（页数/字符数） | 已保存: `./output/doc.md` (15 页, 23,456 字符) |

## ⚠️ 为什么不用 web_fetch

`web_fetch` 只获取 HTML 源码——对 React/Vue/Angular 等 SPA 站点，拿到的是空壳 HTML（`<div id="root"></div>`），内容由 JS 动态渲染。

OpenCLI 驱动真实 Chrome 渲染完成后提取，拿到的是**用户看到的内容**。

## 引用已有 skill

### OpenCLI-下载飞书文档

`common-skills/探索skills/feature-skills/OpenCLI-下载飞书文档/`

**使用方式：**
```bash
cd .cursor/common-skills/探索skills/feature-skills/OpenCLI-下载飞书文档
node scripts/download.js --url "https://xxx.feishu.cn/wiki/xxx" --out "./output/doc.md"
```

**核心流程：**
```
1. OpenCLI browser open URL → 等待页面加载
2. eval 定位内容容器 → 计算 scrollHeight / clientHeight
3. 分页滚动：逐页 scrollTop + wait 渲染 + extract
4. 去重合并（与上一页内容比对）
5. 连续 2 次无新内容 → 提前结束
6. write_file 输出 Markdown 文件
```

**关键代码：** `scripts/download.js` + `lib/opencli.js`

## 通用爬取流程（不依赖已有 skill）

```bash
SESSION="nebula-crawl"
URL="https://example-spa-site.com/docs/guide"
OUTPUT="./output/page-content.md"

# 1. 打开页面
opencli browser $SESSION open "$URL"
sleep 3  # 等 SPA 首次渲染

# 2. 提取全页面文本（一次性）
opencli browser $SESSION extract --chunk-size 20000 > "$OUTPUT"

# 3. 或：按页滚动提取（适合超长页面）
## 获取页面高度
HEIGHT=$(opencli browser $SESSION eval "
  JSON.stringify({
    scrollH: document.documentElement.scrollHeight,
    clientH: document.documentElement.clientHeight
  });
")
echo "页面高度: $HEIGHT"

## 逐页滚动 + 提取（参考 OpenCLI-下载飞书文档 的脚本逻辑）
STEP=800  # 每步滚动像素
for ((page=0; page<50; page++)); do
  opencli browser $SESSION eval "window.scrollTo(0, $((page * STEP)));"
  sleep 2
  opencli browser $SESSION extract --chunk-size 20000 >> "$OUTPUT"
done
```

## 提取结构化数据

对于表格/列表数据，用 `eval` 返回 JSON 更精确：

```bash
# 提取表格数据
opencli browser $SESSION eval "
  JSON.stringify({
    rows: [...document.querySelectorAll('.el-table__body tbody tr')].map(tr => ({
      name: tr.querySelector('td:nth-child(1)')?.innerText?.trim(),
      status: tr.querySelector('td:nth-child(2)')?.innerText?.trim(),
      time: tr.querySelector('td:nth-child(3)')?.innerText?.trim(),
    })),
    total: document.querySelector('.el-pagination .el-pagination__total')?.innerText?.trim()
  });
"

# 提取列表数据（无限滚动）
opencli browser $SESSION eval "
  (function() {
    const items = [...document.querySelectorAll('.list-item')].map(el => ({
      title: el.querySelector('.title')?.innerText?.trim(),
      link: el.querySelector('a')?.href,
      desc: el.querySelector('.desc')?.innerText?.trim(),
    }));
    return JSON.stringify({ count: items.length, items });
  })();
"
```

## 登录后爬取

如果目标页面需要登录验证，用登录流程先建立 session：

```bash
# 方案 A: 自动登录
opencli browser $SESSION open "https://site.com/login"
opencli browser $SESSION fill --role textbox --name "账号" "$USER"
opencli browser $SESSION fill --role textbox --name "密码" "$PASS"
opencli browser $SESSION click --role button --name "登录"
sleep 3

# 确认已离开登录页
URL=$(opencli browser $SESSION get url)
[[ "$URL" == *"/login"* ]] && { echo "登录失败"; exit 1; }

# 方案 B: 手动登录后 bind（适合有验证码的场景）
opencli browser $SESSION open "https://site.com/login"
echo "请在浏览器中手动登录，完成后按 Enter..."
read -r
opencli browser $SESSION bind

# 然后开始爬取
opencli browser $SESSION open "https://site.com/protected/doc"
opencli browser $SESSION extract --chunk-size 20000
```

## 爬取策略选择

| 策略 | 适用场景 | 命令 |
|------|---------|------|
| 一次性提取 | 单页 SPA，无滚动加载 | `extract` |
| 分页滚动 | 超长文档/文章（如飞书文档） | eval scrollTo + extract 循环 |
| 结构化提取 | 表格/列表数据 | eval 返回 JSON |
| 多页面遍历 | 文档站/博客列表 | eval 获取所有链接 → 逐个 open + extract |
| 渲染后 fetch | 不需交互只需渲染 | `opencli fetch <url> --render` |

## 边界处理

| 条件 | 处理 |
|------|------|
| 页面需要登录 | 先用登录流程或 bind |
| 页面内容不存在 | check extract 结果长度，为空则报错 |
| 滚动到底页 | 监视 scrollHeight 不变 + extract 去重 |
| 输出目录不存在 | 自动创建 |
| 连续无新内容 | 提前结束循环 |
| 提取内容过大 | --chunk-size 分段提取 |
