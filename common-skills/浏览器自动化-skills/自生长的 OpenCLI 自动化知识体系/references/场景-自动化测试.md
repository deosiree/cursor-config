# 场景：自动化测试

## 适用条件

用户要对某个页面执行**「操作 → DOM 断言」**的端到端校验，例如：表单校验、Tab 跳转、列表 CRUD、权限控制等。

## 输入 / 输出

| 方向 | 内容 | 示例 |
|:----:|------|------|
| **输入** | 目标 URL / 测试操作步骤 / 期望断言条件 / profile 配置 | URL=`http://localhost:8080/cloud/Apex/system/role`, 操作=「新增角色→不填名→切换Tab→确定」, 期望=「Tab跳回基础信息+显示错误」 |
| **输出** | 测试结果（通过/失败）+ 断言详情 + 失败截图 | `TC1 PASS: activeTab=基础信息, formError=true, errorText=角色名称不能为空`，失败时生成 `screenshots/fail-tc1.png` |

## 引用已有 skill

### 1. 角色 Tab 校验（弹窗交互测试）

`opencli-ux-role-tab-validation/`

覆盖：弹窗打开 → Tab 切换 → 不填表单点确定 → 断言 Tab 跳回 + 错误提示 → 填合法值 → 成功提交。

**核心模式：**
```bash
# 1. 打开页面
opencli browser nebula-ux open "$ROLE_URL"

# 2. 弹窗 Tab 切换（click → eval 兜底）
# 见 lib/common.sh: click_role_dialog_tab

# 3. 填充表单（fill → eval 兜底）
# 见 lib/common.sh: fill_role_name

# 4. DOM 断言（eval 取弹窗状态 + Python JSON 解析）
# 见 lib/common.sh: assert_role_dialog_tab, assert_role_form_error

# 5. 失败截图
opencli browser nebula-ux screenshot "screenshots/fail-${case}.png"
```

**使用方式：**
```bash
cd opencli-ux-role-tab-validation
bash run-e2e.sh --profile local
```

### 2. 租户管理 CRUD（全流程测试）

`opencli-ux-tenant/`

覆盖：登录 → 新增租户（向导多步）→ 列表搜索断言 → 删除 → 再次搜索断言空列表。

**核心模式：**
```bash

# 2. 多步向导：click → wait → eval 定位下一步按钮

"

# 4. 删除确认（弹窗嵌套定位）
# 见 lib/common.sh: 三次 eval 定位 dropdown → delete → confirm
```

**使用方式：**
```bash
cd opencli-ux-tenant
bash run-e2e.sh --profile local
```

## 通用测试流程（不依赖已有 skill）

如果测试目标不匹配上述两个 skill，按以下通用流程：

```bash
SESSION="nebula-ux"

# 1. 登录（或 bind 已有标签）
opencli browser $SESSION open "$BASE_URL/login"

# 2. 填写账号密码
opencli browser $SESSION fill --role textbox --name "账号" "$USERNAME"
opencli browser $SESSION fill --role textbox --name "密码" "$PASSWORD"
opencli browser $SESSION click --role button --name "登录"
sleep 2

# 3. 导航到目标页面
opencli browser $SESSION open "$BASE_URL/$TARGET_PAGE"
opencli browser $SESSION wait text "页面标题" --timeout 15000

# 4. 执行操作
## 点击按钮
opencli browser $SESSION click --role button --name "新增"

## 填写表单（eval 兜底，适合复杂输入）
opencli browser $SESSION eval "
  document.querySelector('.el-input__inner').value = '测试数据';
  document.querySelector('.el-input__inner').dispatchEvent(new Event('input', {bubbles: true}));
"

## 切换 Tab
opencli browser $SESSION click --role tab --name "关联设备"

# 5. 断言
## 等待文本出现
opencli browser $SESSION wait text "操作成功" --timeout 5000

## 计数断言（eval + JSON 输出）
opencli browser $SESSION eval "
  JSON.stringify({
    visible: document.querySelector('.el-dialog').offsetParent !== null,
    toast: document.querySelector('.el-message')?.innerText?.trim()
  });
"

# 6. 截图
opencli browser $SESSION screenshot "./screenshots/step-5-result.png"
```

## 测试复用技巧

| 技巧 | 说明 |
|------|------|
| 固定 session 名 `nebula-ux` | 同一 session 跨多脚本共享，避免重复登录 |
| 用 `--skip-login` 参数 | 已登录时跳过登录步骤（tenant / role-tab / user-perm 均支持） |
| 截图 + 状态转储 | 断言失败时同时 `screenshot` + `state` + `get url` 三连 |
| eval 兜底 | `click --name` 对非标准按钮可能无效，JS eval 更可靠 |
| `bind` 模式 | 手动登录后 `opencli browser $SESSION bind` 绑定现有标签 |
