# Before — 常见失败

## 场景 A：只看 logs 不看 Events
- `kubectl logs` 正常但 Pod 仍 CrashLoop → 遗漏 describe Events 的 OOMKilling / BackOff

## 场景 B：不看 --previous
- Pod 重启后当前日志只有新进程启动 → 遗漏旧进程的错误

## 场景 C：kubectl top 不可用
- metrics-server 未装 → `Error: metrics not available yet` → 改用 describe

## 场景 D：kubectl exec 交互失败
- plink 无 `-t` → `rpc error: pty` → 改用非交互单条命令

## Agent 典型错误
- 混淆 exit code 含义（137 ≠ 128+9 的简单相加）
- 在 CrashLoop 状态仍试图 exec → `unable to upgrade connection`
