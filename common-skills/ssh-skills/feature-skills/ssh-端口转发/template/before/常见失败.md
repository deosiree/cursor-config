# Before — 常见失败

## 场景 A：没加 -N
- plink 分配 pty → 隧道不保持 → 命令执行完就断开

## 场景 B：本机端口被占用
- `bind: Address already in use` → 未先检查端口 → 换端口

## 场景 C：目标地址写错
- 写 `localhost` 但服务在跳板机上 → 转发地址应是内网 IP

## 场景 D：SOCKS DNS 不解析
- 浏览器未开 remote DNS → 域名解析不到内网

## Agent 典型错误
- 忘记 -hostkey 导致批处理交互式中断
- 目标地址写成 `127.0.0.1` 但实际是 K8s Pod IP
