# Before — 常见失败

## 场景 A：pscp 不在 PATH
- 未从 plink 同目录找 pscp → `pscp: command not found`

## 场景 B：hostkey 未缓存
- 首次连接触发交互式提示 → pscp 批处理中断

## 场景 C：kubectl cp 路径不存在
- 未先 `kubectl exec -- ls` 确认 → `resource not found`

## 场景 D：大文件传输无进度
- 以为卡死 → 实际在传输中；缺少进度条/duration 信息

## Agent 典型错误
- Windows 路径含空格未加引号
- ProxyJump 写法不对导致跨跳板机失败
