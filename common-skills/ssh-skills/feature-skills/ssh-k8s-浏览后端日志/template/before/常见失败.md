# Before — 常见失败

## 场景 A：kubectl logs 无 ERRO
- grep 模式写错（大小写/中英文符号）→ 先 `kubectl logs ... | tail -50` 看原始日志格式
- Pod 名不对（hash 变化 / 命名空间错）→ `kubectl get pods -n platform` 确认

## 场景 B：plink 连接失败
- `Cannot confirm host key` → 缺 `-hostkey` 参数
- `Connection timed out` → VPN/morbax 未连

## 场景 C：没有 Running Pod
- 部署更新中，新旧交替 → 加 `--since=5m` 或两个 Pod 都查

## Agent 典型错误
- 把 Pod hash 写死入命令 → 下次部署失效
- 只读 INFO 行不看 ERRO 行 → 误判根因
- 密码写入 skill 正文 → 安全风险
