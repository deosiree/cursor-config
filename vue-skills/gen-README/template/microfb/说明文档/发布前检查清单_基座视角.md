# 说明文档：发布前检查清单（基座视角）

本文档目标：在 `microfb` 发布前提供一份可执行的最小检查清单，优先覆盖最容易导致线上事故的风险：白屏、404、子应用挂载失败、串权。

> 使用方式：发布前逐项打勾；任何“否”都应先处理再发布。

## 1. 配置与模式检查（必做）

- [ ] **`VITE_APP_BASE` 与部署路径一致**
  - 预期：`createWebHistory(getAppBase())` 与实际访问前缀一致（如 `/cloud`）
  - 关联源码：`src/router/index.ts`、`src/api/gateway/route-base.gateway.ts`
  - 参考文档：`说明文档/环境变量与运行模式说明.md`

- [ ] **登录桥接配置可用（如启用）**
  - 预期：桥接模式下 `buildHostLoginUrl()` 能生成有效 URL；否则确认本地登录兜底可用
  - 关联源码：`src/utils/auth-mode.ts`、`src/plugins/permission.ts`

- [ ] **子应用模式与入口配置正确**
  - 预期：`VITE_SUBAPP_MODE` 与联调目标一致（`dynamic/static/auto`），entry 地址可达
  - 关联源码：`src/plugins/qiankun/apps.ts`、`src/utils/micro-app-config.ts`

## 2. 路由与守卫检查（必做）

- [ ] **未登录访问非白名单页会被正确重定向**
  - 预期：跳 host 登录或 `/login?redirect=...`，无死循环
  - 关联源码：`src/plugins/permission.ts`（`redirectToLogin`）

- [ ] **已登录首次进入可落到可用首页**
  - 预期：有菜单时落到 `findFirstValidMenuPath`；无菜单时落 `DEFAULT_HOME_PATH`
  - 关联源码：`src/plugins/permission.ts`（`resolveEntryMenuPath`）

- [ ] **并发导航不会重复生成动态路由**
  - 预期：`isGeneratingRoutes` 互斥生效；无重复 `generateRoutes` 造成的异常
  - 关联源码：`src/plugins/permission.ts`（`isGeneratingRoutes`、`waitForRoutesGeneration`）
  - 参考文档：`状态链路/并发导航互斥链路_动态路由生成.md`

## 3. 会话与菜单状态检查（必做）

- [ ] **登录成功（非 MFA）后会写入本地状态**
  - 预期：`userInfo`、`menuCache` 写入成功；能跳转首页
  - 关联源码：`src/store/modules/user/user.store.ts`（`loginV2`、`finalizeV2Login`）

- [ ] **菜单刷新后无需刷新页面即可生效**
  - 预期：`refreshCurrentUserMenus` 后，路由热重建生效；失效路由自动回退
  - 关联源码：`src/store/modules/user/user.store.ts`（`refreshCurrentUserMenus`、`rebuildDynamicRoutesAfterMenuUpdate`）

- [ ] **登出后前端强解散（后端失败也不阻塞）**
  - 预期：清理 `userInfo/menuCache/动态路由/子应用 props`，并跳回登录
  - 关联源码：`src/store/modules/user/user.store.ts`（`logout`、`resetUserState`）
  - 参考文档：`状态链路/登出强解散链路_后端失败不阻塞.md`

## 4. qiankun 与子应用检查（必做）

- [ ] **`router.isReady()` 后再注册子应用**
  - 预期：容器已存在，避免挂载时机导致空白
  - 关联源码：`src/main.ts`、`src/plugins/qiankun/apps.ts`

- [ ] **子应用容器与 activeRule 一致**
  - 预期：`#subapp-container` 存在；`activeRule` 与 `routerBase` 对齐
  - 关联源码：`src/constants/micro-app.ts`、`src/store/modules/appConfig.store.ts`

- [ ] **props 契约满足（menuList/menuVersion/userInfo/routerBase）**
  - 预期：子应用能拿到完整 props，并按 `menuVersion` 感知变化
  - 关联源码：`src/plugins/qiankun/apps.ts`（`getAppProps`、`setMicroAppProps`）
  - 参考文档：`说明文档/微前端契约说明书_Props与全局状态.md`

## 5. 最小冒烟用例（发布前 5 分钟）

- [ ] **未登录访问受保护页**：验证重定向正确
- [ ] **登录后进入入口页**：验证首页落点正确
- [ ] **快速点击多个菜单**：验证无异常 404/卡死
- [ ] **刷新菜单**：验证当前页失效时能自动回退
- [ ] **登出后登录另一个账号**：验证无串权（菜单与权限已切换）

## 6. 发布失败回滚准备（建议）

- [ ] 保留上一个可用版本构建产物与部署标识
- [ ] 记录本次涉及的关键环境变量改动（尤其 base、subapp entry、host auth）
- [ ] 明确回滚负责人和回滚触发条件（例如：出现持续白屏/大量 404）
