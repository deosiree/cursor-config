# pathLike 风格模型

## 语义

以 `/` 开头的路径模板；分段校验；允许业务在**静态段后缀**拼接 `?` / `#` 查询或锚点模板（如 `/user?`、`/list?from=menu`）。

参考：RFC 3986（path 在 `?`/`#` 处结束）、Vue Router 动态段须占满单段且以 `:` 开头。

## 整路径规则（先于分段）

- 非空；长度 ≤ `ROUTE_PATH_MAX_LENGTH`（与 UI `maxlength` 对齐）
- 禁止协议头、`//` 开头、空格、不可见字符
- 必须以 `/` 开头；除根路径 `/` 外禁止尾部 `/`
- 禁止连续空段 `//`

## 分段规则（按顺序）

```text
空段 → 尾斜杠 / 连续斜杠
段首 ? # & = → 拒绝（段首不要片段符）
含 : → 整段必须匹配 Vue 动态段正则，否则：
  - 非段首 : → 段中不要用冒号
  - 段首 : 且含 #? → 动态段不要接#?
  - 参数名无效 → 动态参数名无效
  - 其它 → 动态段格式不对
纯静态段 → 字母开头 [a-zA-Z0-9_-]*
含 ? 或 # 且无 : → 静态前缀 + [?#] + 可选后缀体
其它 → 段首数字/下划线/非法字符/路径段格式不对
```

## 动态段正则（整段）

```text
^:[a-zA-Z_][a-zA-Z0-9_]*(\([^)]+\))?[*+]?\??$
```

## 拼参后缀段正则

```text
^[a-zA-Z][a-zA-Z0-9_-]*[?#][a-zA-Z0-9\-._~/?#&=*+()]*$
```

## 消息 key 表（≤12 字，skill 不维护 locale）

| key | 场景 |
|-----|------|
| 路径不可为空 | 空 |
| 路径超过64字 | 超长 |
| 必须以/开头 | 无 leading / |
| 不要以/结尾 | 尾部 / |
| 不要以//开头 | 协议式 // |
| 不要使用协议头 | http: |
| 不要包含空格 | 含空白 |
| 不要连续斜杠 | 空段 |
| 段首不要片段符 | /?xxx |
| 段中不要用冒号 | user:id# |
| 动态段不要接#? | :id# |
| 动态参数名无效 | /: |
| 拼参格式不对 | 非法拼参段 |
| 路径段格式不对 | 兜底 |

异步「路径已存在」留在页面层组合 validator，本风格只提供语法规则工厂。
