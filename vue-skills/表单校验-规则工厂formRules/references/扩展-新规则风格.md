# 扩展新规则风格

当 **编排-未知规则MVP与落地** 完成后，若同一语义会在 ≥2 个表单复用，执行升级：

1. 命名 `ruleStyle`（camelCase，如 `numericRange`）
2. 登记 [`rule-style-registry.md`](rule-style-registry.md)
3. 新建 `feature-skills/配置-<中文名>规则/SKILL.md`
4. 从 MVP 代码提取 `references/<风格>-model.md`
5. 写 `assets/few-shot-example/<风格>-sample.md`（仅代码与步骤，无版本号）
6. 父 skill 路由表增一行

升级后，删除 MVP 文档中的临时分支说明，避免双路径并存。
